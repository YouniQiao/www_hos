# 全新沉浸光感，光影灵动

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_Immersive_light.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

沉浸光感让桌面、控制中心、通知中心等界面呈现通透光影质感，部分交互界面还会触发微妙的光晕与灵动的粒子动效，在使用设备时为您带来精致、沉浸的视觉体验。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

设备默认提供均衡适中的通透感和光效，您也可以根据喜好设置**沉浸光感**的强度。

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的桌面和个性化。

2.  在右侧界面的沉浸光感区域，选择不同程度的沉浸光感效果。效果越强，通透质感与光效越显著。

3.  部分界面操作时，可触发微妙的光晕、灵动的粒子动效等，如在桌面拖拽移动内容、移除桌面卡片、在控制中心拖动亮度/声音的滑块。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

仅部分操作支持光感动效，请以实际界面为准。
