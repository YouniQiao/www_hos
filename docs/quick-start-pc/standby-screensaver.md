# 待机屏保，趣味灵动显示

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_MonmentX_cutePet.png" alt="" width="720" height=""/>

**待机屏保**可以丰富设备的待机显示，让您的设备秒变电子时钟摆件、照片墙、音乐播放器等，打造个性化的百变心灵伴侣。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的桌面和个性化。

2.  在右侧界面，单击**待机屏保** > **编辑**进入编辑界面。

3.  在触控板上双指上、下、左、右滑动，或使用键盘上、下、左、右方向键，可切换不同屏保样式，切换到需要编辑的屏保时，点击下方![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_edit_pencil.png)进行编辑。

    +   个性时钟：基础时钟，可自定义时钟的字体、颜色；膨膨时钟，可自定义时钟的颜色，在整点和半点时会出现时钟膨胀、挤压、爆破等动效；萌宠时钟，可选择不同的萌宠，待机屏保时通过触屏或隔空手势与萌宠互动，增添趣味。

    +   照片墙：可添加多张喜欢的图片，轮播切换。

    +   氛围播控：可根据音乐旋律，营造动人的音乐视听氛围。

4.  完成所有编辑后，单击左上角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_chevron_left.png)返回待机屏保详情界面，设置接通电源时开启待机屏保和电池供电时开启待机屏保的时长（需小于设置的熄屏时长），设备闲置（无任何操作）到达指定时间后将自动进入待机屏保。

5.  待机屏幕保护时，您还可以进行以下操作：

    +   切换屏保类别：左右滑动屏幕或使用键盘左右方向键，可在不同类别的屏保间切换。

    +   切换同类别的不同屏保样式：上下滑动屏幕或使用键盘上下方向键，可在同类别的不同屏保样式间切换。

    +   趣味互动（仅萌宠时钟支持）：通过触屏单击萌宠，与萌宠互动；使用隔空手势，伸开手掌对准摄像头并稍作停顿，待屏幕出现![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_AirGesture_handup_blue.png)后向下挥动手掌，可以隔空投喂小狗萌宠或给小猫萌宠投掷网球。

    +   氛围播控：控制音频播放，如播放、暂停或切换上下曲等。
