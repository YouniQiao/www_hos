# 历史剪贴板

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_clipboard_history.png" alt="" width="720" height=""/>

开启**历史剪贴板**，自动保存多条复制记录，可查看剪贴板历史记录并粘贴内容。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的系统，然后在右侧界面单击开启历史剪贴板的开关。您也可以点按（键盘上）鸿蒙键![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png)+ V 组合键，打开历史剪贴板窗口，单击窗口中的开启按钮启用历史剪贴板。

2.  打开文档或应用（如备忘录），选中文本、图片、表格等内容，Ctrl+C 复制到剪贴板。

3.  光标移至编辑位置，点按（键盘上）鸿蒙键![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png) + V 组合键，打开历史剪贴板，单击待粘贴的内容即可。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   使用该功能前，请将您的设备升级到最新版本。

+   历史剪贴板默认显示近期最多 24 条复制记录；单次复制的内容超过 4M 时，不支持在历史剪贴板中显示。

+   关闭历史剪贴板的开关后，将清除历史记录。
