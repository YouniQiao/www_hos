# 桌面个性设置

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_Homescreen_custom.png" alt="" width="720" height=""/>

您可根据需要添加快捷方式至桌面，并对桌面布局、图标等进行个性化设置，让电脑桌面符合您的使用习惯。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

添加快捷方式至桌面

+   应用快捷方式：单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_allapps.png)进入应用中心，光标移至待添加的应用图标区域，右键选择添加至桌面。

+   文件夹/文件快捷方式：单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_filemanager.png)打开文件管理，光标移至待添加的文件夹/文件图标区域，右键选择发送快捷方式到“桌面”。

桌面个性设置

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的桌面和个性化。

2.  在右侧界面，根据需要进行相关设置：

    +   更换图标样式：在图标样式区域，单击勾选喜欢的图标样式。

    +   调整桌面图标大小：在桌面图标大小区域，拖动滑块调整图标大小。仅对桌面的应用图标生效，底部快捷栏的图标不可调整大小。

    +   沉浸光感：支持不同程度的沉浸光感效果。效果越强，通透质感与光效越显著。

    +   切换桌面风格：在桌面风格区域（您可能需要往下滚动页面），单击勾选想要的桌面风格。

    +   调整底部快捷栏高度：在快捷栏高度区域（您可能需要往下滚动页面），拖动滑块调整快捷栏的高度。高度变化的同时，快捷栏的图标会同比例放大或缩小。

    +   应用自动添加至桌面：单击开启应用自动添加至桌面的开关。开启后，应用下载后将自动添加应用图标至桌面。

    +   隐藏快捷栏：单击开启窗口最大化或分屏时隐藏快捷栏的开关（您可能需要往下滚动页面）。开启后，当应用窗口最大化或分屏时，即可自动隐藏快捷栏。
