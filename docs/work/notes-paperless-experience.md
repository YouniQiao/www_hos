# 笔记，无纸化学习办公新体验

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_notes_edit.png" alt="" width="720" height=""/>

**笔记**支持丰富的笔刷样式和辅助工具，能写字、可画图，助您自由描绘创意，在电脑上享受纸质笔记本的随心创作体验。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

以新建和编辑标准笔记为例：

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_allapps.png)进入应用中心，单击打开笔记。

2.  单击全部笔记，在右侧界面单击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/ic_public_add.png" width="24" height="24"/> > **新建标准笔记**，输入笔记名称，设置封面、内容比例、内容背景等，然后单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notepad_todo_checkmark.png)保存并进入编辑界面。

3.  在上方工具栏中，使用各类笔刷、文本、图片等功能，完成笔记创作。

    +   笔刷：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_ballpointpen.png)、![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_pencil_2b.png)、![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_markerpen_fill.png)等笔刷图标，可直接使用笔刷；再次点击可进入笔刷设置界面，根据需要完成笔刷粗细、不透明度、颜色等设置。

    +   橡皮擦：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_eraser_scribble.png)，可擦除部分涂鸦或手写内容，再次点击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_eraser_scribble.png)可进入橡皮擦设置界面，根据需要完成设置。

    +   一笔成形：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_instantshape.png)，一笔画完需要的图形（如圆形、矩形、爱心等），停顿 0.5 秒后可变成标准图形。

    +   套索：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_lasso.png)或![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_square_dashed.png)，圈选待编辑的内容，可在页面内自由拖拽；或者单击圈中内容，进行复制、粘贴、分享等操作。

    +   图片：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_picture.png)，可插入图片，还可以单击图片进行自由裁剪、复制、分享等操作。

    +   贴纸：单击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_stickers.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_stickers_store.png" width="24" height="24"/>，可从素材集市中选择喜欢的贴纸、封面、纸张等，插入到笔记中。

    +   字迹调整：单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_lasso.png)或![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_square_dashed.png)，圈选待编辑的手写字迹，选择字迹调整，从目标字体下拉框中选择喜欢的字体，并适当调整强度，即可美化手写字迹。您也可以单击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_AIsummary_color.png" width="24" height="24"/> > **实时字迹调整**，开启实时字迹调整的开关，选择目标字体、强度，手写内容将会按照目标字体和美化强度自动调整。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

**字迹调整**功能仅针对横向书写的中文、英文、数字、常用标点符号进行调整，请以实际情况为准。
