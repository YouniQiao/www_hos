# 网络邻居，跨设备共享文件夹

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_FileManager_NetworkShare.png" alt="" width="720" height=""/>

开启**网络共享**，电脑可与其他设备在同一局域网下共享本端文件夹，实现文档、图片、音视频等数据共享。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

以其他设备访问电脑本端文件夹为例：

1.  在电脑上，单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_filemanager.png)打开文件管理。

2.  单击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_more_1.png" width="24" height="24"/> > **设置**，开启网络共享的开关（您可能需要往下滚动页面）。首次开启时，需根据界面提示下载并安装网络邻居服务安装包。安装完成后单击保存并关闭，即可启用网络共享。

3.  返回文件管理界面，单击待共享的文件夹，右键选择**授予访问权限** > **特定用户**进入共享界面，在下拉框中选择待共享的用户。首次使用可先单击创建新用户，输入用户名和密码后单击添加。

4.  根据需要设置共享文件夹的访问权限（如读取），然后单击共享。

5.  在其他设备上，通过共享网络的 IP 地址、用户名和密码，访问共享文件夹。具体设备上如何访问共享文件夹，请参考设备说明书或咨询设备厂商。以Windows 11 系统电脑为例：打开文件资源管理器，在上方地址栏中输入“\\共享设备的 IP 地址”（如 \\192.1.1.1），然后输入用户名和密码连接。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

鸿蒙电脑仅 HarmonyOS 6.0.0.115 及以上版本支持共享本端文件夹给其他设备访问。
