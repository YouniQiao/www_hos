# 按键及屏幕操作

## 按键

| 操作 | 功能 |
| --- | --- |
| 单击 | 手表熄屏时，单击侧按键点亮屏幕。 手表显示表盘界面时，单击侧按键进入应用列表界面。 在星环桌面首界面，下拉屏幕可显示/隐藏应用名称。 星环桌面和列表桌面切换方式： 在星环桌面或列表桌面，上滑屏幕至应用最后一页，点击星环桌面或列表桌面切换。 点击设置 > 表盘和桌面 > 桌面，选择星环或列表模式。 手表显示非表盘界面时，单击侧按键返回表盘界面。 来电时，单击侧按键可将手表上的来电静音。 |
| 长按 | 手表关机状态时，长按侧按键开机。 手表开机状态时，长按侧按键 3s 及以上，出现重启/关机选项画面。 手表开机状态时，长按侧按键 12s 以上，可强制重启。 |
| 轻推开盖键 | 向前轻推开盖键，表盖自动弹开。 |

+   来电、锻炼等过程中有特别定义的场景例外。
+   HUAWEI WATCH Buds 系列不支持旋转表冠，您可通过手指上下滑动屏幕选择应用、调节音量等。

## 屏幕基本手势

| 操作 | 功能 |
| --- | --- |
| 单击 | 选择确认。 |
| 长按 | 设备在表盘界面时，长按可快速更换表盘。 设备在卡片界面时，长按显示卡片管理界面。 |
| 上滑 | 查看消息通知（在表盘界面上滑）。 |
| 下滑 | 进入控制中心（在表盘界面下滑）。 可开启找设备、设置情景模式等。 可查看剩余电量和蓝牙连接状态。 |
| 向左滑 | 表盘界面向左滑查看手表卡片。 |
| 向右滑 | 表盘界面向右滑进入负一屏。 应用子页面向右滑返回上一级。 |
