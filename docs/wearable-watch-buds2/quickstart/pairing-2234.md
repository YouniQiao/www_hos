# 与 iOS 手机配对连接

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   支持iOS 13.0 及以上版本手机。

## 配对前准备

1.  安装华为运动健康<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002464972260.png" width="24" height="24"/>应用。如已安装，请升级至最新版本。 如未安装，请到手机App Store 搜索华为运动健康，下载并安装。
2.  进入华为运动健康，点击我的 > 登录华为帐号。如果没有华为帐号，请先注册后再登录。 为保证您的穿戴设备与手机配对连接成功，建议您使用成人华为帐号登录。 配对完成前，请勿打开表盖或取出耳机。
3.  穿戴设备开机，选择语言，将设备靠近手机。

## 配对连接

添加设备连接：

1.  在华为运动健康首页点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002497971673.png" width="24" height="24"/> > 添加设备，在扫描结果中找到您的设备，点击连接。
2.  当穿戴设备屏幕出现配对请求时，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002464812644.png" width="24" height="24"/>。手机上华为运动健康界面出现蓝牙配对请求提示框，点击配对。手机出现是否允许设备显示手机通知的提示框，请点击允许，实际请按界面指引进行操作。
3.  等待几秒钟，华为运动健康提示与穿戴设备配对成功。
4.  手表与手机完成配对后，手机开始与耳机配对。手机上华为运动健康应用界面出现蓝牙配对请求提示框，点击配对，华为运动健康应用提示配对成功，点击完成。

扫码连接：

1.  在华为运动健康首页点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002464812900.png" width="24" height="24"/> > 扫一扫。
2.  当穿戴设备屏幕出现配对请求时，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002464972520.png" width="24" height="24"/>。手机上华为运动健康界面出现蓝牙配对请求提示框，点击配对。手机出现是否允许设备显示手机通知的提示框，请点击允许，实际请按界面指引进行操作。
3.  等待几秒钟，华为运动健康提示与穿戴设备配对成功。
4.  手表与手机完成配对后，手机开始与耳机配对。手机上华为运动健康应用界面出现蓝牙配对请求提示框，点击配对，华为运动健康应用提示配对成功，点击完成。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   请不要在手机上手动上滑关闭华为运动健康，以防穿戴设备与华为运动健康断连，无法接收手机消息和来电。
+   为确保穿戴设备能及时收到通知信息，请在手机上确认消息通知设置是否正常。
