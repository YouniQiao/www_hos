# 选择和更换耳塞

## 选择合适的耳塞

由于耳朵存在个体差异，默认的耳塞可能无法匹配至每个人。可以根据佩戴体验选择大小合适的耳塞，左右耳机也可以使用不同大小尺寸的耳塞组合。

## 更换耳塞

1.  先按箭头方向将耳塞翻过来，左右手分别捏住耳柄和耳塞，同时轻轻用力向斜下方分离，将耳塞取下。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000001457448757.png"/>
2.  将新耳塞翻过来后，轻轻推进卡槽。完毕后，将耳塞翻转到正常状态。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000001457528617.png"/>
