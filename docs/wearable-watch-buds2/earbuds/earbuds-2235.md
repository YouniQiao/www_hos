# 耳机控制卡片

耳机连接状态正常时，您佩戴耳机后，负一屏将会自动显示耳机控制卡片，您可快速操控耳机。

1.  手表与华为运动健康配对连接正常，手表与耳机连接正常。
2.  佩戴耳机后，在手表表盘界面，向右滑动屏幕进入负一屏。
3.  在耳机控制卡片中，可快速查看耳机电量，调整音量，切换降噪模式。 <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002503529037.png"/> 配图仅供参考，请以产品实际为准。
4.  点击耳机控制卡片，可进入耳机管理页面进行更多设置。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   当耳机与手表断开连接时，耳机控制卡片会自动消失，重新连接后会再次出现。
