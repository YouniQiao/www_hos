# 找耳机

## 手机找耳机

1.  进入华为运动健康的设备详情页，点击找设备 > 查找耳机。
2.  耳机和手机正常连接时，点击左耳机响铃或右耳机响铃。若耳机在较远范围时，可点击地图查找。 当耳机连接不上手机时，进入手机上的查找设备应用，点击设备可以查看到我的设备列表，点击目标设备，可查看耳机最后一次连接时的位置（位置信息保存7天）。 耳机再次重连或断连时会刷新地理位置，具体显示情况如下：当左右耳地理位置一致，显示双耳图标+地理位置，当左右耳地理位置不一致，分别显示左耳机图标+左耳机地理位置&右耳机图标+右耳机地理位置。

## 手表找耳机

1.  在表盘界面下滑进入控制中心，点击找设备 > 耳机。 两只耳机正常连接：点击左耳机响铃或右耳机响铃。 有耳机断开连接：点击重新连接，连接成功后，点击左耳机响铃或右耳机响铃。
2.  找到耳机后，点击停止响铃或等待铃声结束。
