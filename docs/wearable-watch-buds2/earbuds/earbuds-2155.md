# 耳机管理

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   耳机在表外，或表盖打开的状态下使用（向前轻推开盖键，表盖可自动弹开）。

## 手机管理耳机（HarmonyOS 4.3 及以下版本手机）

1.  进入华为运动健康应用设备详情页，点击耳机管理。
2.  在耳机管理页面，可进行以下操作： 可选择降噪、关闭和透传模式。 点击音质音效，可选择默认音效、低音增强、高音增强、清晰人声。 点击早问候，开启早问候后，每天上午首次佩戴耳机 5 秒无操作时，自动播报选定内容。 点击随心听，开启随心听后，无需打开手机，轻点三下耳机即可播放所设置的音频。 点击手势，可设置手势指令控制耳机，如“轻点两下，可接听/挂断通话”。 点击耳塞匹配，进行耳塞贴合度检测。 点击设置，可以打开/关闭左右耳机自适应、智能佩戴检测、语音唤醒等。开启语音唤醒功能后，唤醒词为“小艺小艺”，每次需要执行命令时，对耳机说“小艺小艺，......”，即可唤醒耳机。 可以通过语音唤醒询问天气、调节音量、切换上下首音乐等功能。

## 手表管理耳机

1.  在表盘界面下滑进入控制中心，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000001344753494.png"/>，进入耳机管理界面。
2.  向上滑动屏幕，可进行以下操作。 可选择降噪、关闭和透传模式。 点击EQ 音效，上下滑动屏幕，选定音效（如高音增强）。 点击更多设置，可打开/关闭左右耳机自适应开关、重置耳机、查看耳机的系统版本。
