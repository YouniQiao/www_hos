# 耳机配对连接新设备

耳机默认与手表连接同一手机，也可以与新的蓝牙设备（如手机、平板等）连接。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用前请将手表和耳机升级至最新版本。
+   耳机与新的蓝牙设备（如手机、平板等）蓝牙断开后，无法自动回连。

1.  让耳机进入可配对状态。 耳机在表内：向前轻推开盖键，表盖自动弹开后，长按手表侧按键 2s。 <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002508848393.png"/> 耳机在表外：在表盘界面下滑进入控制中心，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/zh-cn_image_0000002500143925.png"/>，进入耳机管理界面，点击更多 > 配对新设备。
2.  进入新设备（如手机、平板等）的蓝牙界面。点击新设备设置 > 蓝牙，在新设备搜索出的蓝牙设备中，点击耳机的蓝牙名称，完成配对。
