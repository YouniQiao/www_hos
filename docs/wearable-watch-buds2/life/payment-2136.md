# 支付宝支付

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   本设备操作指导视频中操作界面仅供参考，请以实际界面为准

将设备与支付宝应用绑定后，可以通过扫描设备上的二维码或条形码，完成支付。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   支付宝支付功能仅中国大陆版的设备支持。

## 绑定支付宝

1.  在设备应用列表中，点击支付宝，进入绑定码页面。
2.  在手机端打开支付宝应用，扫描设备上的二维码，根据提示绑定设备。
3.  根据支付宝界面提示，设置设备名称、扣款方式和每日支付上限，点击完成设置并开启，输入支付密码即绑定成功。
4.  绑定成功后，可在手机支付宝智能设备页面点击对应设备卡片，对设备支付进行管理。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   设备在与手机断连、无网、离线的情况下也可以完成支付。
+   使用设备付款的扣款顺序与手机支付宝本身设置的扣款方式顺序一致。
+   如果在绑定时没有修改设备在支付宝的名称，绑定完成后则不能修改设备名称，想要修改需要解绑重新绑定再修改。

## 扫码支付

当设备与支付宝应用绑定成功后并设置为卡片，购物时，只需在设备表盘界面左滑至支付宝付款码界面（或在设备应用列表点击 支付宝），向商家出示设备上的支付宝二维码或条形码（可切换展示支付二维码和支付条形码），商家通过扫码枪进行扫码，即可完成支付。

## 碰一下支付

+   在手表应用列表中，选择支付宝，点击碰一下，将手表屏幕紧贴收款设备碰一下即可付款。
+   从表盘顶部下滑进入控制中心，点击碰一碰，将手表屏幕紧贴收款设备碰一下即可付款。
+   在表盘界面左滑进入支付宝卡片，将手表屏幕紧贴收款设备碰一下即可付款。

## 解绑支付宝

可以通过以下两种方式解绑设备。

设备端解绑：

在设备应用列表中选择并进入支付宝，点击进入付款码界面，上滑屏幕，然后点击解除绑定。

手机端解绑：

在手机支付宝搜索框中，搜索智能设备并点击进入，选择目标设备，点击解除绑定，根据提示解除设备与手机支付宝的绑定。

或点击我的，选择右上角设置图标，点击支付设置 > 智能设备，选择您的设备，根据提示解除设备与手机支付宝的绑定。

解绑成功后，请在设备支付宝界面上滑屏幕点击解除绑定，完成设备端的支付宝解绑操作。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F1/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   如果之前在设备侧存入过零花钱，在设备侧解绑后零花钱不会自动退回，从手机支付宝中解除绑定设备后，零花钱自动退入当时的充值账户。
+   请妥善保管设备，如果设备不慎丢失，请立即在手机支付宝中解绑设备，避免被盗刷造成资金损失。
+   当手机支付宝与设备解绑后，设备仍会显示支付码，但支付功能实际上已失效。再次使用时，需要确保双侧都解绑后，重新绑定支付宝。
+   设备恢复出厂设置后，之前绑定的支付宝自动解除绑定。
