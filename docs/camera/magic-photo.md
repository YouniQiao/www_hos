# 魔法移图，智能生成合影

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044584_f008_Move.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

亲友合影缺一人？使用魔法移图，从其他照片快速抠取对象至本照片，智能粘贴到合适位置，一键融合光影，轻松生成大合照。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在**图库**中，选择要编辑的照片，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_edit.png" width="24" height="24" alt="编辑图标"/> > AI 修图 > 魔法移图。

2.  点击贴纸 > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_add.png" width="24" height="24" alt="添加图标"/>，选择目标照片，在**智能选择**模式下，在对象内部画线选中要抠取的对象，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_comfirm.png" width="24" height="24" alt="确认图标"/>，对象自动粘贴到推荐位置。您可以：

    +   拖动<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_move_tuiyi.png" width="24" height="24" alt="空间推移图标"/>，对象在 3D 空间中移动，并根据位置推移智能变换尺寸。

    +   点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_move_layer.png" width="24" height="24" alt="图层图标"/>，长按并拖动图层，调整对象图层的前后顺序。

3.  点击**一键合成**，待生成新照片后，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_settings_save.png" width="24" height="24" alt="保存图标"/>，根据提示保存照片。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

如需编辑本照片对象，可通过**智能选择**或**手动涂抹**选中要抠取的对象，识别选区后即可进行移动、旋转、缩放、复制等操作。
