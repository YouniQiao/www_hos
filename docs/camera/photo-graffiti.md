# 涂鸦新体验，还能一键还原

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/20005895_f002_galleryedit.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

您可以在图片上，用各种涂鸦笔触轻松画出标准图形，给图片添加文字，或是用马赛克笔涂抹隐私信息。保存图片后，还能一键恢复原图。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

在图库中选择图片，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_edit1.png" width="24" height="24" alt="编辑图标"/>进入编辑界面：

+   点击**涂鸦**，您可以选择不同笔触和颜色进行创作。用手指一笔画出图形并停顿片刻，可快速生成标准图形。

+   点击**文字**，您可以先点击**文本框**，选择**默认文字**或其他文本框样式，输入想添加的文字内容；再点击**样式**，调整文本颜色和字体大小。

+   点击**马赛克**，您可以给图片添加马赛克。

图片保存后，如需修改重做，可点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_edit1.png" width="24" height="24" alt="编辑图标"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_restore_edit.png" width="24" height="24" alt="恢复图标"/>恢复为原图。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用该功能前，请将您的设备升级到最新版本。
