# 一键沾色，快速调整图片色调

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044584_f011_Colors.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

使用沾色功能，将喜欢的色调一键“沾”到自己的图片，轻松体验多种色调风格，让图片更出彩。逆光人物图还可一键变为剪影效果，更具氛围感。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在图库中打开想要调整色调的照片，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_edit.png" width="24" height="24" alt="编辑图标"/> > AI 修图 > 沾色。您可以：

    +   应用推荐色调：点击**灵感推荐**应用推荐色调，再次点击，可更换推荐色调。

    +   应用参考图色调：点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_add.png" width="24" height="24" alt="添加图标"/>，选择参考图后，点击**添加**。

2.  色调应用后，左右滑动滑块，可调节色调强度。

3.  点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_settings_save.png" width="24" height="24" alt="保存图标"/>，根据提示保存照片。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   如需生成剪影效果，建议使用逆光、人物主体占比较小、人物比背景区域暗的图片。部分适合剪影效果的场景（如：日出日落、夜景、烟花、晚霞、海景等），**灵感推荐**将优先推荐剪影效果。

+   您可添加多张参考图，下次沾色时仍可继续使用。长按已添加的参考图，可删除或重命名色调。
