# 更换壁纸

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_settings_wallpaper.png" alt="" width="720" height=""/>

您可挑选喜欢的图片，设置为锁屏和桌面壁纸，使您的电脑桌面与众不同。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在电脑桌面，右键单击空白处，选择编辑壁纸。

2.  从预置壁纸中单击喜欢的图片设为壁纸。部分预置壁纸为动态壁纸（图片左下角有动态标识![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/circle_live_wallpaper.png)），使用此类壁纸，可在锁屏界面欣赏持续播放的动态效果，或双击桌面互动。

3.  您也可以单击添加图片，从图库或文件管理选择喜欢的图片设为壁纸。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   部分预置动态壁纸不支持双击桌面互动，请以实际情况为准。

+   并非所有图片格式都可设为壁纸，若添加图片时未显示想要选择的图片，可能是不支持该图片格式，请以实际情况为准。
