# 查看和优化存储空间

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_StorageUsage.png" alt="" width="720" height=""/>

您可查看电脑存储空间的使用情况，并根据需要清理应用的缓存数据或卸载不常用的应用，优化电脑的可用存储空间。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的存储，然后在右侧界面查看存储空间的使用情况。

2.  单击某应用可进入详情界面，查看该应用占用的存储空间情况。

3.  根据需要，单击清空缓存或卸载，释放其占用的存储空间。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   部分应用不支持卸载，请以实际情况为准。

+   卸载应用前，请提前将重要数据进行备份。
