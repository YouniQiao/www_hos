# 通信防护，守护通话安全

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_FaceSwap_Check.png" alt="" width="720" height=""/>

通信防护，可在视频或语音通话时智能检测诈骗话术、换脸或变声痕迹等风险，并弹出风险提示，帮您防范潜在的诈骗风险。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的隐私和安全。

2.  在右侧界面，单击**星盾防诈** > **通信防护**，然后单击开启视频通话时检测、语音通话时检测的开关。

3.  开启后，进行视频或语音通话时将自动检测人脸、语音信息，当检测到对方可能存在 AI 换脸、 AI 变声等风险时，通过弹框提示风险。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   部分应用可能不支持通信防护，请以实际情况为准。

+   检测过程仅在设备本地完成，不会将个人信息上传至云端。
