# 应用锁，保护应用隐私数据

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_AppLock.png" alt="" width="720" height=""/>

为文件管理、邮件、备忘录等重要办公应用添加应用锁，通过身份认证后才可进入，防止他人未经允许访问。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_settings.png)打开设置，单击左侧边栏的隐私和安全。

2.  在右侧界面，单击**应用锁** > **开始使用**。首次开启时，需设置锁屏密码或隐私密码作为验证密码，当人脸、指纹无法使用时，可通过密码进入。

3.  通过以下任一方式添加应用锁：

    +   单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_allapps.png)进入应用中心，选中要加锁的应用图标，右键选择添加应用锁。

    +   进入**设置** > **隐私和安全** > **应用锁**，通过身份验证后，单击打开要加锁的应用开关。

4.  添加成功后，单击加锁应用，需通过身份验证后（密码、指纹或人脸识别）才可进入。若您的设备支持指纹、人脸且已录入，验证时将优先支持人脸或指纹进行验证。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   默认应用最小化后上锁，再次单击应用需通过身份验证。您也可以进入**设置** > **隐私和安全** > **应用锁**，在上锁设置的下拉选项中，选择应用关闭后上锁。

+   仅部分机型支持人脸识别，请以实际情况为准。
