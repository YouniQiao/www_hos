# 加密文件，分享指定授权人

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_FileManager_EncryptedShare.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

重要文件只希望给指定授权人查看时，您可使用**加密分享**，为文件设置访问权限，还可限制查看有效时长，保护信息安全。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

使用此功能前，请先登录**华为账号**。

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_allapps.png)进入应用中心，单击打开待分享内容所在的应用（如文件管理、图库）。

2.  选中单个或多个要加密的文件，右键选择**分享** > **加密分享**。

3.  单击添加可查看的用户，输入目标授权人华为账号绑定的手机号/邮箱后单击搜索华为账号，或单击从通讯录中选择选中目标联系人后单击完成。

4.  在加密分享设置界面，根据需要选择文件查看有效时长（发送方华为账号不受有限时长限制），还可开启水印保护。

    +   永久：仅目标授权人可打开，打开次数不限。

    +   仅可查看一次：仅目标授权人可在首次打开，关闭文件预览应用后，无法再次打开。

    +   限定时长：打开文件后，目标授权人仅可在限定时间内查看，查看时间归零或关闭文件预览应用后，无法再次查看。

5.  单击去分享加密成功后回到分享界面，选择华为分享、畅连等方式将加密文件分享给指定授权人。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   仅 HarmonyOS 5 及以上版本设备支持查看加密文件，加密文件内容不支持截屏和录屏。

+   仅 HarmonyOS 6.1 及以上版本设备支持添加、查看水印保护效果和设置加密文件的查看限定时长。

+   并非所有文件格式支持加密，请以实际情况为准。
