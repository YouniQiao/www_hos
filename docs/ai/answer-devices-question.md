# 有问题找小艺，功能咨询更方便

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/video/10044717_f011_celiacontrol.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

使用平板的过程中有疑问？让客服小艺智能体为您解答。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

在主屏幕右滑进入**负一屏**，找到**有问题找小艺**卡片，点击**前往咨询**后进入**客服小艺**智能体。

您可通过语音或者文字输入进行咨询：

+   询问产品功能、使用技巧等，例如：“HarmonyOS 7 有什么黑科技功能”。

+   进行耗电、发热、电池等多项检测，例如：“我想知道哪个应用最耗电，帮我检测下”。

+   查询本机相关权益内容及有效期，例如：“华为服务日是什么”。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

为了更好地体验小艺新功能，请在应用市场将小艺应用更新至最新版本。
