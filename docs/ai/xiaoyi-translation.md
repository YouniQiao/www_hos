# 小艺翻译，打破跨国沟通障碍

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/video/10104441_f011_CeliaTranslate.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

出国旅游、国际会议语言不通怎么办？小艺翻译帮您跨国沟通无障碍。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  长按屏幕底部导航条，唤醒小艺，说“打开小艺翻译”。

2.  进入智能体后，您可选择所需的翻译功能：

    +   点击面对面翻译、同声传译、拍照翻译、文档翻译等功能，可进入对应的专项翻译功能。

    +   点击底部对话框进入翻译界面，通过对话进行翻译，例如“早上好用法语怎么说”。

    +   点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/ic_historyclock.png" width="24" height="24" alt="历史图标"/>可查看翻译历史。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

为了更好地体验小艺新功能，请在应用市场将小艺应用更新至最新版本。
