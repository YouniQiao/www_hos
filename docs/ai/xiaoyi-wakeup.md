# 随时随地一步唤醒小艺，操作更便捷

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/video/10044717_f010_AIVoice.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

随时随地一步唤醒小艺，操作更便捷。还可与小艺视频对话，让小艺陪您看世界。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

长按屏幕底部导航条，可快速唤醒小艺。用语音或文字向小艺发出指令，如：“今晚7点有约会，帮我设个闹钟”。

唤醒小艺后，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/ic_celiacamera1.png" width="24" height="24" alt="视频图标"/>还可进入小艺看世界，与小艺实时视频互动，如：“帮我看看这套衣服搭配什么鞋子比较好”。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   使用三键导航时，可通过长按电源键、语音唤醒等方式唤醒小艺。

+   为了更好地体验小艺新功能，请在应用市场将小艺应用更新至最新版本。
