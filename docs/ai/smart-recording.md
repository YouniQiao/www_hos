# 智能录音，摘要导图一键呈现

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044773_f003_Smart_Recording.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

在会议、访谈中使用智能录音，录音即时转写为文本，还能自动生成摘要和思维导图，关键信息清晰梳理。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  打开**录音机**，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_record_start.png" width="24" height="24" alt="开始图标"/>启动录音，点击**智能转写**，录音内容将实时转写文本。

2.  录音完成后，点击录音文件进入详情界面，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_Hexagram_star.png" width="24" height="24" alt="录音智能图标"/>，您可以：

    +   点击**摘要**，可选择**通用**、**会议纪要**、**知识笔记**、**访谈记录**等风格。

    +   点击**思维导图**，自动结合录音内容生成思维导图，支持导出为图片或 Xmind 格式。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

录音智能转写内容少于 200 个字符时，暂不支持生成摘要和思维导图。
