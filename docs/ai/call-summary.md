# 通话摘要，大事小事都能记

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10217074_f001_callsummary.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

电话沟通中信息太多记不住？使用通话摘要功能，从日常生活到职场工作，每次通话的关键信息都能轻松记录，让您沟通更专注。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  通话时，在通话界面点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_AIplaintext.png" width="24" height="24" alt="通话摘要图标"/>，通话结束后将自动生成通话摘要。

2.  您可通过以下任一方式查看通话摘要：

    +   从屏幕顶部左侧下滑出通知中心，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_celiacall.png" width="24" height="24" alt="摘要详情图标"/> 进入可查看摘要详情。

    +   打开**电话**，在本次通话记录上点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_callsummary.png" width="24" height="24" alt="记录详情图标"/>，点击摘要概述可查看摘要详情。

    +   进入备忘录 > 来自其他应用 > 来自通话摘要，选择本次通话，可查看摘要详情。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用前，请进入电话 > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_AITouchmore.png" width="24" height="24" alt="更多图标"/> > 设置 > 小艺通话，打开**小艺通话**开关；或者在通话时点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_AIplaintext.png" width="24" height="24" alt="通话摘要图标"/>，同意弹窗的相关授权和协议，即可开启**通话摘要**功能。
