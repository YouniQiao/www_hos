# 全新小艺修图，一站式创作

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/video/10104441_f010_celiaps.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

拍照遇上阴天、路人乱入影响出片？试试全新小艺修图，一句话换背景、消路人，生成创意大片。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  打开**小艺**应用，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/Menu.png" width="24" height="24" alt="菜单图标"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/ic_search.png" width="24" height="24" alt="查找图标"/>，搜索“小艺修图”并进入。

2.  在底部快捷菜单，根据需要选择创作方式，如“**小艺修图**”，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/ic_add_plus.png" width="24" height="24" alt="添加图标"/>上传图片。

3.  在对话框输入修图指令并发送，例如“背景换成蓝天”、“老照片修复”、“消除路人”等，即可生成。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612281hYjqb/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   小艺修图还支持按模板生成同款、根据文字生成图片。

+   为了更好地体验小艺新功能，请在应用市场将小艺应用更新至最新版本。
