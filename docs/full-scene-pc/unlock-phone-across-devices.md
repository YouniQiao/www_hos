# 跨设备解锁手机

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_pc_unlock_phone.png" alt="" width="720" height=""/>

电脑和手机协同连接后，若手机屏幕锁定，可直接在电脑端通过手机锁屏密码、电脑录入的人脸或指纹，轻松解锁手机。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在手机、电脑上，开启 WLAN、蓝牙，并登录同一华为账号。

2.  在电脑上，单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_controlcenter_icon.png)或点按（键盘上）鸿蒙键![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png) + C 组合键，打开控制中心。

3.  在超级终端中单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_superdevice.png)，然后在设备列表中单击待连接的手机，发起协同连接。

4.  协同连接后，手机屏幕锁定时，可在电脑端的手机镜像主窗口中选择解锁方式：

    +   密码解锁：单击使用手机锁屏密码，输入手机锁屏密码解锁手机。

    +   生物识别解锁：单击使用电脑录入的人脸或指纹，根据电脑端人脸、指纹的输入情况，通过人脸识别或指纹验证解锁手机。首次使用，需输入手机锁屏密码进行授权，授权后手机将自动解锁。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   使用生物识别解锁，要求协同的电脑、手机系统版本为 HarmonyOS 7.0 及以上。若电脑端未录入生物信息（人脸、指纹），或手机端未设置锁屏密码，或手机端开启隐私空间，则不支持生物识别解锁手机。

+   若电脑端同时录入了人脸和指纹，使用生物识别解锁时优先进行人脸识别解锁。

+   仅部分机型支持人脸识别，请以实际情况为准。
