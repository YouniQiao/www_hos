# 外接显示器，畅享双屏体验

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_projection_DesktopMonitor.png" alt="" width="720" height=""/>

通过线缆或转接器将显示器与电脑连接，实现双屏操作，畅享大屏办公体验的同时，轻松处理各项事务。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在电脑亮屏解锁状态时，通过直连线缆或转接器转接线缆，将显示器与电脑连接，然后接通显示器的电源并打开。

2.  连接成功后，显示器屏幕将显示电脑的系统桌面。首次接入，显示器默认作为电脑的扩展屏幕。

3.  您也可以根据需要，单击桌面右下角<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_chevron_up.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_screencast_management.png" width="24" height="24"/>进入投屏管理界面，切换显示方式：

    +   主显示器：外接显示器将作为主显示器，电脑屏幕作为扩展显示屏。

    +   扩展显示器：外接显示器作为电脑的扩展屏幕，可在电脑和显示器打开不同的应用窗口，双屏操作。

    +   本机屏幕的镜像：外接显示器与电脑显示相同内容并实时同步。

    +   仅在外接显示器显示：外接显示器显示电脑屏幕内容，电脑屏幕自动关闭。

4.  若要断开电脑与显示器的链接，移除连接的线缆或转换器，也可直接将显示器关机。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

设备型号不同，接口存在差异，请根据设备接口准备连接的线缆或转接器。
