# 超级终端，快速协同多设备

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_SuperDevice_trag.png" alt="" width="720" height=""/>

使用**超级终端**，快速发起协同，体验丰富的多设备协同场景。例如：电脑协同手机，跨屏编辑更方便；电脑协同耳机，音乐轻松流转。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

以手机与电脑协同为例：

1.  在手机、电脑上，开启 WLAN、蓝牙，并登录同一华为账号。

2.  在发起连接设备上，打开控制中心，然后在超级终端中单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_superdevice.png)。

    +   手机：从顶部右侧下滑出控制中心。

    +   电脑：单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_controlcenter_icon.png)或点按（键盘上）鸿蒙键![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png) + C 组合键，打开控制中心。

3.  在超级终端界面的设备列表中，单击想要协同连接的设备名称，即可发起协同。
