# 小艺深度解题，您的智能助教

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_AI_Celia_ProblemAnalysis.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

**深度解题**可为您深度解析、提供详细解题思路，也可以通过引导式解题启发自主思考，助您高效学习。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)，打开小艺侧边窗。

2.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，并单击左侧边栏的深度解题。

3.  在右侧界面，单击截屏快答，然后截取试卷题目并单击去解答。您也可以单击选择 AI 互动讲解，开启引导式解题。

4.  解答完成后，您还可以根据需要，执行以下操作：

    +   单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_copy.png)，将解题过程粘贴至其他应用（如备忘录）。

    +   单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_share.png)，选择图片保存至其他应用（如图库）。

    +   单击右侧添加错题，将题目添加至错题本，方便后续重复查看。仅截屏快答模式支持。

    +   根据界面 Tips 提示，继续下一步操作，如选择换种解题方法、继续下一题。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用该功能前，请将您的设备升级到最新版本。
