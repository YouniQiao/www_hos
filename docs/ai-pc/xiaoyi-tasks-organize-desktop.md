# 小艺任务，自动整理桌面

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_AI_CeliaTask_arrange.png" alt="" width="720" height=""/>

小艺任务可执行文件智能分类、内容提取、重名文件清理等操作，帮您智能管理电脑桌面。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)，打开小艺侧边窗。

2.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，在新对话右侧界面，单击切换到任务页签。

3.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_mic.png)发送语音或输入文字后点按 Enter 键发送，向小艺发送任务指令。以下是部分场景的任务指令示例：

    +   文件整理：例如“帮我按文件类型、内容整理桌面”、“帮我把桌面所有图片放到‘图片素材’并按每周时间分开归档”。

    +   文件内容识别：例如“帮我把桌面的简历文件统一重命名为‘姓名-申请岗位-工作年限’，并按岗位归类到文件夹”

    +   文件清理：例如“帮我删除桌面重名文件”、“帮我删除桌面去年的文件”。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用该功能前，请将设备和小艺应用都升级到最新版本。
