# 小艺卡片，一键直达智能体

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_AI_Celia_Card.png" alt="" width="720" height=""/>

将常用的小艺智能体以卡片形式添加至桌面，以便快速进入并使用智能体。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

通过以下方式将小艺智能体卡片（如深度研究、文档助理、小艺翻译等）添加至桌面：

+   在电脑桌面，右键选择添加卡片，在左侧边栏找到小艺，然后在右侧单击想要添加的卡片，单击完成。仅部分智能体支持此方式添加卡片至桌面。

+   单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)打开小艺侧边窗，并单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，在左侧边栏单击某个功能项或单击智能体广场搜索并进入某个智能体，然后单击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_more_1.png" width="24" height="24"/> > **添加至桌面**，即可添加该智能体卡片至桌面。
