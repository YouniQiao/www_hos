# 魔法移图，智能生成合影

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_gallery_AIretouch_move.png" alt="" width="720" height=""/>

使用魔法移图，从其他照片快速扣取对象至本照片，智能粘贴至合适位置，一键融合光影，轻松生成合照。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_gallery.png)，打开图库。您也可以单击桌面底部![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_allapps.png)进入应用中心，单击打开图库。

2.  双击待编辑的图片进入详情界面，然后单击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_edit_pencil.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_notes_AIsummary.png" width="24" height="24"/>进入 AI 修图界面。

3.  单击魔法移图展开功能选项，单击贴纸，选择目标照片。

4.  在智能选择模式下，在对象内部画线选中要扣取的对象，单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_ok.png)后对象将自动粘贴到推荐位置。您可以：

    +   移动对象位置：光标移至对象区域，单指长按触控板（或鼠标左键）并移动，将对象移至指定位置。

    +   调整对象大小：光标移至对象四角边缘，单指长按触控板（或鼠标左键）并移动，拖拽调整对象尺寸。

5.  调整完成后，单击一键合成，等待图片合成。

6.  生成新的图片后，单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_save.png)，可选择另存为或覆盖原图保存。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用该功能前，请将您的设备升级到最新版本。
