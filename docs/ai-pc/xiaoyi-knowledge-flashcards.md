# 小艺知识闪卡，助您记忆学习

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_AI_Celia_Memory_flashcard.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

**知识闪卡**可将重要知识点转换为问题和答案的形式呈现在一张张知识卡片上，助您重复练习、强化记忆。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)，打开小艺侧边窗。

2.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，并单击左侧边栏的小艺帮记。

3.  在右侧界面，单击右上角添加知识，将待转换的文件添加至小艺帮记。

4.  单击下方知识闪卡进入生成知识闪卡界面，选择生成的卡片数量、卡片类型，然后单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_add.png)选择待转换的文件并单击确认。

5.  返回生成知识闪卡界面，再次单击确认，等待知识闪卡生成（预计 1~3 分钟）。

6.  闪卡生成后，单击可进入详情界面开始答题，根据对闪卡内容的掌握情况进行对应操作。答题结束后，将自动统计并生成您的学习掌握情况。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

使用该功能前，请将您的设备升级到最新版本。
