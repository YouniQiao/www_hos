# 小艺任务，自动执行预设任务

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/figure/fig_AI_CeliaTask_autotasks.png" alt="" width="720" height=""/>

小艺任务可执行预设好的任务指令，帮您完成日常中一些重复性、周期性的操作，如每周的工作周报总结、每周例会提醒、定时设备操控等。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)，打开小艺侧边窗。

2.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，在新对话右侧界面，单击切换到任务页签。

3.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_mic.png)发送语音或输入文字后点按 Enter 键发送，向小艺发送预设任务指令。例如：“每周一上午帮我整理上周的工作周报”，“工作日晚上开启深色模式”。

4.  任务创建后，可单击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_more_1.png" width="24" height="24"/> > **自动任务**，查看所有任务。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   使用该功能前，请将设备和小艺应用都升级到最新版本。

+   小艺任务可深度融合领域 AI 能力，您可根据需要，在任务界面单击 Skills市场进入详情界面，获取对应的 Skill 智能体。
