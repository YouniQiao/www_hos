# 智能分类，指定文件自动归类

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_FileManager_SmartCollections.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

使用**智能分类**，将符合共同条件的文件自动归类，方便快速查看。添加、修改或删除复合条件的文件时，**智能分类**中的文件列表将自动更新。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面底部快捷栏中的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_filemanager.png)，打开文件管理。

2.  单击左边栏的智能分类，然后在右侧界面单击新建智能分类，或单击左上角**新建** > **智能分类**。

3.  在创建智能分类界面，输入分类名称后，单击新增设置分类条件（如关键词，文件类型、文件名等）。如有需要，可单击新增添加多个条件。

4.  设置完成后，单击创建智能分类。
