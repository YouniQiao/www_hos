# 小艺帮记，您的专属知识管家

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/video/vid_AI_Celia_Memory.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

**小艺帮记**可以协助您高效管理电脑上的本地数据、海量网络信息与知识等，为您提供知识智能分类、AI 问答、AI 播客等服务，让沉淀积累的知识发挥更大的价值。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  单击桌面右下角![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/icon/appicon_xiaoyi.png)，打开小艺侧边窗。

2.  单击![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_window_xiaoyi_maxmize_2.png)进入小艺应用窗，并单击左侧边栏的小艺帮记。

3.  在右侧界面，您可通过以下任一方式，收藏知识并归类：

    +   单击右上角添加知识，选择想要添加的内容，如文件、链接、图片等。添加的内容在完成解析后将自动归类到已有的合集中。

    +   单击已有的合集进入详情界面，然后单击添加知识。

    +   单击创建合集区域的![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/zh-cn/image/common/buttons/HM_public_add.png)新建合集，输入合集名称、简介并开启智能关联的开关，然后点击确认。在新建的合集界面，单击添加知识。

4.  知识添加完成后，可根据需要输入问题，然后点按 Enter 键发送，让小艺基于帮记内容进行解答。
