# 亲密圈，时刻关心亲友

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/20013690_f001_MyCircle.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

在**亲密圈**中为亲友创建专属卡片，您可与亲友共享运动健康数据、建立远程守护关系，守护亲友的健康与安全。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  进入设置 > 华为账号，点击**亲密圈**卡片。

2.  首次使用时，点击添加成员 > 添加家人和挚友，按界面提示添加成员。如已添加过成员，可点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_personbadge.png" width="24" height="24" alt="添加成员图标"/>添加其他成员。

3.  设置成员信息后，您可自定义成员卡片，如添加**共享健康数据**、**远程守护**等服务。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   如需添加宠物成员，您可在添加成员时选择**添加宠物**，按界面提示添加。

+   点击成员头像进入详情页，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_hiden_more.png" width="24" height="24" alt="更多选项图标"/> > **添加桌面卡片**可将成员卡片添加至桌面，点击**移除成员**可按提示删除该成员。
