# 智感护眼，守护用眼健康

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/20006187_f001_Smart_eye_protection.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

智能检测用眼行为、眼部疲劳状态，并及时提醒休息，守护您和家人的用眼健康。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

进入设置 > 健康使用设备，开启**智感护眼**，以下守护自动开启：

+   **疲劳状态分析**：自动检测眼部疲劳状态，适当提醒休息，引导放松训练。

+   **用眼习惯提醒**：及时提醒不良用眼行为，如**屏幕距离过近**、**环境光过暗**等。

+   **健康护眼显示**：护眼模式**智能开启**，根据视疲劳状态自动调节屏幕显示。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   首次开启健康使用设备时，**智感护眼**功能默认开启。

+   您还可通过建立**远程守护**关系或开启**未成年人模式**，为孩子开启此功能。
