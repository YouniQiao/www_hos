# 全新沉浸光感，让界面更通透

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612220zjZV2/zh-cn/image/video/10044742_f001_Transparency.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

沉浸光感视效全面升级，在桌面大文件夹、通知、控制中心等界面操作时，您可以体验更清透的界面、跟随指尖移动变化的光影，以及富有弹性的动态视效。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612220zjZV2/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

进入设置 > 桌面和个性化 > 沉浸光感，选择不同程度的沉浸光感效果。效果越强，通透质感与光效越显著。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202612220zjZV2/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

不同档位支持的沉浸光感视效可能不同，请以实际为准。
