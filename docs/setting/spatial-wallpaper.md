# 3D 空间壁纸，体验空间美学

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/video/10044758_f016_Spatial_wallpaper.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

设置 3D 空间壁纸，体验透视时钟与壁纸的自然融合，感受全新空间美学的视觉效果，让您的锁屏与众不同。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  进入设置 > 桌面和个性化 > 壁纸，您可以：

    +   在 **3D 空间壁纸**下，选择预置的**空间时钟**壁纸，可自动生成空间时钟样式。

    +   点击**从图库选择**，挑选合适的壁纸，画面中含有适当倾斜、连续不中断且笔直延伸的景物边缘时，可更好地生成空间时钟样式。

2.  在壁纸编辑界面，您可以：

    +   拖动壁纸调整位置，双指开合缩放壁纸大小。

    +   长按并拖动时钟调整位置，拖拽时钟顶部或底部边框的<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/common/buttons/ic_3dclock07.png" width="24" height="24" alt="上下边框图标"/>调整高度。

3.  点击应用 > 确定，完成设置。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   首次使用此功能时，请根据提示下载空间计算模型。

+   当前仅静态壁纸支持生成具有景深或透视效果的空间时钟（如 <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/common/buttons/ic_3dclock04.png" width="24" height="24" alt="空间时钟图标"/>、<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606150sYodg/zh-cn/image/common/buttons/ic_3dclock05.png" width="24" height="24" alt="空间时钟图标"/>），请以实际体验为准。
