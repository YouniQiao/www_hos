# 互动萌宠主题，萌趣无处不在

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202607231huhgy/zh-cn/image/video/10044758_f003_adorableanimals.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

设置萌宠主题，让可爱的小猫小狗时时陪伴您，闲暇时刻还可在桌面和锁屏界面与萌宠进行趣味互动。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202607231huhgy/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  进入设置 > 桌面和个性化 > 更多主题，在**互动萌宠**中选择喜欢的萌宠，例如小猫绵绵。

2.  点击**自定义**，可更换萌宠的毛发颜色、性格和主题背景。

3.  点击**应用**后，您可通过以下方式体验互动乐趣：

    +   桌面：在可容纳萌宠的桌面空白处单击，萌宠跳跃至点击位置，点击萌宠，可进行互动小游戏。

    +   锁屏界面：点亮屏幕后，点击萌宠、空白区域，或对萌宠招手（掌心朝向屏幕向下挥动）、隔空比心，萌宠将给出有趣回应。锁屏时收到通知，或上滑音乐胶囊，也可触发萌宠动效。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202607231huhgy/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

首次使用该主题时，点击**去应用**加载主题。
