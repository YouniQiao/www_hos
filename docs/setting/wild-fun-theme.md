# 野趣憨憨，解锁互动新玩法

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044753_f012_countryfieldfluffy.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

为萌主换上专属套装，从锁屏到桌面，萌主会卖萌能陪伴，多样互动，处处充满小惊喜。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  进入设置 > 桌面和个性化，点击**更多主题**，在**舞林萌主**中选择**野趣憨憨**。

2.  点击**自定义**进入编辑，选择喜欢的套装，例如光感菠萝套装。

3.  点击**应用**，您可与憨憨进行趣味互动：

    +   桌面：憨憨会划屏跟随，点击憨憨会在应用图标、卡片或文件夹之间跳跃。

    +   锁屏：戳一戳憨憨，会做出生动的表情动作；晃动手机，憨憨呈现碰撞弹跳动效。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   部分机型首次使用该主题时，请点击**去应用**加载主题。

+   不同机型支持的萌主套装有差异，请以实际为准。
