# 加密文件，分享指定授权人

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/20005748_f001_EncryptedSharing.png" alt="" width="560" height=""/>

有私密图片、视频、音频或文档，希望只给指定授权人查看？您可以使用加密分享，为文件设置访问权限，还可限制仅可查看一次。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在**文件管理**、**图库**或**录音机**中，选中单个或多个要加密的文件，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/ic_gallery_share.png" width="24" height="24" alt="分享图标"/>，选择**加密分享**，根据界面提示添加可查看的华为账号用户。

2.  在添加用户界面，可设置文件查看有效期为**永久**、**仅可查看一次**或限定时长，还可开启**水印保护**。

    +   **永久**：仅目标授权人可打开，打开次数不限。

    +   **仅可查看一次**：目标授权人仅可在首次打开文件，关闭**文件预览**应用后，无法再次打开。

    +   限定时长：打开文件后，目标授权人仅可在限定时间内查看，查看时间归零或关闭**文件预览**应用后，无法再次查看。

3.  点击**去分享**生成新的加密文件。

4.  回到分享界面，选择**华为分享**、**畅连**等途径继续分享。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   仅 HarmonyOS 5 及以上版本设备支持查看加密文件，加密文件不支持截屏和录屏。

+   仅 HarmonyOS 6.0.0.328 SP52 及以上版本设备支持添加、查看**水印保护**效果和设置文件查看限定时长。

+   并非所有文件格式支持加密，请以实际为准。
