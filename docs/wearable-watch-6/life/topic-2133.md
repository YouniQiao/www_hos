# 实况窗管理

手表实况窗可以同步显示华为手机的实况窗信息，为您提供贴心的实况提醒服务，随时掌握当前任务的实时信息。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用实况窗功能，请确保手表已升级至最新版本。
+   实况窗功能仅支持配对 HarmonyOS 4.0 及以上版本的华为手机时使用，不支持三方安卓及iOS手机。

## 开启实况窗

1.  在穿戴设备应用列表中，点击设置 > 表盘和桌面 > 实况窗，开启实况窗开关。
2.  在手机华为运动健康的设备详情页，点击通用设置 > 实况窗， 打开手机实况窗信息同步至手表实况窗开关。

## 查看实况窗消息

开启后，当有新任务时，实况窗会实时显示任务的概要信息。任务结束后，实况窗自动消失。

+   在手表表盘界面上滑进入消息中心，点击实况卡片可进入实况通知详情页，查看对应实况通知详情。
+   当有多个任务时，在手表表盘界面上滑进入消息中心，实况窗会堆叠显示，点击堆叠卡片可展开所有实况卡片。
+   在手表表盘界面的屏幕下半屏，向下滑动可闭合实况窗。表盘实况窗手动下滑闭合隐藏后，再次在表盘界面上滑进入消息中心后，返回表盘实况窗可再次弹出。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/zh-cn_image_0000002579558644.jpg"/>

## 删除实况窗消息

+   点击手表实况窗实况信息，进入实况窗消息列表，左滑待删除消息，点击删除按钮即可。
+   在手机上删除对应实况消息，手表侧实况消息同步删除。
