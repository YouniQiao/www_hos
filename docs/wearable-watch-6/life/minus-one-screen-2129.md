# 使用和管理负一屏

在负一屏中，您可查看天气信息、控制音乐播放、添加卡片等，为您生活带来更便捷的服务。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   智能情景推送，仅支持与EMUI 11.1/HarmonyOS 2.0及以上版本华为手机配对时使用。

## 开启/关闭负一屏

1.  单击手表上键，在手表应用列表中，点击设置 > 表盘和桌面 > 负一屏。
2.  开启/关闭负一屏开关。负一屏开关开启后，在手表表盘界面，向右滑动屏幕，进入负一屏，向左滑动屏幕，退出负一屏。 负一屏开关关闭后，在手表表盘界面右滑不再显示负一屏。

## 快速进入应用

1.  在手表表盘界面右滑，进入负一屏。
2.  点击负一屏的某个卡片，可进入对应应用详情页。

## 音/视频播控中心

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   视频播控仅支持与初始版本为HarmonyOS 5.1及以上版本的华为手机连接时使用。
+   手表负一屏播控中心控制手机音/视频应用功能仅支持在手机播控中心显示正在播放的音/视频应用。由于部分应用未适配手机播控中心，若手机侧播控中心显示无法控制，则在手表侧同样不能控制。

可通过负一屏的音/视频播控中心卡片，控制手机和手表的音/视频播放。控制手机音/视频时，须手表和手机正常连接且手机正在播放音/视频。

## 使用音/视频感知场景卡片

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与初始版本为HarmonyOS 5.1及以上版本的华为手机连接使用时，手表侧支持此功能。
+   场景卡片无法关闭。

在手表表盘界面，当您使用手机播放音/视频时，且手机的播控中心也支持播控音/视频时，⼿表会⾃动弹出音/视频控制的场景卡⽚，提醒您使用手表的音/视频控制功能。

## 负一屏管理

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   负一屏管理的编辑功能仅在全能模式下支持，在省电模式下没有编辑按钮。

添加卡片

1.  在手表表盘界面右滑，进入负一屏。
2.  向上滑动至最后一页，点击下方的编辑，进入板块管理页面。
3.  向上滑动至最后一页，点击我的卡片管理，进入我的卡片管理页面。
4.  向上滑动至最后一页，点击添加卡片，根据需要选择添加卡片。

置顶/删除卡片

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   音乐卡片是常驻卡片无法删除。

1.  在手表表盘界面右滑，进入负一屏。
2.  长按负一屏的某张卡片，根据需要置顶、取消置顶或删除卡片。也可以在负一屏向上滑动至最后一页，点击下方的编辑，进入板块管理页面，向上滑动至最后一页，点击我的卡片管理，进入我的卡片管理页面，根据需要置顶、取消置顶或删除卡片。
