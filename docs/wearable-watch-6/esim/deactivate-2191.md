# 中国联通用户注销独立号码

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   手机升级 HarmonyOS 5 及以上版本后该功能暂不支持，请您耐心等待功能适配，感谢理解！
+   部分地区暂不支持开通及注销业务，详情请咨询10010。

注销独立号码业务需要先前往中国联通营业厅注销业务，再在手表端删除eSIM配置文件。

1.  前往中国联通营业厅注销eSIM独立号码业务。
2.  点击手表上键，在应用列表中选择设置 > 移动网络 > eSIM 管理 > 设置。
3.  在设置页面点击重置，根据界面提示完成重置，删除eSIM相关配置文件。
