# 双模式切换

手表支持切换全能模式和省电模式。全能模式下，手表拥有完整的体验；在省电模式下，可提升续航时间，但是部分功能不可用。

## 开启省电模式

全能模式下，在表盘界面从顶部下滑进入控制中心，点击省电模式，退出全能模式，进入省电模式。

## 开启全能模式

省电模式下，在表盘界面从顶部下滑进入控制中心，点击全能模式，退出省电模式，进入全能模式。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   当您的手表电量低于一定阈值时，会自动切换到省电模式；充电至电量高于一定阈值时，也会自动切换到全能模式。
