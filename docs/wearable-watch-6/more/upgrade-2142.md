# 升级版本

## 在手表侧升级

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   升级前，请确保手表连接网络。
+   穿戴产品系统版本升级提示不支持关闭，不支持版本回退。

1.  单击手表上键，在应用列表中点击设置，进入设置页面。
2.  点击设备的名称（如，HUAWEI WATCH XXX），进入关于手表页面。
3.  点击检查更新，根据提示完成软件版本更新。

## 在手机侧升级

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FO/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   iOS手机不支持在手机侧升级，无固件更新的选项。

在华为运动健康的设备详情页，点击通用设置 > 固件更新，手机将检测手表的版本更新信息，请根据提示进行更新操作。
