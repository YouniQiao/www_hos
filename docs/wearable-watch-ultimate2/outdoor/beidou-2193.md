# 北斗卫星通信

在当前无信号且无网络环境（包含WLAN和通过蓝牙连接使用的手机网路）的情况下，处于空旷无遮挡的环境时，可以通过北斗卫星通信，实现位置上报和卫星消息发送。

## 发送消息

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用北斗卫星通信前，手表会提醒您开启定位服务以及通信录信息，请根据界面提示完成操作。
+   为了提升北斗卫星消息发送成功率和回执接收成功率，建议将手表取下后使用该功能。
+   系统准备启动的限制条件：环境温度过低或手表电量低于10%，该功能将不可用或发送成功概率会降低。建议将手表保持在适温环境且电量充足的条件下再次尝试。
+   发送卫星消息前请尽量保证四周空旷无遮挡，手表表盘十二点钟方向朝正南方；如果不能满足，至少保证南面空旷无遮挡。在正南方 180° 范围开阔无遮挡场所使用，成功率更优。
+   北斗卫星通信属于无线通信手段，受地理环境、人为操作等因素影响，存在发送/接收不成功的概率。使用时请尝试不同环境多次发送确保消息送达，建议同时准备多种避险措施，提升自身户外探险安全性。

1.  单击手表上键进入应用列表，点击畅连 > 北斗卫星消息，点击消息发送图标<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002401147365.png"/>，进入北斗卫星消息新建界面。
2.  点击选择联系人输入框，或者联系人图标进入联系人选择页面选择收件人。如联系人列表没有联系人，则单击手表上键进入应用列表，点击电话 > 联系人进行联系人同步。
3.  根据需要选择自定义消息（支持文字编辑和语音录制）、快捷求助或预置消息，发送消息时，请根据界面引导完成。
4.  根据手表提示操作寻找卫星方向，正在发送过程中请保持静止，等待手表界面显示发送成功。

## 接收消息

1.  单击手表上键进入应用列表，点击畅连 > 北斗卫星消息，点击消息接收图标<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002401067797.png"/>，进入系统准备界面。
2.  根据手表提示操作寻找卫星方向，正在接收过程中请保持静止，等待手表界面显示接收成功。

## 删除消息

1.  单击手表上键进入应用列表，点击畅连 > 北斗卫星消息，进入会话列表界面。
2.  在会话列表界面长按，勾选要删除的联系人信息，点击删除，点击√，可删除单个或多个联系人的所有消息。在会话列表界面，左滑要删除的联系人信息，点击删除图标，点击√，可删除单个联系人的所有消息。
3.  在会话详情界面长按消息，勾选要删除的消息，点击删除，点击√，可删除单个联系人的多条消息。在会话详情界面，左滑要删除的消息，点击删除图标，点击√，可删除单个联系人的单条消息。
