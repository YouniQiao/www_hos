# 海豚通信

海豚声纳通信（简称：海豚通信）。海豚通信功能开启后，可在潜水时通信使用。

海豚通信可实现潜伴之间通过手表在水下发送预置文字、表情消息、SOS求救消息 。海豚通信发送时，手表会在25秒内持续发出蜂鸣声，海豚最远通信距离可达30 米，水下SOS求救消息可通过开启海豚声呐通信功能的手表进行一次转发，最远通信距离达60米。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   在空气中只能短距离测试。
+   不支持空气和水之间发送接收消息。

## 入水前准备

在入水前需要完成的准备，具体操作如下：

开启开关

单击手表上键进入应用列表，点击锻炼 > 潜水 > 海豚通信。仔细阅读安全提示信息后，点击同意，进入设置页面，开启海豚通信开关。

完善个人信息

在设置页面，点击您的昵称，可以编辑您的ID和昵称。ID和昵称会在面对面添加潜伴时，通过蓝牙方式广播给您周围的潜伴。ID是海豚通信的潜伴识别凭证，修改后会导致您之前的潜伴无法识别到您，建议不要频繁修改。

添加潜伴

在设置页面，点击我的潜伴进入新建潜伴页面。新建潜伴的方式有两种，可根据需要选择添加方式：

方法一：面对面添加

1.  在新建潜伴页面，点击+新建潜伴。根据界面提示，允许发现和连接附近的设备。
2.  需要添加的潜伴也进入此页面才可被发现，发现对方后点击对方信息后的+，可添加成功。

方式二：手动添加

1.  在新建潜伴页面，点击+新建潜伴。
2.  点击手动录入，根据界面提示输入对方的ID、昵称。

管理快捷信息

1.  在设置页面，点击快捷消息，可以给休闲水肺、自由潜水、技术潜水、仪表潜水不同的潜水模式添加快捷消息，还可以添加表情消息。
2.  点击目标潜水模式/表情，点击+添加消息，根据需要选择快捷消息/表情。已添加的快捷消息/表情，支持排序/删除/长按消息置顶操作。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   如果您不想收到陌生人的消息，可以在设置页面开启屏蔽陌生人消息开关。

水上测试

在设置页面，点击水上测试，根据界面提示完成测试验证操作，验证收发消息是否正常。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002511841169.png"/>

## 水下发送消息

1.  手表在潜水界面，单击辅助键，进入高级菜单界面。
2.  旋转表冠选择海豚通信，单击下键确认进入海豚通信界面。
3.  根据需要旋转表冠选择发送消息/发送表情，单击下键确认进入快捷消息/发送表情界面。
4.  消息发送成功后，其他人手表振动提醒查看消息。如果消息发送失败，手表也会收到消息发送失败的提醒。

## 水下SOS求救

1.  手表在潜水界面，长按辅助键 3秒，界面显示确认发起SOS求救信息，单击下键确认发送SOS求救信息。手表在潜水界面，也可以单击辅助键，在高级菜单界面，选择海豚通信中的SOS 求救，完成发送SOS求救信息。
2.  其他人手表会振动提醒并显示收到SOS求救信息。
