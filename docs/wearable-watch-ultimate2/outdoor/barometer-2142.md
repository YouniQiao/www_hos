# 海拔气压计

手表的海拔气压计，会自动测量当前位置的海拔和气压，并以波形图记录当天的测量数据。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用前请先连接华为运动健康应用进行自动校准。

## 查看海拔和气压

1.  单击手表上键，在应用列表中点击 海拔气压计。
2.  上下滑动屏幕可切换查看当前海拔和气压。

## 其他设置

+   点击海拔界面的校准，可校准当前海拔高度。
+   点击气压界面的设置，可开启/关闭暴风雨预警的预警开关，也可设置预警频率。预警频率默认为4hPa/3hr，表示在3小时内，气压持续下降累计超过所设置的频率（4hPa），则会发出预警提醒。
