# 潜水设置

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   每次潜水前请仔细检查相关潜水设置及设备电量。

## 通用设置

您可以根据需要设置自动开始潜水、自动结束潜水。

+   开启或关闭自动开始潜水。开启后，可设置自动开始深度和默认潜水模式。默认潜水模式：为最近一次潜水模式，您也可以配置下一次的潜水模式。
+   开启或关闭自动结束潜水。开启后，可设置水面延迟结束时间。

## 潜水模式的介绍

手表支持休闲水肺、自由潜水、技术潜水、仪表潜水 4 种潜水模式。

+   休闲水肺：适用于使用氮氧混合气进行的免减压潜水活动。

+   自由潜水：适用于通过闭气下潜的方式进行的潜水活动。

+   技术潜水：用于包含减压计划的开放系统技术潜水活动，可在水下使用多个包含氦氮氧混合气的气瓶。
+   仪表潜水：进入仪表模式后，手表将只显示深度和时间，不包含任何组织信息追踪及减压算法计算。

## 潜水模式下的设置

可以根据需要对不同的潜水模式进行设置。

1.  单击手表上键，在应用列表中点击锻炼 > 潜水。
2.  点击不同潜水模式侧的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002372938316.png" width="24" height="24"/>图标，进入设置页面。 休闲水肺：可设置气体、水体类型、保守级别、最高氧分压、安全停留时间、提醒、告警、提醒告警方式、潜水防误触。 自由潜水：可设置水体类型、提醒、告警、提醒告警方式、潜水防误触。 技术潜水：可设置气体、水体类型、GF值、氧分压极限、最后停留深度、提醒、告警、提醒告警方式、潜水防误触。 仪表潜水：可设置水体类型、提醒告警方式、潜水防误触。
