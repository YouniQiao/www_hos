# 遥控拍照

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   支持与HarmonyOS 2、EMUI 8.1及以上版本的华为手机和 iOS 13.0 及以上版本的手机配对时使用，与 iOS 手机配对使用时，需先在手机上打开相机。
+   配对初始系统为HarmonyOS 5.1及以上版本（API 版本≥18），或已升级至 HarmonyOS 6.0 及以上版本的手机时，手表侧支持显示翻转摄像头、预览、录像和图片查看，使用前请先确保手表已同步登录华为账号。手机API版本检查路径：手机设置页面点击搜索按钮，输入“API版本“并查看，若小于此版本，则无法使用功能，请及时升级手机系统

## 遥控拍照

1.  查看手表和手机连接状态，确保手表和华为运动健康正常连接。从表盘界面顶部下滑，在控制中心中可查看手表和手机的连接状态为<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002248941212.png"/>。
2.  在手表应用列表中，点击遥控拍照，联动打开手机相机功能，点击手表屏幕上的拍照图标，即可拍照。

## 遥控拍照定时设置

在手表应用列表中，点击遥控拍照，联动打开手机相机功能，点击遥控拍照界面的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002283838693.png" width="24" height="24"/>，可设置定时拍照时间 。

若手表与HarmonyOS 5.1及以上版本（API版本≥18），或已升级至HarmonyOS 6.0及以上版本的手机连接使用时，请点击遥控拍照界面的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002283920897.png" width="24" height="24"/>，在更多页面设置定时拍照的时间，还可以设置使用前置或后置相机拍照。

## 遥控拍照模式选择

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   仅与HarmonyOS 5.1及以上版本（API版本≥18），或已升级至HarmonyOS 6.0及以上版本的手机连接使用时，手表侧支持此功能。

1.  在手表应用列表中，点击遥控拍照，联动打开手机相机功能。
2.  点击遥控拍照界面上方文字，选择人像/拍照/录像模式。
3.  点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002283845929.png" width="24" height="24"/>完成拍照/人像、点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/zh-cn_image_0000002248966936.png" width="24" height="24"/>开始录像。

## 查看照片

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   仅与HarmonyOS 5.1及以上版本（API版本≥18），或已升级至HarmonyOS 6.0及以上版本的手机连接使用时，手表侧支持此功能。

拍照完成后，可点击左下角缩略图，在手表上查看最新拍摄的一张照片，双击照片、捏合屏幕或旋转表冠可缩放照⽚。如需查看更多照片，请在手机侧查看。

## 使用遥控拍照场景卡片

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   仅HarmonyOS 5.1及以上版本（API版本≥18），或已升级至HarmonyOS 6.0及以上版本的手机连接使用时，手表侧支持此功能。
+   将手机放在静止支架上或者靠在稳定的物体上不移动时才会触发该场景卡片，若手持手机则不会触发。

在手表表盘界面，当您使用手机拍照/⼈像/录像功能时，且手机与水平面呈60-120度之间，并保持静止状态 2-3s 后 ，⼿表会⾃动弹出遥控拍照场景卡⽚，提醒您使用手表遥控拍照功能。
