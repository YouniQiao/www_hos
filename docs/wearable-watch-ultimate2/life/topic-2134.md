# 控制小憩模式

车上开启小憩模式后，当您小憩结束时手表会振动提醒，抬腕即可显示小憩卡片，在手表上快速关闭或延迟提醒。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用此功能前，请将手表升级至最新版本。
+   使用此功能时，手机和车机都需要打开 WLAN 和蓝牙开关，打开即可，无需连接。
+   与HarmonyOS 2 及以上版本的华为手机配对时，支持该功能。
+   支持的车型请查看：支持华为手表控制小憩模式的车型

## 关闭小憩提醒

+   点击手表屏幕关闭图标。
+   长按手表上键。

## 延时小憩提醒

+   点击手表屏幕延时图标。
+   单击手表上键。
+   无操作 40s 后，自动延时。
