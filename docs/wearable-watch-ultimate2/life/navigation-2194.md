# 使用手表独立导航

手表联网状态下支持独立导航，无需手机即可体验智能交互的步行、骑行导航，满足您的出行需求和日常生活。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   目前仅支持步行和骑行导航。

## 使用手表独立导航

1.  在手表应用列表中，点击Petal Maps进入应用。
2.  点击下方搜索图标，在搜索栏可通过语音、手写、拼音输入目的地，也可点击分类图标展示附近地点并选择。
3.  确认地点后，选择步行或骑行导航方式，选择路线后将出现路线预览。
4.  点击开始导航即可开始，导航过程中上滑屏幕显示文字导航，轻触屏幕并点击声音图标可调节导航音量大小。
5.  轻触屏幕并点击退出图标，即可结束导航。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EX/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   在搜索界面长按地点名称可删除单条搜索记录；下拉至底部，点击清空，可清除所有搜索记录。
