# 驾驶模式，安全驾车新体验

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/figure/10044619_f017_hicar_mode.png" alt="" width="360" height="486"/>

使用驾驶模式，导航、听音乐、通话等场景沉浸体验。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

进入手机设置 > 多设备协同 > HUAWEI HiCar，选择**驾驶模式**：

+   点击左侧功能区应用图标，一键直达导航、音乐等应用。

+   点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_car_desk.png" width="24" height="24" alt="断开连接图标"/>进入更多应用列表，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_car_home.png" width="24" height="24" alt="断开连接图标"/>可返回驾驶模式主界面，在应用列表点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_car_exit.png" width="24" height="24" alt="断开连接图标"/>可退出驾驶模式。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   使用此功能前，请进入**应用市场**搜索并更新 HUAWEI HiCar 至最新版本。

+   在控制中心关闭**旋转锁定**开关，手机横屏显示体验更佳。

+   为保证行车安全，驾驶员请勿在驾驶过程中进行操作及设置，如需使用请驻车并确保环境安全。
