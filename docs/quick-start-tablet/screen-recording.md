# 录屏，记录屏上精彩片段

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/10044780_f001_ScreenRecord.png" alt="" width="560" height=""/>

您可将屏幕上的精彩内容录制成视频，分享给家人朋友。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

从屏幕顶部右侧下滑出**控制中心**，点击**屏幕录制**，启动录屏；点击屏幕顶部实况窗中的<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/stop_circle_fill.png" width="24" height="24" alt="结束图标"/>，结束录屏。

点击实况窗非按钮区域，将胶囊态展开为卡片态，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/mic_slash_fill-01.png" width="24" height="24" alt="麦克风图标"/>可打开麦克风，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/hand_point_up_tap_fill-01.png" width="24" height="24" alt="显示触摸轨迹图标"/>可关闭触摸轨迹。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

您可进入图库 > 屏幕录制，查看录制的视频。
