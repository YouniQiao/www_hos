# 加密分享，避免泄密风险

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/20005748_f001_EncryptedSharing.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

私密图片、视频、音频或文档，担心分享被泄露？使用加密分享，可指定人员查看，限制截屏录屏，有效防止泄密。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在**文件管理**或**图库**中，选择需加密的文件，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/ic_gallery_share.png" width="24" height="24" alt="分享图标"/> > 加密分享。

2.  按界面提示设置分享：

    +   若未添加指定查看人，默认**仅可查看一次**。

    +   若添加指定查看人，可设置查看时效为**永久**、**仅可查看一次**或限时查看（如 5 秒）。

    +   可按需开启**水印保护**。

3.  点击**去分享**生成加密文件，分享后指定人员可查看，转发他人将失效。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

+   登录生成加密分享文件的华为账号，查看该加密文件时不受有效期等限制。

+   仅 HarmonyOS 5 及以上版本设备支持查看加密文件，加密文件不支持截屏和录屏。

+   仅 HarmonyOS 6.1 及以上版本设备支持添加、查看**水印保护**以及限时查看。

+   并非所有文件格式支持加密，请以实际为准。
