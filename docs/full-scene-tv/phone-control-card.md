# 手机/手表感知控制卡片

当华为手机/手表靠近智慧屏，可以在手机/手表中打开智慧屏控制卡片，您可以通过控制卡片对智慧屏快捷操作。

## 前提条件

+   华为手机靠近智慧屏，智慧屏在亮屏状态。
+   华为手机在解锁并且处于桌面状态。
+   华为手机、手表和智慧屏使用同一华为账号登录。
+   手机和手表的系统版本需要在HarmonyOS 5.1及以上，且支持星闪功能。

## 操作方法

手机：

1.  满足前提条件后，华为手机底部会出现彩色流光通知。
2.  长按导航条打开小艺对话框，呈现智慧屏控制卡片提示，点击后打开控制卡片。
3.  使用智慧屏控制卡片对智慧屏进行对应的操作。

手表：

方式一：通过负一屏控制智慧屏

1.  使用华为手表负一屏控制智慧屏，参考：华为手表控制智能家居。
2.  在手表端进入负一屏的智慧屏卡片，可以实现对智慧屏熄屏/亮屏，智慧屏华为视频播控的功能。 智慧屏熄屏/亮屏：在手表端进入负一屏的智慧屏卡片，通过<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002446132590.png" width="24" height="24"/>控制智慧屏熄屏/亮屏。 华为视频播控：在手表端进入负一屏，点击智慧屏卡片进入详情页。 智慧屏有内容播放时，标题显示“播放内容+内容来源”，同时可通过页面按钮进行快进/快退/播放/暂停/音量控制等。 智慧屏未播放内容时，标题显示“未在播放+控制不可用”，同时页面内除音量按钮外，其他按钮不可用。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002479372617.jpg"/> 配图仅供参考，请以产品实际为准。

方式二：通过手表端进入华为账号中心控制智慧屏

1.  点击手表上的设置进入华为账号中心。
2.  点击我的设备，进去设备列表。
3.  点击所需要控制的智慧屏设备，即可实现对智慧屏熄屏/亮屏，智慧屏华为视频播控的功能。
