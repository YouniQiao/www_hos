# 开始跑步

## 户外跑步

1.  在设备应用列表中，锻炼 > 户外跑步。
2.  定位成功后，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002586217013.png"/>图标，开始跑步。（如果没有定位成功也可开始跑步，在运动中会继续定位。）手表跑步界面，上下滑动屏幕可查看运动数据，也可右滑屏幕进入快捷设置界面，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002525188580.png" width="24" height="24"/>调整锻炼提示音的音量，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002525028636.png" width="24" height="24"/>进入运动设置界面进行设置。

## 操场跑步

支持在标准长度为400米的操场上运动，并尽可能在所选跑道上跑步，切换跑道会影响记录准确性。

1.  在设备应用列表中，点击锻炼 > 操场跑步。
2.  跑步开始前，选择目标跑道，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002586336963.png"/>图标，开始运动。

## 跑步课程

设备内置多种跑步课程，可指导并记录您的健身记录和体能训练，让您保持一种更加积极向上的生活状态。

1.  在设备应用列表中，点击锻炼。
2.  点击课程与计划 > 跑步课程 > 预置课程或自定义课程，根据需要选择不同的跑步模式进行锻炼。自定义课程需要根据界面提示，先在华为运动健康中完成创建和同步操作。

## 训练计划

根据不同的训练目的和时间，量身定制科学训练计划，促进短闭环，根据训练状态和反馈，智能调整后续课程难度。

1.  进入华为运动健康的 运动页面，选择计划。
2.  在智能训练计划中，根据您的需求选择跑步计划，按提示完成创建。
3.  创建成功后，正常连接设备时，计划可自动同步到设备。
4.  在设备侧或手机侧均可开启训练。在设备侧查看并开启： 进入设备应用列表，选择锻炼 > 课程与计划 > 训练计划，点击查看周计划可查看跑步计划，点击课程名称可开启训练。 在手机侧查看并开启： 在华为运动健康的 运动页面，选择计划，可查看计划，点击对应日期和计划详情，可开启训练。若您已佩戴设备，设备侧也将同步开启。
