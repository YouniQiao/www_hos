# 情绪几何表盘

情绪几何表盘采用正向建构的方式，能够让情绪变得可见可感，让每一种情绪感受都被尊重、被看见，通过以美润心的审美体验帮助人们认知到自己的情绪，学会与自己的情绪和解。

## 设置表盘

1.  在手表表盘界面，长按表盘进入表盘选择界面，左右滑动选择情绪几何表盘。
2.  点击表盘下方自定义，左右滑动可设置不同样式、功能。 在样式页面，上下滑动可选择喜欢的样式。 在功能页面，点击组件可更换功能。

## 表盘说明

在情绪几何的图形参数化设计中，情绪的愉悦度（Pleasure）和唤醒度（Arousal）是两个核心参数。

+   愉悦度主要决定图形的形状：当情绪处于愉悦状态时，系统会生成柔和、圆润的图形，例如圆形或弧线，象征放松与满足；当情绪趋于中性时，图形形态则更加平直、规则，如方形，表达平和与冷静；而当情绪低落或紧张时，图形会呈现出尖锐、有棱角的特征，如菱形或不规则多边形，用以传达内在的张力与不安。
+   唤醒度影响图形的动态表现与复杂程度：当唤醒度较高时，例如激动或焦虑状态下，图形会呈现出更快的运动节奏与更为密集的线条结构，整体显得活跃而外放；当唤醒度较低时，如平静或疲惫状态，图形的运动节奏则更加缓慢，线条也相对简约整齐，仿佛在轻声呼吸。
+   颜色作为重要的视觉元素，进一步辅助情绪的表达：温暖的黄色与橙色通常代表愉悦情绪，蓝绿色调传达平静与放松，而蓝紫色系则对应低落、紧张等情绪状态。色彩会随着情绪强度的变化呈现渐变效果，在保持视觉美感的同时，也增强了情绪表达的识别性。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002555229857.png"/>
