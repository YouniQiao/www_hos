# 控制小憩模式

车上开启小憩模式后，当您小憩结束时手表会振动提醒，抬腕即可显示小憩卡片，在手表上快速关闭或延迟提醒。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用此功能前，请将手表升级至最新版本、手表和手机连接正常。
+   使用此功能时，如果手机和车机登录相同的华为账号，手机和车机都打开 WLAN 和蓝牙开关，打开即可，无需连接。
+   使用此功能时，如果手机和车机登录不同的华为账号，需要手机与车机已完成碰一碰流转和建立了互信，手机与中控屏首次碰一碰流转时，如果点击始终信任，手表小憩会一直生效，下次小憩则不需要重新进行碰一碰流转建立互信，手表小憩也会生效。
+   与 HarmonyOS 4 及以上版本的华为手机配对时，支持该功能。
+   支持的车型请查看：支持华为手表控制小憩模式的车型

## 关闭小憩提醒

+   点击手表屏幕关闭图标。
+   长按手表上键。

## 延时小憩提醒

+   点击手表屏幕延时图标。
+   单击手表上键。
+   无操作 40s 后，自动延时。
