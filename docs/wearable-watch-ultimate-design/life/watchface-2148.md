# 设置趣味贴纸表盘

您可选择或上传多张贴纸，配合多种个性化样式及功能控件，打造您的个性化表盘。还可点击屏幕与贴纸互动，获得好玩的惊喜体验。

1.  进入华为运动健康的设备详情页，点击我的表盘，选择趣味贴纸。
2.  进入几何、心情、萌宠等页面，选择喜欢的贴纸，还可点击自定义 > <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002219835673.png" width="24" height="24"/>上传贴纸图片。
3.  选择喜欢的布局、背景颜色、时间字体等，还可选择功能，更换表盘中显示的数据。
4.  点击设为当前表盘，设备表盘将自动切换为所设置表盘，点击屏幕可与贴纸互动。
