# 与 Android 手机配对连接

1.  安装华为运动健康<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002340603334.png"/>。如已安装，请打开华为运动健康，点击我的 > 检查更新，升级至最新版本。
2.  进入华为运动健康，点击我的 > 登录华为帐号。如果没有华为帐号，请先注册后再登录。 为保证您的穿戴设备与手机配对连接成功，建议您使用成人华为帐号登录。
3.  穿戴设备开机，选择语言后准备配对。
4.  将穿戴设备靠近手机，进入华为运动健康首页，点击界面右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002374601185.png" width="24" height="24"/> > 添加设备，在扫描结果中找到您的穿戴设备，点击连接。也可以点击扫一扫，直接扫描穿戴设备界面展示的二维码。
5.  当穿戴设备屏幕出现配对请求时，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/zh-cn_image_0000002374481321.png" width="24" height="24"/>，同时在手机端根据界面提示完成穿戴设备和手机配对。
6.  点击去设置，完成防断连保护设置，以防穿戴设备与华为运动健康断连，无法接收手机消息和来电。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F7/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   为了确保穿戴设备能及时收到通知信息，请在手机上确认消息通知设置是否正常。
