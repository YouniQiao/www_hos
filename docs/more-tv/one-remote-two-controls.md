# 华为智慧屏Mate TV系列一遥两控如何绑定机顶盒

智慧屏遥控器和机顶盒绑定成功后，一个灵犀遥控器既可以控制智慧屏又可以控制机顶盒，也可以通过语音切换机顶盒频道，告别繁杂的手工切换。 在智慧屏【5.1.0.243(SP3)】及之后的版本中支持一遥两控，具体操作方法如下：

## 前提条件

1.  运营商移动/联通/电信/广电提供的机顶盒与智慧屏连接（HDMI线直接连接至智慧屏，不支持级联），并开启机顶盒进入直播频道全屏播放页面。支持的机顶盒见：华为智慧屏Mate TV系列一遥两控支持绑定哪些机顶盒。
2.  智慧屏与灵犀遥控器已完成配对。
3.  智慧屏网络连接正常。
4.  绑定前建议打开机顶盒CEC开关，请参考：华为智慧屏连接机顶盒后如何打开机顶盒CEC开关。

## 操作步骤

1.  请进入一遥两控绑定入口。绑定入口一：在智慧屏首页点击输入源<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525409748.jpg" width="24" height="24"/>，进入机顶盒直播全屏播放页面（建议调整至“央视”或“卫视”的全屏播放页面），等待一段时间，智慧屏会弹窗提醒去绑定一遥两控。 <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525763148.png"/><img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556764117.png"/> 如果没有出现一遥两控绑定弹窗，可能有以下原因：①该输入源画面非机顶盒直播频道全屏页面；②已绑定过一遥两控；③智慧屏未接入网络。 绑定入口二：在智慧屏首页点击输入源<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525249808.jpg" width="24" height="24"/>，进入机顶盒直播全屏播放页面（建议调整至“央视”或“卫视”的全屏播放页面），短按菜单键调出输入源快捷菜单，选择绑定遥控机顶盒。 <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525764982.png"/> 绑定入口三：进入智慧屏设置页，选择输入源 > 绑定遥控器机顶盒后，选择机顶盒接入的HDMI输入源。 <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525765324.png"/><img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556765585.png"/>
2.  绑定提醒。此时如果机顶盒不在全屏播放页面，需使用机顶盒遥控器将机顶盒画面调整至直播频道全屏播放页面，阅读并点击同意即可。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556765891.png"/>
3.  选择省市区。省市区会根据智慧屏IP地址自动识别，若自动识别有误也可以按遥控器手动调整（建议使用遥控器上键或下键精确调整）。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556766309.png"/>
4.  选择机顶盒运营商。可在包装盒或机顶盒表面查看服务提供商，也可直接咨询办理机顶盒的业务员，建议使用遥控器上键/下键精确选择。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002525606914.png"/>
5.  绑定前注意事项。开始绑定后，需按照示意图将灵犀遥控器放置在机顶盒正前方并确保中间无遮挡。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556647201.png"/>
6.  绑定流程为自动化，将遥控器放置好之后会自行绑定，这个过程中机顶盒会静音、换台，都是正常现象。<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002556767441.png"/>
7.  绑定完成。以下情况均代表绑定成功。可参考：华为智慧屏Mate TV系列一遥两控绑定成功后有哪些状态。 绑定成功后，灵犀指向遥控会切换按键控制模式，指向光标消失，退出绑定的输入源之后恢复光标控制模式。可参考：华为智慧屏 MateTV 系列绑定一遥两控进入机顶盒页面后光标消失。 更多内容：华为智慧屏 MateTV 系列一遥两控绑定失败。
