# 华为智慧屏本地视频如何设置循环播放

您可通过以下方式在智慧屏本地视频中播放视频，并将视频设置为循环播放模式。

1.  请您根据不同的存储位置选择对应方式进行操作：

+   智慧屏：在智慧屏桌面，打开文件管理<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002493424314.png" width="24" height="24"/> > 点击视频。
+   USB存储设备： 在智慧屏首页，打开文件管理 > 选择U盘 > 点击视频。

2.  选择任意视频全屏播放。在视频播放界面，按遥控器菜单键<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002500182417.png" width="24" height="24"/>，在播放模式的选项弹框中，选择对应的播放模式。

3.  选择 单个循环 或 列表循环 即可实现循环播放，请您根据您的习惯进行选择。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   顺序播放：按照当前文件夹中显示的视频顺序依次播放，播放完最后一个视频后自动停止播放。
+   单个播放：仅播放选中的单个视频。
+   单个循环：选中单个视频后，长时间一直重复播放该视频。
+   列表循环：页面加载好自动播放第一个视频，第一个播放完之后自动切换下一个视频，当列表最后一个视频播放完毕，自动切换回第一个视频实现循环播放。
