# 无线投屏，畅享大屏体验

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/10045857_f001_WirelessProjection.png" alt="" width="560" height=""/>

无需连线，平板屏幕可快速投至华为智慧屏，畅享大屏视听体验。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  在智慧屏主页进入设置 > 多设备协同/网络与联接/遥控器与连接 > 投屏，开启**投屏**开关。

2.  从平板顶部右侧下滑出**控制中心**，点击**无线投屏**，根据提示完成投屏。

投屏结束后，点击平板顶部投屏中胶囊<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/ic_projection_mirror.png" width="24" height="24" alt="投屏图标"/>，然后点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/ic_project_close.png" width="24" height="24" alt="关闭图标"/>退出投屏。
