# 遥控拍照

遥控拍照功能，可帮您使用手表遥控手机拍照。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用前，请将您的设备和华为运动健康升级至最新版本。
+   与 iOS 和 Android 手机配对使用时，需先在手机上打开相机。与 Android手机配对使用时，手机中的蓝牙配对列表设备数不能超过7个。如果超过，建议先删除不用的蓝牙设备，然后重新配对手表后再使用该功能。

## 遥控拍照

1.  查看手表和手机连接状态，确保手表和华为运动健康正常连接。您可从表盘界面顶部下滑，在控制中心中查看手表和手机的连接状态为<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002355442668.png"/>。
2.  在手表应用列表中，点击遥控拍照，联动打开手机相机功能，点击手表屏幕上的拍照图标，即可拍照。

## 定时拍摄

1.  在手表应用列表中，点击遥控拍照，联动打开手机相机功能，点击手表遥控拍照界面的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002355602604.png" width="24" height="24"/>，可设置定时拍照时间，再次点击可切换时间 。
2.  点击手表屏幕上的拍照图标，倒计时结束后拍照。
