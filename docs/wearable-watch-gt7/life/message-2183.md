# 消息管理

华为运动健康与穿戴设备正常连接时，如您开启消息通知，可将手机状态栏的消息同步至设备上，以便查看。

## 打开消息通知开关

1.  在华为运动健康的设备详情页，点击 消息通知，开启同步手机消息通知至手表开关。
2.  在下方的应用列表中开启需要推送消息的应用开关。

## 消息提醒方式设置

如需根据手机使用状态智能选择提醒设备，您可进入华为运动健康的设备详情页，点击 消息通知，设置消息提醒方式。

+   多设备提醒：手机手表同时提醒。
+   单设备提醒：亮屏使用手机时，手表不提醒；佩戴手表时，手机不提醒。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与 iOS 手机配对使用时暂不支持设置消息提醒方式。

## 查看/删除未读消息

1.  佩戴手表时，当手机状态栏有新消息提醒，会将状态栏的消息推送至手表并振动提醒。
2.  若没有立即查看消息，可在手表主界面向上滑动，进入消息中心，查看未读消息。
3.  如需删除消息： 向左滑动要删除的消息，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002389118309.png"/>，可删除消息。 点击消息列表最下方的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002548191753.png"/>，可清除所有消息。

## 回复短信消息

1.  穿戴设备收到短信通知时，您可以向上滑动屏幕，选择快捷回复内容，点击即可回复。
2.  如需自定义消息快捷回复的内容，可在华为运动健康的设备详情页，点击消息。
3.  点击添加回复，可编辑新增回复内容；点击已编辑的回复内容，可进行修改编辑；点击回复内容右侧<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002355438280.png" width="24" height="24"/>图标，可删除回复内容。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与 iOS 手机配对使用时暂不支持该功能。
+   快捷回复短信消息，仅支持使用收到短信消息的SIM卡回复。
