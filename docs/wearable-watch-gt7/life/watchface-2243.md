# 萌宠表盘

当萌宠表盘样式设置为来自情绪时，可根据您的情绪状态变更不同的颜色和动作反馈，界面展示您最近一次的情绪检测状态，按照平静<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002468699402.png" width="24" height="24"/>、愉悦<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002468699406.png" width="24" height="24"/>、不愉悦<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002501619399.png" width="24" height="24"/>三种状态进行展示。还支持12种情绪表达，情绪表达是基于情绪状态与压力状态共同计算的结果（如低落、平和、满足等）。

1.  在设备表盘界面，长按表盘进入表盘选择界面，左右滑动选择萌宠表盘。
2.  点击表盘下方自定义，左右滑动可设置不同样式、颜色、功能等。 在样式、颜色等页面，上下滑动可选择喜欢的样式、颜色等。 样式设置为来自情绪时，会根据您的情绪状态显示不同的颜色，该样式不支持自定义颜色。 样式设置为自定颜色时，在颜色页面，可上下滑动选择您喜欢的颜色。 在功能页面，点击组件可更换功能。

您还可进入华为运动健康的设备详情页，点击我的表盘 > 趣味交互，选择更多萌宠表盘。
