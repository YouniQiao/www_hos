# 与HarmonyOS 4.3 及以下版本的手机配对连接

1.  安装华为运动健康<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002374600597.png"/>。如已安装，请打开华为运动健康，点击我的 > 检查更新，升级至最新版本。
2.  进入华为运动健康，点击我的 > 登录华为帐号。如果没有华为帐号，请先注册后再登录。 为保证您的穿戴设备与手机配对连接成功，建议您使用成人华为帐号登录。
3.  穿戴设备开机，选择语言后准备配对。
4.  将穿戴设备靠近手机，进入华为运动健康首页，点击界面右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002340762538.png" width="24" height="24"/> > 添加设备，在扫描结果中找到您的穿戴设备，点击连接。也可以点击扫一扫，直接扫描穿戴设备界面展示的二维码。
5.  华为运动健康界面出现蓝牙消息同步服务，点击同意。
6.  当穿戴设备屏幕出现配对请求时，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002374480733.png" width="24" height="24"/>，同时在手机端根据界面提示完成穿戴设备和手机配对。 为了确保穿戴设备能及时收到通知信息，请在手机上确认消息通知设置是否正常。
