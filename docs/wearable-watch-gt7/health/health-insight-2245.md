# 健康洞察

## 健康洞察介绍

健康洞察是一款跟踪您个人健康变化的应用，应用基于个人多维度数据跟踪分析，并适时通知给您。主要追踪睡眠质量、锻炼时长、压力等数据变化，并提供趋势图分析。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用前，请将您的设备升级至最新版本，华为运动健康App需更新至 17.0.7.300 (HarmonyOS 4.3及以下版本手机、Android手机) 或 17.0.7.305 (iOS手机) 及以上版本。
+   洞察报告并非每日都有，佩戴时间过短或睡眠时未佩戴，可能不会触发相关报告。
+   需连续佩戴两天后，方可在手表侧看到数据，长期佩戴可让分析逐渐变得更加精准。
+   健康变化可能由多种因素导致，摘要信息会根据您个人多维健康数据综合分析，识别多因素之间的关联性，短期数据变化可能是某些异常或疾病的征兆。
+   本应用不属于医疗软件，分析结果不作为医疗诊断依据。健康建议仅供参考，请您结合个人差异，合理安排改善计划。

## 开启提醒开关

开启后，如果健康分析结果有更新，但您未及时进入健康洞察进行查看时，设备会适时通知提醒您。

1.  进入华为运动健康首页，向上滑动屏幕，点击健康洞察下方卡片。
2.  在健康洞察页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002672437981.png" width="24" height="24"/> > 设置，开启健康洞察通知开关。

## 查看健康洞察数据

在设备侧查看

1.  在设备应用列表中，点击健康洞察可查看健康洞察结果概览。首次使用时需根据提示完成相关授权。
2.  在健康洞察首页，上滑屏幕可查看睡眠质量、身体状态准备度、锻炼时长等各项结果。

在华为运动健康侧查看

1.  进入华为运动健康的首页，向上滑动屏幕，点击健康洞察下方卡片。
2.  在健康洞察页面，您可查看如下内容： 点击精选洞察：可查看健康洞察总结分析报告、健康解读、睡眠的得分及分析结果等。在精选洞察页面，点击身体状态准备度旁边的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002701668164.png" width="24" height="24"/>图标，可按照日期查看当天的总得分，还有各关键影响因素的具体得分。身体状态准备度反映当天的身体技能与恢复平衡状态，为当日工作、生活规划提供参考，得分越高代表身体状态越好。在身体状态准备度页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002701451445.png" width="24" height="24"/>可查看关于身体状态准备度的更多介绍。 点击趋势列表：查看各项数据的趋势变化。趋势变化可能反映您的健康状况发生了变化，或者会对您的健康状况产生影响。建议您持续使用穿戴设备或手机运动健康App记录运动健康数据。
