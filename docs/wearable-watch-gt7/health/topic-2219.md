# 冠心病健康研究

通过手机侧华为创新研究应用加入冠心病研究项目，持续采集白天和夜间不同状态下的体征数据，佩戴 3 至 4 天后可查看冠心病风险评估结果。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   该功能目前仅HUAWEI WATCH GT 7 Pro 支持。
+   使用前，请将华为手表升级至最新版本。
+   HarmonyOS 5 及以上版本手机，华为创新研究应用需升级至 1.1.10.320 及以上版本； HarmonyOS 5 以下版本或安卓系统的手机，华为创新研究应用需升级至 16.0.10.320 及以上版本。
+   iOS手机无“华为创新研究”应用，手表和 iOS 手机配对后无法使用该功能。
+   测量数据和结果仅供参考，不作为诊疗依据，如身体不适建议您及时就医。
+   本研究适用于年龄18岁及以上的人群使用。

## 加入冠心病研究

1.  在手机华为创新研究首页，选择冠心病研究，点击去加入。
2.  根据界面提示，同意数据授权，然后勾选已阅读并同意知情同意书的条款，点击加入研究，进入冠心病研究首页。

## 启动冠心病风险评估

评估启动时需测量一次心电图，评估期间白天和夜间均需坚持佩戴手表约3天时间，且佩戴期间将会再次提醒您测量心电图。

1.  确保穿戴设备和华为运动健康蓝牙连接正常。
2.  在手机华为创新研究首页，点击冠心病研究，在冠心病研究首页，点击启动评估。首次启动评估时根据界面提示，如实完成调查问卷填写后点击提交，如实填写个人信息后点击下一步。
3.  在评估教程页面，点击下一步，查看测量引导。
4.  首次华为创新研究项目时，根据手表界面提示，阅读并点击同意关于华为创新研究与隐私的声明，选择佩戴方式后点击确定。
5.  手表侧已启动心电图测量页面，手指轻触电极开始测量，测量过程中请保持正确的测量姿势。
6.  心电图测量完成后开启评估，评估期间白天和夜间均需坚持佩戴手表。评估进度在手机华为创新研究的冠心病研究首页查看评估进度。
7.  佩戴时长达标，评估进度达到100%后，手表弹出评估结果并同步到手机，在手机冠心病研究首页也可以查看评估结果。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   在评估期间白天和夜间均需坚持佩戴手表，佩戴 3 至 4 天内， 保证白天总佩戴 23 小时，夜间睡眠总佩戴 18 小时，进度到100%出值。
+   在评估过程中，手表会有进度提醒，提醒当前白天和夜间佩戴时长是否达标、心电可选测量提醒、运动后心电测量提醒、无法出值风险提醒、出值提醒。
+   您长时间未开启评估，系统会根据上次评估结果弹出提醒，提醒您定期测量。

## 查看冠心病风险评估结果

+   在手机华为创新研究首页，点击冠心病研究，在冠心病研究首页，可查看评估进度以及评估结果。
+   一轮评估有效出值后，手表会提醒您查看评估结果及详情，测量结果也会同步到手机侧。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002506074278.png"/>

## 退出冠心病研究

在手机华为创新研究首页，点击冠心病研究，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002504641870.png" width="24" height="24"/> > 退出研究。

退出后，需重新加入对应研究项目，再次体验或使用。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   退出研究项目后，会永久删除冠心病研究的相关数据，且无法恢复。
