# 活力三环

活力三环包含了当天活动的三个数据：活动热量、锻炼时长、活动小时数。通过全天候的佩戴，设备将记录相关活动数据，并不间断地激励您完成目标，养成良好的运动习惯，助您时刻保持活力。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用前，请将穿戴设备和华为运动健康App升级至最新版本。

## 调整目标和设置提醒

您可以根据实际情况，调整活力三环目标值。

手机侧：

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002524747907.png"/>

+   点击调整目标，可设置活动热量、锻炼时长、活动小时数。
+   点击提醒设置，可开启/关闭久坐提醒、进度提醒、目标达成提醒等。

设备侧：

在设备应用列表中，点击活动记录，可进行如下设置：

+   在三环首页，上滑至最后一页，点击三环设置，可开启/关闭活动提醒、进度提醒、目标达成提醒。
+   在三环首页，右滑进入更多页面，点击调整目标，设置活动热量、锻炼时长、活动小时数的目标值。

## 查看活动记录

手机侧：

进入华为运动健康首页，点击活力三环卡片，进入活动记录详情页，可按日期查看活动热量、锻炼时长等。

设备侧：

在设备应用列表中，点击活动记录，可进行如下操作：

+   在三环首页右滑进入更多页面，可查看本周统计、活动记录。
+   在三环首页上滑可查看今日详情、活动热量、锻炼时长、活动小时数等。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002492748362.png" width="24" height="24"/>：活动热量，机体维持正常运行的基础上，因身体活动额外消耗的热量。单次运动中的活动热量小于总消耗热量。例如：某次运动总消耗热量 300 千卡，其中包含活动热量 260 千卡。您可以通过锻炼、家务、休闲娱乐等方式增加活动热量。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002524748059.png" width="24" height="24"/>：锻炼时长，中高强度锻炼时间的总和。世卫组织建议：成年人每周至少进行 150min 中等强度锻炼或 75min 高强度锻炼。尝试进行使心率和呼吸频率明显加快的中高强度运动，适度参加力量训练，能够提升心肺耐力和力量水平，全面提升身体素质。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FW/zh-CN/zh-cn_image_0000002524748159.png" width="24" height="24"/>：活动小时数，统计您全天在多少个小时时段里有进行身体活动。当您在某个小时时段内进行身体活动超过一分钟，该时段被标记为活动小时。世卫组织研究表明：长时间不活动将增加 II 型糖尿病、肥胖、抑郁等疾病的风险。

## 智能运动推荐服务

智能运动推荐为您在活动记录应用中推荐合适的运动建议和运动类型，提供个性化的服务。

在设备应用列表中，点击活动记录，在三环首页上滑至最后一页，点击关于 > 应用说明，开启或关闭智能运动推荐服务。

运动建议是根据您的场景和运动偏好智能生成，每一次您都可以获取多条运动建议，可以点击换一换，更换当前的运动建议。
