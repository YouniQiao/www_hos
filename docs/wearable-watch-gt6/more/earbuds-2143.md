# 连接蓝牙耳机/音箱

手表与蓝牙耳机/音箱正常连接后，可通过已连接设备听音乐等。

## 通过手表“设置”连接蓝牙耳机/音箱

1.  手表与华为运动健康配对连接后，将蓝牙耳机/音箱设置为可配对状态。
2.  进入手表应用列表，上下滑动屏幕，选择设置 > 蓝牙。
3.  选择目标蓝牙耳机/音箱连接。

## 通过手表“音乐”连接蓝牙耳机/音箱

1.  手表与华为运动健康配对连接后，将蓝牙耳机/音箱设置为可配对状态。
2.  进入手表应用列表，上下滑动屏幕，选择 音乐 ，在音乐播放界面点击右下角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0ER/zh-CN/zh-cn_image_0000002432867644.png" width="24" height="24"/>，点击音频通道 > 新设备。
3.  选择目标蓝牙耳机/音箱连接。
