# 运动设置

您可根据实际需要对锻炼类型进行设置，包括目标、提醒、自动暂停、数据显示、置顶运动等。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0ER/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   不同穿戴设备或不同运动类型设置项不同，不显示则表示该运动不支持此项设置。

1.  在穿戴设备应用列表中，点击锻炼。
2.  点击锻炼类型侧的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0ER/zh-CN/zh-cn_image_0000002412909661.png" width="24" height="24"/>图标，进入运动设置界面。 目标设置点击目标，可按照距离，时间，总消耗热量设置目标值。 提醒设置点击提醒，点击间隔提醒，可按距离或时间设置间隔提醒；还可打开或关闭心率提醒等。 运动防误触点击运动防误触，根据需要打开或关闭对应功能的开关（如自动锁定屏幕）。 自动暂停点击自动暂停，可开启或关闭自动暂停开关。开启后，停止运动时自动暂停，再次运动时继续。 移除此运动点击移除此运动，该运动类型即可从锻炼应用列表中移除。 置顶运动点击置顶运动，该运动类型将移动至锻炼应用列表中最顶端； 在锻炼列表中长按需要置顶的运动类型，点击置顶图标。
