# 使用输入法

手表端简洁的输入法，并支持语音转文字功能，腕上交互体验更便捷。

首次使用输入法时，请根据界面提示，完成隐私声明授权。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   输入法使用的场景：修改闹钟名、短信消息回复。
+   与 iOS 手机配对时，手表不支持消息回复。
+   语音转文字输入：仅支持与华为手机配对时使用。（与 iOS 手机和Android 手机配对使用时均不支持，部分手表与 Android 手机配对使用时，有语音按钮，但点击后会有不支持的提示信息，请以实际为准。）
+   语音转文字输入：仅支持部分语种，请以实际为准。

您在短信消息回复或修改闹钟名时，在使用输入界面，可文字输入，也可点击语音图标（<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002512314105.png" width="24" height="24"/>）语音转文字输入。

## 键盘输入界面的设置

您在使用输入界面时，点击下方的键盘图标（<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002512391251.png" width="24" height="24"/>），进入键盘设置界面。

+   点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002513654748.png" width="24" height="24"/> > 键盘布局，可切换键盘布局为全键或宫格键。
+   点击语言图标（<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002451539630.png" width="24" height="24"/>），点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002512511633.png" width="24" height="24"/>，根据需要添加语言，点击确定。最多能添加3种语言。
