# 控制音乐播放

您可以通过手表控制播放手机音乐，也可以为手表添加音乐独立播放。

## 控制播放手机音乐

1.  在华为运动健康的设备详情页，点击音乐，开启手表控制手机音乐开关。 iOS手机无需设置。 使用该功能时，需要保持手表和华为运动健康正常连接。
2.  打开手机音乐应用，播放音乐。
3.  在手表主屏幕向右滑动至负一屏，点击音乐卡片，进入播放界面，可暂停、切换歌曲、调整音量大小。

## 给手表添加音乐

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   给手表添加音乐前，需确保在手机音乐应用中的歌曲正常下载完成，且符合手表音乐导入格式要求。

1.  进入华为运动健康的设备详情页，点击音乐 > 音乐管理 > 添加音乐。iOS手机路径：进入华为运动健康的设备详情页，点击音乐 > 从手机导入音乐。
2.  选择需要添加的音乐，点击页面右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002522594654.png" width="24" height="24"/>完成添加。HarmonyOS 5 及以上版本手机路径：选择需要添加的音乐，点击页面右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002602772289.png" width="24" height="24"/>完成添加。
3.  在音乐管理页面，点击新建歌单，输入歌单名称，然后选择音乐，可将已上传至手表的音乐分类管理。创建歌单后，也可点击歌单页面右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002553674599.png"/> > 添加音乐。
4.  将音乐文件添加至手表成功后，不需联网即可播放音乐。
5.  如需删除已添加的音乐，请进入华为运动健康的设备详情页，点击音乐 > 音乐管理，在音乐列表中，点击歌名旁边的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002522594656.png" width="24" height="24"/>图标，选择删除。

## 控制播放手表音乐

1.  单击手表上键进入应用列表，选择音乐。
2.  点击播放按钮，即可播放音乐。
3.  在播放音乐界面，可调节音量、设置播放顺序（如顺序播放、随机播放等），还可通过旋转表冠调节音量。
4.  在播放音乐界面，上滑可查看播放列表；在播放音乐界面，点击左上角的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002553674617.png" width="24" height="24"/>图标进入更多页面，点击本地歌曲，可查看手表中的所有歌曲。
