# 升级版本

## 在设备端升级

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与iOS手机配对连接时，不支持在设备端升级设备版本。
+   穿戴产品系统版本升级提示不支持关闭，不支持版本回退。

1.  在设备应用列表中，点击设置 > 系统和更新 > 软件更新。
2.  点击更新图标，根据提示进行下载更新操作。

## 在手机端升级

1.  在华为运动健康的设备详情页，点击通用设置 > 固件更新。
2.  在固件更新页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002531790625.png" width="24" height="24"/>图标，打开WLAN 下自动下载和设备空闲时自动安装并重启开关，有新版本时会静默传输至设备侧进行版本更新。iOS手机路径为：在固件更新页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/zh-cn_image_0000002531710599.png" width="24" height="24"/>图标，打开无线局域网下自动下载和设备空闲时自动安装并重启开关。
3.  手机将检测设备的版本更新信息，请根据提示进行更新操作。
