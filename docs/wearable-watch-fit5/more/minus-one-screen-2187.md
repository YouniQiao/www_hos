# 负一屏

在负一屏中，您可查看天气信息、控制音乐播放等，为您生活带来更便捷的服务。

## 进入/退出负一屏

在手表表盘界面，向右滑动屏幕，进入负一屏。向左滑动屏幕，退出负一屏。

## 快速进入应用

1.  在手表表盘界面右滑，进入负一屏。
2.  点击负一屏的某个卡片，可进入对应应用详情页。

## 音/视频播控中心

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   手表负一屏播控中心控制手机音/视频应用功能仅支持在手机播控中心显示正在播放的音/视频应用。由于部分应用未适配手机播控中心，若手机侧播控中心显示无法控制，则在手表侧同样不能控制。

可通过负一屏的音/视频播控中心卡片，控制手机和手表的音/视频播放。控制手机音/视频时，须手表和手机正常连接且手机正在播放音/视频。

## 开启情景智能

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   情景智能卡片，仅支持与EMUI 11.1/HarmonyOS 2.0及以上版本华为手机配对时使用，同时需要在手机侧开启对应的情景智能场景。

如需使用航班、火车、快递等情景智能卡片，请进入设置 > 智慧助手，打开情景智能的开关。
