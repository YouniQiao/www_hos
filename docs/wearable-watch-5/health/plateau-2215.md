# 高原关爱

当处于高原地区时，高原关爱可帮助您实时了解自身身体状况，以便决定安排休息还是继续进行科学的运动，在很大程度上避免发生意外和高原反应带来的伤害。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   高原关爱适用于海拔2500-4500米的高原地区，暂不支持海拔4500米以上场景。当海拔在4500米以上时，血氧精度有所下降（如血氧出值较实际可能偏高）。
+   使用此功能时，请同时开启血氧自动检测功能。

## 在手机侧开启高原关爱

开启后，当您进入高原地区后，基于连续健康监测结果，如识别到高原反应风险时会进行提醒。

进入华为运动健康的设备详情页，点击高原关爱，开启自动监护。

## 在手表侧进行高反评估

设备检测到身处高海拔地区后6小时，会提示是否要进行高原反应自测（当海拔在2500-3500之间且血氧平均值大于90且高反风险小于3时，则不会提醒）。也可通过以下方式进行测量。

1.  在手表应用列表中，点击高原关爱。
2.  点击高反评估，进行评估。
