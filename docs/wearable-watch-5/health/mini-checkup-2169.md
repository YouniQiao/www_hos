# 微体检

快速测量心率、血氧、压力、体温、心电图、血管健康、呼吸健康等多项健康指标，并可在手表和App端查看生成的微体检报告。

## 微体检测量

1.  正常佩戴手表，保持静止状态。
2.  在设备应用列表中选择微体检，首次测量需要进行隐私授权，根据需要激活心电图服务、加入体温研究等项目。
3.  在手表表盘界面轻压智感窗 3s 后可快捷启动微体检或在微体检首页点击测量，按照测量指导进行测量。
4.  微体检报告生成后会振动提醒，在微体检首页上滑屏幕可查看历史报告。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   微体检的测量结果仅作为参考，不可作为医疗诊断依据，如有身体不适请及时就医。
+   进入微体检首页，上滑屏幕，在更多页签，可选择佩戴方式。
+   如果在华为运动健康首页不显示健康档案卡片，点击首页编辑卡片添加到首页。
+   个人信息的性别、年龄、身高、体重会影响测量结果。测量前，请进入手机华为运动健康应用，确保其个人信息与您的实际情况相符合（如手机安装了华为创新研究应用，其个人信息也需与华为运动健康中的信息保持一致）。

## 查看微体检报告

+   手表侧查看：在手表应用列表中，点击微体检，在微体检首页上滑屏幕查看历史报告。
+   手机侧查看：进入华为运动健康首页，点击健康档案查看详情。

微体检报告可展示：平均心率、血氧、压力、情绪、体温、心电图、血管弹性、心率变异性（HRV）、心血管风险、肺功能评估、慢阻肺风险、肺部感染风险，卵巢功能评估、脉搏波心律失常分析、高血压风险评估、高血糖风险评估、睡眠呼吸暂停检测，助您便捷掌握自身健康状况。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   微体检报告支持脉搏波心律失常分析、睡眠呼吸暂停检测需单独激活；高血糖风险评估研究项目需在华为创新研究中加入对应项目。同时收录血压(数据从运动健康APP首页血压卡片中同步，由用户通过血压卡片手动输入或华为运动健康应用连接其他支持血压监测的设备获取)。

## 删除微体检报告

进入华为运动健康，在微体检报告页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002378488157.png"/> > 删除，勾选待删除的报告，点击屏幕下方删除。手表端无法删除微体检报告。
