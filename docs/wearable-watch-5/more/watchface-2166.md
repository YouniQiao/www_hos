# 设置相册表盘

## 设置相册表盘

1.  进入华为运动健康的设备详情页，点击我的表盘 > 相册表盘，进入相册表盘设置界面。
2.  点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002356284902.png" width="24" height="24"/>，选择拍照或选择图片，选择照片后，拖动照片调整显示的区域，点击右上角的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002356437526.png" width="24" height="24"/>，照片上传完成。
3.  在相册表盘页面，可设置表盘的颜色、样式、功能等。
4.  在其他设置中，开启或关闭抬腕显示新照片。当上传图片大于一张时，开启后每次抬腕亮屏会切换一张新照片，关闭后抬腕将停留在上次显示的照片，需要点击设备表盘的屏幕才会切换新照片。
5.  点击设为当前表盘，设备表盘将设置为相册表盘。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   相册表盘支持以下格式图片：*.gif、*.jpg、*.jpeg、*.png、*.bmp、*.psd、*.tif、*.tiff、*.webp、*.pcx，其中gif图显示为静图，不显示动态效果。

## 一碰传更换相册表盘图片

通过一碰传功能可将手机本地图片上传到穿戴设备的相册表盘。当上传图片大于一张时，可通过轻触表盘屏幕实现图片随机切换。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用该功能前，请确保设备和华为运动健康蓝牙正常连接。
+   穿戴设备及配对的华为手机均需支持 NFC 功能。
+   使用该功能前，请先此确认穿戴设备支持上传照片的数量，若您添加的照片数量超过上限，则无法使用一碰传。进入华为运动健康的设备详情页，点击我的表盘，选择相册表盘，相册表盘的介绍中有支持的照片数量。

1.  单击手表上键，在手表应用列表中，点击设置 > 多设备协同 > NFC，开启NFC开关。
2.  打开手机 NFC 开关。
3.  进入手机图库，选择需要传输的图片后，用手机背部 NFC 区域紧贴设备表盘进行传输，传输成功后表盘屏幕显示该图片。

如需修改表盘样式，进入华为运动健康的设备详情页，点击我的表盘，选择相册表盘，进入相册表盘设置界面进行修改。

## 删除相册表盘图片

在相册表盘设置界面，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002389900221.png" width="24" height="24"/>进入图片总览页，然后点击图片上的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002358224088.png" width="24" height="24"/>，返回相册表盘设置界面，点击保存。
