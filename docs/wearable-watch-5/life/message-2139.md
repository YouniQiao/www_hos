# 消息管理

华为运动健康应用与手表保持正常连接时，开启消息通知功能后，可将推送至手机状态栏的消息同步至手表上，以便查看。

## 打开消息通知开关

1.  在华为运动健康的设备详情页，点击 消息通知，打开 通知 开关。
2.  在下方应用列表中打开需要推送消息的应用开关。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   支持通知的应用类型可在应用列表中查看。

## 消息提醒方式设置

如需根据手机使用状态智能选择提醒设备，您可进入华为运动健康的设备详情页，点击 消息通知，设置消息提醒方式。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与 iOS 手机配对使用时暂不支持消息智能提醒或使用手机时静默通知。

+   华为手机（HarmonyOS 4.3 及以下版本）：开启消息智能提醒。在您使用手机时，手表不振动、不响铃，以静默方式接收消息。 在您未使用手机且佩戴手表时，将在手表接收消息提醒，此时手机不振动、也不响铃。
+   其他 Android 手机：开启使用手机时静默通知开关（此开关默认关闭），在您使用手机时，手表不振动、不响铃，以静默方式接收消息。

## 查看/删除未读消息

1.  佩戴手表时，当手机状态栏有新消息提醒，会将状态栏的消息推送至手表并振动提醒。
2.  若没有立即查看消息，可在手表主界面向上滑动，进入消息中心，查看未读消息。
3.  如需删除消息： 向左滑动要删除的消息，点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002525684067.png"/>，可删除消息。 点击消息列表最下方的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002548191831.png"/>，可清除所有消息。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   未开通独立号码eSIM业务且手表与手机蓝牙断连时，不支持接收和回复短信和消息。
+   消息在手机端查看后手表消息列表会自动删除，手表端查看过的消息仍会保留在手表的消息列表中，需点击删除图标删除。

## 回复短信消息

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与 iOS 手机配对使用时暂不支持该功能。
+   若手表已开通独立号码，可独立回复短信。
+   快捷回复短信消息，仅支持使用收到短信消息的SIM卡回复。

1.  手表收到短信通知时，通过以下几种方式进行回复： 您可以点击该消息下方的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002227220746.png"/>表情按钮，选择表情快捷回复。 您可以点击该消息下方的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002262174461.png" width="24" height="24"/>键盘按钮，进行内容自定义回复。 消息提醒界面，向上滑动屏幕，选择快捷回复内容，点击即可回复。
2.  如需自定义消息快捷回复的内容，可在华为运动健康的设备详情页，点击消息卡片。
3.  点击添加回复，可编辑新增回复内容；点击已编辑的回复内容，可进行修改编辑；点击回复内容后<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EB/zh-CN/zh-cn_image_0000002525568045.png" width="24" height="24"/>，可删除回复内容。
