# 马拉松

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   使用该功能前，请将华为运动健康升级至最新版本。
+   为确保体能指导准确运行，请合理制定比赛目标，并确保赛前身体状态良好，避免状态不佳参赛。
+   赛事信息均来自各赛事官方网站，如有变动，请以各赛事官网最新公告为准。

## 马拉松设置

1.  在手表应用列表中，点击锻炼。
2.  点击马拉松右侧的<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/zh-cn_image_0000002491299042.png" width="24" height="24"/>图标，进入马拉松设置页面，您可进行如下设置： 马拉松指导：点击马拉松指导，开启马拉松指导开关。开启后，会为您提供智能化的比赛体能指导和补给提醒。点击体能指导，可选择按配速指导或按心率指导。 配速员：点击配速员，开启配速员开关。开启后，会根据目标成绩自动计算配速员配速。

## 管理赛事

添加赛事：

1.  在华为运动健康的运动页面，点击户外跑步。
2.  在屏幕下方的赛事助手卡片中，点击查询赛事，选择您的目标赛事。
3.  点击下一步，选择参赛距离和目标成绩，点击添加到我的赛事。
4.  添加后，赛事会自动同步到手表。也可在我的赛事页面，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/zh-cn_image_0000002500795264.png" width="24" height="24"/> > 同步到设备进行同步。

您还可点击自定义赛事，输入名称、时间等信息进行添加。

删除赛事：

1.  在华为运动健康的运动页面，点击户外跑步。
2.  在赛事助手卡片中，点击我的赛事，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/zh-cn_image_0000002529469920.png" width="24" height="24"/> > 删除赛事。
3.  选择待删除的赛事，点击删除。

## 查看赛事

手表侧：

在手表应用列表中，点击锻炼 > 马拉松，可查看我的赛事信息（如：距离比赛日的剩余天数、目标成绩）。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   如需查看已结束的赛事，请前往华为运动健康App中查看，手表侧不显示已结束的赛事。

手机侧：

1.  在华为运动健康的运动页面，点击户外跑步。
2.  在赛事助手卡片中，点击我的赛事，可查看您已添加的所有赛事： 点击进行中，可查询待参加的所有赛事。点击某个赛事，可查看该赛事的详细信息，还可进行编辑。 点击已结束，可查看已结束的所有赛事。 若您所添加的赛事中暂无已结束的赛事，则在我的赛事页面可直接查看，不会显示进行中和已结束页签。

## 开始跑步

1.  在手表应用列表中，点击锻炼 > 马拉松。
2.  如当日有多场赛事，需选择需要参赛的赛事。若无赛事时，可选择测试赛进行运动。
3.  点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/zh-cn_image_0000002491476196.png"/>开始跑步。运动结束后，可在手机侧查看马拉松锻炼记录。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   跑步过程中，设备会基于您的身体特征、目标成绩、运动能力、比赛配速和天气情况，并参考通常的水站分布情况，进行个性化精准补水及补糖（碳水）提醒，避免身体脱水或糖原耗竭导致掉速。
