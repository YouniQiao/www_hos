# 健康摘要

## 健康摘要介绍

健康摘要是一款跟踪您个人健康变化的应用，应用基于个人多维度数据跟踪分析，并适时通知给您。主要追踪睡眠质量、锻炼时长、压力等数据变化，并提供趋势图分析。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   摘要报告并非每日都有，佩戴时间过短或睡眠时未佩戴，可能不会触发相关报告。
+   需连续佩戴两天后，方可在手表侧看到数据，长期佩戴可让分析逐渐变得更加精准。
+   健康变化可能由多种因素导致，摘要信息会根据您个人多维健康数据综合分析，识别多因素之间的关联性，短期数据变化可能是某些异常或疾病的征兆。
+   本应用不属于医疗软件，分析结果不作为医疗诊断依据。健康建议仅供参考，请您结合个人差异，合理安排改善计划。

## 开启提醒开关

开启后，如果健康摘要分析结果有更新，若您未及时进入健康摘要查看，设备会适时通知提醒您。

进入华为运动健康首页，下滑屏幕，点击健康摘要下方卡片，然后点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0EV/zh-CN/zh-cn_image_0000002298138392.png" width="24" height="24"/> > 设置，开启健康摘要通知开关。

## 查看健康摘要数据

在设备侧查看

在设备应用列表中，点击健康摘要可查看健康摘要报告概览，上滑屏幕可查看各项结果。首次使用时需根据提示完成相关授权。

在华为运动健康侧查看

进入华为运动健康的首页，向上滑动屏幕，点击健康摘要下方卡片，可查看如下内容：

+   点击精选摘要：查看运动健康数据分析总结报告。
+   点击趋势列表：查看各项数据的趋势变化。趋势变化可能反映您的健康状况发生了变化，或者会对您的健康状况产生影响。建议您持续使用穿戴设备或手机运动健康App记录运动健康数据。
