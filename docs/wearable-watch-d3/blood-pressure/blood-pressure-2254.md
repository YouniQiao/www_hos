| 异常场景 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 信号质量差 | 测量时手表压迫胸口、身体未保持平稳或深呼吸。 | 请测量时避免手表压迫胸口，保持平稳，均匀呼吸。 |
| 未保持静止 | 测量时移动手臂、活动手指、说话等。 | 请保持静止姿势，避免说话、移动手臂或活动手指。 |
| 不规则心跳 | 测量时检测到不规则心跳。 | 请休息1-2分钟后再次测量。如果多次测量连续出现该提示，请咨询医生。 |
| 气囊加压错误 | 检测到气囊安装异常，或气囊、气泵、气路受损。 | 请检测气囊的安装状态，确保正确安装。检测气囊、气泵或气路是否有破损，若有破损，请及时更换。 |
| 未佩戴 | 测量时未正确佩戴手表。 | 请按照说明书正确佩戴手表。 |
| 电量过低 | 手表电量过低。 | 请为手表充电，保持电量充足。 |
| 未安装气囊 | 检测到未安装气囊。 | 请根据腕围大小，安装正确的气囊及表带。 |
| 气囊安装不匹配 | 气囊安装类型与设置腕围不匹配：气囊安装不正确或者血压应用中腕围选择不正确。 | 请根据上手指导测量腕围，安装合适的表带及气囊，并在血压 > 设置 > 腕围设置中选择正确腕围。 |
| 泄气异常 | 测量结束后泄气慢。 | 请立即摘下手表，按照气囊泄气慢处理方法清理进出气口。 |
| 加压时间过长 | 测量时加压时间过长。 | 请立即摘下手表，等气囊泄气结束再进行测量。如果多次出现，请联系维修网点。 |
| 压力过高 | 测量时压力过高。 | 测量过程中请勿压迫气囊及表带。 |

## 气囊泄气慢处理方法

请将短表带（含表扣）取下，将表体的短表带连接处朝下，甩动表体 2-3 下，若连接处有液体甩出，用干净的纸巾或布将连接处的液体轻轻擦干。完成后将短表带扣合到表体，约 2-4 小时后重新测量，查看问题是否恢复。如果 24 小时后尝试测量问题还存在，请联系维修网点。
