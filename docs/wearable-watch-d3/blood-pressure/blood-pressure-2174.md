# 在家和在医院测量的血压值不一致原因

+   在家测量血压值比在医院测量血压值低有以下可能原因： 在医院测量血压时往往会精神紧张，因此测量值也会偏高。因为在自己家中测量时心绪安稳，身体放松，有时会比医院的测量值低 测量位置若高于心脏，会导致测量值偏低。测量时，如果手腕位置高于心脏，测出的血压值会偏低。
+   在家测量血压值比在医院测量血压值高有以下可能原因： 如果正在服用降压药，则药效消失时会引起血压值升高。服用降压药几小时后，药效会逐渐消失，而此时血压也会相应升高。具体情况请咨询医生。 佩戴的过松，有时也会导致测量值偏高。佩戴手表过松，会致使压力无法传达到血管，因此测量到的血压值也会比实际值偏高。 测量的姿势不正确也会导致测量结果偏高。盘腿坐，坐在较矮沙发上或在低矮的桌子前等易使身体部位受压的姿势，会因为产生腹压或佩戴位置低于心脏而致使血压的测量值偏高。
