# 微体检

快速测量心率、血压、血氧、压力、体温、心电图、血管健康、睡眠呼吸暂停检测等多项健康指标，并可在手表和手机端查看生成的微体检报告。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   本软件不适用于未满18周岁的用户。
+   微体检的测量结果仅作为参考，不可作为医疗诊断依据，如有身体不适请及时就医。

## 微体检测量

1.  正常佩戴手表，保持静止状态。
2.  在设备应用列表中选择微体检<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/zh-cn_image_0000001984735846.png"/>，首次测量需要进行隐私授权，根据需要激活心电图服务、加入体温研究等项目。
3.  在微体检首页点击测量，按照测量指导进行测量。
4.  测量结束后会自动生成微体检报告。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   进入微体检首页，上滑屏幕至更多页面，可选择佩戴方式。
+   个人信息的性别、年龄、身高、体重会影响测量结果。测量前，请进入手机华为运动健康应用，确保其个人信息与您的实际情况相符合（如手机安装了华为创新研究应用，其个人信息也需与华为运动健康中的信息保持一致）。

## 查看微体检报告

手表端查看：

在手表应用列表中，点击微体检，在微体检首页，上滑屏幕至更多页面，点击历史报告可查看历史报告。

手机端查看：

进入华为运动健康首页，点击健康档案查看详情。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   如果在华为运动健康首页不显示健康档案卡片，点击首页编辑卡片添加到首页。

微体检报告可展示：平均心率、血压、血氧、压力、体温、情绪、心电图、血管弹性、心率变异性（HRV）、心血管风险、脉搏波心律失常分析、睡眠呼吸暂停检测、高血糖风险评估、卵巢功能评估、多囊卵巢风险评估、高尿酸评估、冠心病风险评估、肝脏脂肪风险等级等，助您便捷掌握自身健康状况。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   脉搏波心律失常分析、睡眠呼吸暂停检测需单独激活；高血糖风险评估、卵巢功能评估、多囊卵巢风险评估、高尿酸评估、冠心病风险评估、肝脏脂肪风险等级（依赖华为智能体脂秤 3Pro提供数据）需在华为创新研究中加入对应项目。

## 删除微体检报告

1.  进入华为运动健康首页，点击健康档案。
2.  点击微体检报告，点击右上角<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/zh-cn_image_0000002645441996.png" width="24" height="24"/> > 删除，勾选待删除的报告，然后点击删除。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   手表端无法删除微体检报告。
