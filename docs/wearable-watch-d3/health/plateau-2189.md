# 高原健康研究

当您有高原出行计划时，高原健康研究应用可以根据测量结果和主观感受收集综合评估您的高原反应风险，并给出健康指导和建议。

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/images/icon-note.svg" width="24" height="24"/>

+   与 iOS 手机配对连接时，不支持该功能。

## 加入高原健康研究项目

单击手表上键，在应用列表中，点击华为创新研究 > 高原健康研究，点击加入研究。

## 测量高原健康

+   手机侧测量 打开手机华为创新研究应用，进入高原健康研究项目，点击开始评估。首次使用时，请点击开始体验，根据界面提示完成问卷调查，然后点击开始评估，阅读测量教程，点击下一步 > 开始评估 。 在设备侧，根据界面测量教程提示，完成测量。 测量结束后，手机界面显示测量结果。
+   设备侧测量 打开手机华为创新研究应用，进入高原健康研究项目。 单击手表上键，在应用列表中，点击华为创新研究 > 高原健康研究，点击开始评估，测量时根据测量教程完成问卷填写和生理数据采集。 测量结束后设备界面显示测量结果，可点击<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0FG/zh-CN/zh-cn_image_0000002358363533.png" width="24" height="24"/>查看结果说明。

## 查看数据

打开华为创新研究应用，进入高原健康研究项目，可查看测量数据和历史数据。

测量成功后可以在设备侧看到测量结果，上滑页面可点击查看统计详情和历史测量结果。
