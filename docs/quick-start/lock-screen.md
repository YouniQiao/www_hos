# 快速锁屏，便捷高效

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044757_f006_ScreenLock.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

使用快捷锁屏方式，无需按电源键也可快速锁屏。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

+   一键锁屏：在桌面双指捏合，点击**卡片**，向下滑动，点击**一键锁屏**，选择所需的卡片样式后**添加至桌面**，点击即可快速锁屏。

+   轻触锁屏：进入设置 > 系统 > 快捷启动和手势，开启**轻触锁屏**开关，连续轻触两次桌面空白区域，即可快速锁屏。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

一键锁屏小卡片可拖拽至底部快捷操作栏（需预留位置，可支持 5 个图标）。
