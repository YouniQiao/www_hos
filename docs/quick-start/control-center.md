# 使用控制中心

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/video/10044640_f014_ControlCentre.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

您可在控制中心快速设置常用小功能，如调整响铃模式、切换默认 SIM 卡等。在空白处左右滑动，轻松切换控制中心和通知中心。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

从屏幕顶部右侧下滑出控制中心：

+   点击快捷开关，快速开启或关闭功能。

+   长按快捷开关，部分可查看更多设置。

+   在任意位置（亮度和音量区域除外）右滑，切换至通知中心。在通知中心空白处左滑，可切回控制中心。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202601231gjcjr/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

您可在锁屏状态下进入控制中心，若不需要，可进入设置 > 生物识别和密码，关闭**控制中心**开关。
