# 桌面编辑，个性高效

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/20005692_f002_HomeScreen.png" alt="" width="560" height=""/>

在桌面编辑器，您可以快速更换壁纸、主题，调节图标，添加卡片，设置主桌面，让您平板使用更便捷，桌面显示更个性化。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

在桌面上双指捏合，进入桌面编辑器，您可以：

+   点击**壁纸**、**卡片**、**图标**或**主题**，按照需求进行选择并应用，打造个性化桌面。例如：点击**图标**，拖动**图标大小**滑块可调节图标大小。

+   左右滑动页面，在最常用页面上方点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/ic_public_home.png" width="24" height="24" alt="主桌面图标"/>，可将其设置为主桌面。
