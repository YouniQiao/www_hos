# 关怀模式，安全便捷

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/20006188_f001_SeniorMode.png" alt="" width="560" height=""/>

开启关怀模式，可快速放大屏幕显示，看得更清楚。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

进入设置 > 关怀和无障碍 > 关怀模式，开启**关怀模式**开关。

在**放大显示**中拖动滑动条，根据需要调节至合适的显示大小。
