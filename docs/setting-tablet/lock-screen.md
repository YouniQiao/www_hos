# 锁屏界面，个性装扮

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/20005688_f002_lockScreen.png" alt="" width="560" height=""/>

在锁屏编辑界面，您可以更改时钟样式、添加闹钟天气等锁屏卡片、设置锁屏签名或艺术签名，还可快速更换壁纸和主题，让锁屏更加美观实用。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  通过以下任一方式进入锁屏编辑界面：

    +   锁屏状态下点亮屏幕，在锁屏界面双指捏合，解锁后进入。如您使用人脸识别解锁屏幕，建议选择**滑动解锁**，解锁后双指捏合进入。

    +   点击设置 > 桌面和个性化 > 锁屏。

2.  点击时钟卡片，调整锁屏时钟样式、字体、颜色，在**锁屏签名**下方文本框输入签名内容，点击**确定**。

3.  再次点击时钟卡片，点击下方圆圈，添加喜欢的卡片，长按并拖拽卡片可以调整位置。

4.  设置完成后，点击**应用**。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

当前仅部分主题支持该功能，如：推荐主题、宇宙与天气等，您可进入设置 > 桌面和个性化 > 更多主题进行设置。
