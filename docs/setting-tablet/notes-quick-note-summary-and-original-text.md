# 备忘录速记，速览摘要和原文

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/20014428_f001_QuickNote.png" alt="" width="560" height=""/>

浏览应用内容时，使用速记功能把链接添加至备忘录，不仅可自动生成摘要，还能一键快速复访原文，碎片化信息轻松整合。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> 方法

1.  为了获得更佳体验，使用前请登录**华为账号**。

2.  打开要记录的内容，从屏幕左、右边缘向内滑动并停顿，调出**智慧多窗应用栏**，点击<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/quick_note.png" width="24" height="24" alt="速记图标"/>。

3.  点击添加链接 > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/ic_choose_done.png" width="24" height="24" alt="确认图标"/>，将原文链接保存至备忘录。

4.  点击屏幕顶部通知进入**备忘录**，打开对应备忘，网页链接下方会自动生成摘要；点击链接，可快速返回原文。

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> 提示

部分应用不支持添加链接，部分敏感信息可能不支持生成摘要，请以实际体验为准。
