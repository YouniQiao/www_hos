# Share Files Between HarmonyOS and iOS Devices

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/figure/10044641_f070_ShareApple.png" alt="" width="560" height=""/>

Seamlessly exchange photos, videos, and files across devices—whether they're Huawei smartphones, tablets, or HarmonyOS PCs, or even iPhones, iPads, and Macs.

**Try it out**

The following example illustrates how to transfer files between your Huawei tablet and iPhone.

1.  Before you get started, apply the following settings:

    +   **iPhone**: Download and open **HarmonyOS Interconnect** via App Store, and enable **Bluetooth**.

    +   **Huawei tablet**: Open **Control Panel**, tap **Huawei Share**, and select **Everyone (10 min)** for the first time.

2.  Perform the following operations based on the sharing scenario:

    +   **From your tablet to an iPhone**: Select the files to be shared, go to <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/common/buttons/ic_Celia_share.png" width="24" height="24" alt="Share icon"/> > Huawei Share, and tap the icon of the target iPhone.

    +   **From an iPhone to your tablet**: Open **HarmonyOS Interconnect**, tap **I want to send**, select the files to be shared, and tap the icon of the target Huawei tablet.

**Note**

The iPhone must run iOS 13 or later, and the Huawei tablet must run HarmonyOS 6.0.0.112 or later.
