# Star River interconnect: Transfer files between HarmonyOS and iOS devices

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/figure/10044641_f070_ShareApple.png" width="560" height=""/>

You can seamlessly transfer images, videos, documents, and more between HUAWEI phones, tablets, HarmonyOS PCs, and iPhone, iPad, or Mac devices.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

The following steps use file transfer between a HUAWEI tablet and an iPhone as an example.

1. Before sharing, complete the following settings:

   - **iPhone**: Download and open Star River interconnect from the App Store, and turn on Bluetooth.

   - **HUAWEI tablet**: Go to the Control Panel, tap HUAWEI Share, and when sharing for the first time, select Visible to all (10 minutes).

2. During sharing, perform the following operations based on the scenario:

   - **Share from this device to iPhone**: Select the file to share, tap the share icon > HUAWEI Share, then tap the iPhone icon you want to share with.

   - **Share from iPhone to this device**: Open Star River interconnect, tap Send, select the file to transfer, then tap the HUAWEI tablet icon you want to share with.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+ The iPhone must run iOS 13 or later, and the HUAWEI tablet must run HarmonyOS 6.0.0.112 or later.
