# Instant Transfers with Huawei Share

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/figure/10044641_f002_Sharephone.png" alt="" width="560" height=""/>

Huawei Share makes it quick and easy to transfer files between your device and nearby tablets without having to use any mobile data.

**Try it out**

**Receiving device:** Swipe down from the upper right corner of the screen to display **Control Panel**, tap **Huawei Share**, and select **Everyone (10 min)** for the first sharing.

1.  **Sending device:** Select the file you wish to share (for example, an image), tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/common/buttons/ic_Celia_share.png" width="24" height="24"/>, then **Huawei Share**, and select the receiving device.

2.  **Receiving device:** Once you receive the file transfer notification, tap **Accept**.
