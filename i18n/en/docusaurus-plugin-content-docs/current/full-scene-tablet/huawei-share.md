# HUAWEI Share, share files at lightning speed

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/10044641_f002_Sharephone.png" width="560" height=""/>

Share files with nearby Huawei phones at lightning speed, no data connection required.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

**On the receiving device:** Swipe down from the top of the screen to open the Control Panel, tap HUAWEI Share, and when receiving a share for the first time, select Visible to all (10 minutes).

1.  **Sender:** Select the file to share (for example, a photo), tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202406260lXnqu/zh-cn/image/common/buttons/ic_Celia_share.png" width="24" height="24"/>, tap HUAWEI Share, select the receiving device, and send the file.
2.  **Receiver:** When the file share prompt appears, tap Accept.
