# A new doodle experience, with one-tap restore

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202512310dkjZd/zh-cn/image/figure/20005895_f002_galleryedit.png" width="560" height=""/>

On an image, you can use a variety of doodle strokes to easily draw standard shapes, or use the mosaic brush to protect private information in the image. You can also add a text box to add text to the image. After saving the image, you can restore the original with one tap.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  In Gallery, select an image, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512031Znvtc/zh-cn/image/common/buttons/penkitpenkit.png" width="24" height="24"/> to enter the doodle screen, then choose different strokes and colors to create.
2.  Draw a shape with one stroke and pause for a moment to quickly generate a standard shape. If you need to add a mosaic to the image, select the mosaic stroke on the far right.
3.  Tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512031Znvtc/zh-cn/image/common/buttons/ic_more.png" width="24" height="24"/> > Add text box to add text:
    +   Tap Edit, enter the text you want to add, then tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512031Znvtc/zh-cn/image/common/buttons/ic_comfirm.png" width="24" height="24"/>.
    +   Tap Style to adjust the text color and size.
    +   Tap Delete to delete the text box.
4.  After the image is saved, if you need to modify or redo it, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512031Znvtc/zh-cn/image/common/buttons/ic_gallery_edit1.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512031Znvtc/zh-cn/image/common/buttons/ic_gallery_restore_edit.png" width="24" height="24"/> to restore the original image.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

Before using this feature, update your device to the latest version.
