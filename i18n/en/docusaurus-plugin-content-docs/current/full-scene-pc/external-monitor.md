# Connect an External Monitor for Seamless Dual-Screen Experience

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_projection_DesktopMonitor.png" alt="" width="720" height=""/>

Connect a monitor to your computer using a cable or adapter to enjoy a seamless dual-screen experience. This helps you work efficiently on larger screens while easily handling various tasks.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  When the screen is unlocked, connect the monitor to the computer using a direct cable or an adapter cable, then power on the monitor.

2.  After the connection is successful, the home screen of the computer is displayed on the monitor. When the monitor is connected for the first time, it is used as the extended screen of the computer by default.

3.  You can also go to <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_public_chevron_up.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_screencast_management.png" width="24" height="24"/> in the lower right corner of the home screen to access the Manage screen casting screen and switch the display mode as required.

    +   Main display: The external monitor will be used as the main display, and the computer screen will be used as the extended display.

    +   Extended display: The external monitor will be used as the extended screen of the computer. This allows you to open different app windows on each screen, making it more efficient for work and study with dual screens.

    +   Mirror for This device: The external monitor will display the same content as the computer.

    +   Standalone display: The external monitor will display the computer screen, and the computer screen will automatically turn off.

4.  To disconnect the computer from the monitor, remove the cable or adapter, or power off the monitor.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

The port varies according to the device model. Prepare the cable or adapter to be connected based on the device port.
