# Transfer Files between Devices, with Huawei Share

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_HuaweiShare.png" alt="" width="720" height=""/>

**Huawei Share** helps you send files between computer, tablet, and phone, seamlessly and data-free.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  Enable Huawei Share on your phone/tablet and computer.

    +   Phone/Tablet: Swipe down from the upper right corner to display Control Panel and enable Huawei Share.

    +   Computer running HarmonyOS: Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_controlcenter_icon.png) in the lower right corner of the home screen, or press HarmonyOS Key![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/keyboard/HM_keyboard_OH_1.png) + C (on the keyboard) to open Control Panel, and click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_public_hwshare.png) to enable Huawei Share.

    +   Huawei computer running Windows: Double-click Huawei PC Manager to open it and toggle on the Huawei Share switch.

2.  On the sending device, select the file that you wish to transfer, go to **Share** > **Huawei Share** (or **Show more options** > **Huawei Share**), and select a receiving device from the device list.

3.  On the receiving device, click Accept or Save as after receiving the file sharing notification.

    +   Accept: The shared files will be automatically saved to a fixed path, for example, the Huawei Share folder in Files or Gallery.

    +   Save as: You can customize the directory for storing shared files (only supported on certain devices).

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

+   For devices to accept a sharing for the first time, enable Huawei Share and select Everyone (10 min) first to get them discoverable.

+   Files shared between devices logged in to the same HUAWEI ID will be automatically received and saved on the receiving device.
