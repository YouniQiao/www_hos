# Using the keyboard

Watch-based input method and speech-to-text input allow for convenient interactions directly on your wrist.

When using Input method for the first time, follow the onscreen instructions and agree to the privacy statement.

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/images/icon-note.svg" width="24" height="24"/>

+   The watch-based input method can be used for editing alarm names and replying to SMS messages.
+   Replying to messages is not supported when the watch is paired with an iPhone.
+   Speech-to-text input requires your watch to be paired with a HUAWEI phone. (The voice icon is not available when your watch is paired to an iPhone. When paired with an Android phone, certain devices will display a prompt after you tap the voice icon).
+   Actual languages supported by speech-to-text input shall prevail.

When you reply to SMS messages or edit alarm names, you can use the input screen to use text input, or tap the voice icon (<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/en-us_image_0000002512314105.png" width="24" height="24"/>) to use speech-to-text input.

## Keyboard settings

While using the input screen, tap the keyboard icon (<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/en-us_image_0000002512391251.png" width="24" height="24"/>) at the bottom to access the keyboard settings screen.

+   Go to <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/en-us_image_0000002513654748.png" width="24" height="24"/> > Keyboard layout to switch between Full and 9-key.
+   Tap the language icon (<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/en-us_image_0000002451539630.png" width="24" height="24"/>) and then <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0F9/en-US/en-us_image_0000002512511633.png" width="24" height="24"/> to select the language you want to add, and tap OK. You can add up to three languages to suit your preferences.
