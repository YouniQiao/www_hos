# Peripheral Compatibility List

HarmonyOS PC supports the following types of peripherals. You can check them at [HarmonyOS PC Peripheral Compatibility List](https://devicepartner.huawei.com/cn/certifications/peripheralproducts/).

| Peripheral Type | Peripheral Type | Peripheral Type | Peripheral Type  |
| ---- | ---- | ---- | ----- |
| Printer  | Card reader  | Bluetooth glasses | Wireless display adapter |
| Scanner  | Earbuds   | Bluetooth speaker | Monitor   |
| Keyboard   | SSD | Microphone  | Speaker    |
| Mouse   | HDD | Barcode scanner  | Adapter cable   |
| USB flash drive   | Docking station  | Pen tablet  | Memory card   |
| Camera  | Bluetooth earbuds | Projector  | -     |
