# Trail Running

> This article applies to **WATCH Ultimate ULTIMATE DESIGN, WATCH GT 6 series, and WATCH 5**.

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

<TabItem value="gt6" label="WATCH GT 6">

Professional Workouts


|  | Trail Running |
| --- | --- |


   Trail Running

    The watch supports professional trail running features, letting you follow segment navigation as needed and view full-color maps, with richer data screens.


> 💡 **Tip:** Before use, update **HUAWEI Health** and your watch to the latest versions. Trail running segment navigation is supported only on some watches. If your watch does not display segments, it is not supported. Refer to the actual UI.


## Workout Settings


1. Press the watch's upper button, then tap **Workout** in the app list.
2. Swipe up or down on the screen to select **Trail Running**, then tap the **<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0ER/zh-CN/zh-cn_image_0000002364516078.png" width="24" />** icon to enter the settings screen. Tap **Goals** to set target values for distance, time, and total calories burned.
3. Tap **Reminders** to set interval reminders, heart rate reminders, training load, and more. During a workout, when the configured reminder thresholds are met, you'll hear a voice reminder.
4. Tap **Data display** to set the data to display on the workout screen. > 💡 **Tip:** The data display items you can set include heart rate, pace, slope, and altitude trend. Available options vary by device. Refer to the actual UI.
5. As needed, you can also configure workout anti-mistouch, metronome, segments, and other settings.


## Importing a Trail Running Route

     Before starting a trail run, first import the route file downloaded from the race's official website in **HUAWEI Health**, and transfer it to your watch. If the imported route is in a new city, download the offline map.
     When the imported trail running route includes CP points and altitude data, the altitude curve chart and segment navigation data can be displayed during the workout.


> 💡 **Tip:** The altitude curve chart feature is currently supported only on HUAWEI WATCH GT 6 Pro.


1. In **HUAWEI Health**, go to **Me > My routes** > **Import route**, select the route file you've downloaded locally, and save it to **My routes**.
2. After selecting the target route, tap the **<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/M0ER/zh-CN/zh-cn_image_0000002373063754.png" width="24" /> > Transfer to wearable** icon in the upper right corner to import the route file to your watch.


## Starting a Trail Run


1. Press the watch's upper button, then tap **Workout > Trail Running** in the app list to enter the workout preparation screen.
2. Swipe up on the screen to the **More** screen, then tap **Navigate route**.
3. Select a route as needed, then tap **Go workout > GO** to start the trail run.
4. Swipe up or down on the screen to view more workout data.
