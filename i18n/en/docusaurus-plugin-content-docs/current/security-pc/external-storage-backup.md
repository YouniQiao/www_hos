# Back Up Data Using External Storage

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/figure/fig_ExternalStorage_Backup.png" width="720" height=""/>

With an external storage device (such as a USB flash drive or portable hard drive), you can easily back up important data and restore it at any time.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Connect the USB storage device to your PC. For details, refer to the device documentation.
2.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_settings.png) in the dock at the bottom of the home screen to open Settings, then click System in the left sidebar.
3.  In the right pane, click Backup and restore > External storage, then perform a backup or restore as needed:
    +   **Backup:** Click New backup, select the data to back up, and click Start backup.
    +   **Restore:** In the backup record list on the External storage screen, click the record you want to restore to open its details, select the data to restore, and click Start restore.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

When you back up for the first time, create a backup password as prompted. Your data will be encrypted during backup.
