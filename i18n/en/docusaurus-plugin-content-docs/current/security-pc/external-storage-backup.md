# Back Up Data Using an External Storage Device

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_ExternalStorage_Backup.png" alt="" width="720" height=""/>

Back up your important data effortlessly to an external storage device (like a USB flash drive or external hard drive) and restore it anytime.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  Connect the USB storage device to the computer. For details, see the device manual.

2.  Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_settings.png) in Dock at the bottom of the home screen to open Settings, and click System in the left pane.

3.  In the right pane, go to **Backup & Restore** > **External storage** to back up or restore data as required.

    +   Backup: Click Back up, select the data you wish to back up, and click Back up.

    +   Restore: In the Backups list on the External storage screen, click your desired backup record to go to the details screen, select the data you wish to restore, and click Restore data.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

During the first backup, follow the onscreen instructions to set the password. The data will be encrypted and backed up.
