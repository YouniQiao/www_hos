# Encrypted File Sharing

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_FileManager_EncryptedShare.png" alt="" width="720" height=""/>

**Encrypted share** restricts file access to specific individuals, by setting permissions to ensure that only authorized people are able to open the encrypted files. You can also set the validity period for viewing encrypted files based on your security needs.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

Before using this feature, remember to log in to your **HUAWEI ID**.

1.  Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_allapps.png) in Dock at the bottom of the home screen to open App chest, and click the app (such as Files or Gallery) where the content to be shared is located.

2.  Select one or more files to be encrypted, right-click the files, and go to **Share** > **Encrypted share**.

3.  Click Add users. Enter the mobile number or email address linked to the HUAWEI ID of the recipient and click Search HUAWEI ID. Alternatively, click Select from Contacts, select the desired contact, and click Done.

4.  On the Encrypted share settings screen, set Validity as needed, and you can also enable Add watermark. The file can be viewed without any time limit with the sender's HUAWEI ID.

    +   No limit: Only the authorized person can open the file, and there is no limit on the number of times the file can be opened.

    +   One view only: Only the authorized person can open the file for the first time. After the File Preview app is closed, the file cannot be opened again.

    +   Set a specified period of time: After the file is opened, the authorized person can only view the file within the specified time limit. After the time limit expires or the File Preview app is closed, the authorized person will no longer be able to view the file.

5.  Click Go share. After the file is encrypted, return to the sharing screen, and click Huawei Share or MeeTime to share the encrypted file with the specified recipient.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

+   Only devices running HarmonyOS 5 or later support viewing encrypted files. Encrypted files do not support screenshot and screen recording.

+   Only devices running HarmonyOS 6.1 or later support adding and viewing the watermark effect, and setting the file validity period.

+   Not all file formats support encryption.
