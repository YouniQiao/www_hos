# Encrypt a file and share it with specified authorized recipients

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/video/vid_FileManager_EncryptedShare.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

When you want only specified authorized recipients to view important files, you can use encrypted sharing to set access permissions for the files and protect your information.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Before using this feature, sign in to your HUAWEI ID.

1.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_filemanager.png) in the shortcut bar at the bottom of the home screen to open Files.
2.  Right-click the file you want to encrypt, select Share > Encrypted share, and follow the on-screen instructions to enter the phone number bound to the target recipient's HUAWEI ID.
3.  After the file is encrypted, click HUAWEI Share to share the encrypted file with the specified authorized recipient. Only the target recipient can open and view the file contents normally after receiving it.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+   This feature is currently supported only between devices running HarmonyOS 5 or later.
+   Not all file formats support encryption. The actual behavior prevails.
