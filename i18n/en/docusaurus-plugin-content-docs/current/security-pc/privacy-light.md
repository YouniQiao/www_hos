# Privacy light, timely alerts for sensitive permissions

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/figure/fig_PrivacyIndicator.png" width="720" height=""/>

Worried that an app might be using sensitive permissions without your knowledge? The privacy light lets you see when sensitive permissions are in use so you can act right away.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When an app is using a sensitive permission (such as location, camera, or microphone), the privacy light indicator appears in the **status bar** at the bottom right of the home screen.

+   **A yellow dot to the right of the battery icon (![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/HM_PrivacyIndicator_yellow.png)):** Indicates that an app is using the microphone permission.
+   **An orange dot to the right of the battery icon (![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/HM_PrivacyIndicator_orange.png)):** Indicates that an app is using the camera permission.
+   **The ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/ic_controlcenter_location_filled.png) icon in the status bar:** Indicates that an app is using the location permission.

Tap the middle area of the status bar at the bottom right of the home screen (which includes the battery icon ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/status/HM_public_battery.png)) to open the Control Panel. At the top of the Control Panel, you can see which apps are currently using permissions. Tap the alert to view details, and tap an app's access record to open the permission management screen and set the permission scope for that app.
