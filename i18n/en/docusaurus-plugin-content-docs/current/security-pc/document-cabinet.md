# Move Files to Safe

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_FileManager_safebox.png" alt="" width="720" height=""/>

Adding important files to **File Safe** and setting access passwords for them, keeps them safely stowed away and safe from prying eyes.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_filemanager.png) in Dock at the bottom of the home screen to open Files.

2.  Go to <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/butons/ic_public_more.png" width="24" height="24"/> > **File Safe** > **New Safe**, set Safe name, Password, and Security questions as prompted, and click Finish.

3.  Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_filenanager_MoveToSafebox.png) in the upper right corner, select a file, and click Open to move the file to File Safe.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

If you're using **File Safe** for the first time, the **Create Safe** screen will display after you click **Enable**.
