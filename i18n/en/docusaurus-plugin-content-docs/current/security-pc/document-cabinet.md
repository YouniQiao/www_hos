# File Safe, protect your private files

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/video/fig_FileManager_safebox.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

Add important files to File Safe and set an access password to prevent files from being illegally obtained, tampered with, or lost, keeping your information secure.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_filemanager.png) in the shortcut bar at the bottom of the home screen to open Files.
2.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/HM_public_more_1.png) > File Safe > Create File Safe, then follow the onscreen instructions to set the File Safe name, password, and security question, and click Done.
3.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/HM_filenanager_MoveToSafebox.png) in the upper right corner, select the files, and click Open to move them into File Safe.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

When you use File Safe for the first time, follow the onscreen instructions and click Enable Now. The File Safe creation screen will then open automatically.
