# Real-time Protection Against Virus Threats

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_settings_VirusProtection.png" alt="" width="720" height=""/>

Safeguard your device with **Security protection** that scans for malicious threats, provides real-time defense, and ensures comprehensive safety at all times.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  Go to **Settings** > **Privacy & security** > **Advanced options** > **Security protection** and make sure that Security protection is enabled (enabled by default). Once enabled, you will be notified if a malicious threat is detected.

2.  You can also click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_filemanager.png) in Dock on the home screen to open Files, select the folder or file to be checked, right-click the folder or file, and go to **More** > **Run security scan** from the shortcut menu.

3.  After the check is complete, if a risky file is displayed on the security screen, you can click Delete or Ingore next to the risky file in the Unhandled threats list.
