# Have a question about your tablet? Try asking Celia

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/10044717_f011_celiacontrol.png" alt="Have a question about your tablet? Try asking Celia" width="560" height="" />

When you're using your tablet and have a question about how a feature works, let Celia answer it for you.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Touch and hold the navigation bar at the bottom of the screen to wake Celia, then ask your question about how a feature works, for example: "How do I set HUAWEI Share to be discoverable by everyone?"

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

If you're using three-button navigation, you can wake Celia by touching and holding the power button, using voice wakeup, and other methods.
