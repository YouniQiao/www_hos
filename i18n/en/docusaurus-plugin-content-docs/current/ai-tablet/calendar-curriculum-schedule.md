# Calendar class schedule, view your class schedule anytime

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/20022701_f001_Curriculum.png" alt="Calendar class schedule" width="560" height="" />

In Calendar, you can quickly create a class schedule by importing an image, and add the class schedule card to the home screen to easily manage and view your classes.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

**Create a class schedule**:

1. Go to **Calendar**, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_calendar_spinner_small.png" width="24" height="24"/> > **Add** > **Add schedule**, and select **Import from Gallery**.
2. Tap **Start Gallery Import**, select the class schedule image, and tap **Done**.
3. Once parsing is complete, check and edit the imported result, then tap **Next**.
4. Adjust the class schedule name, semester start and end dates, and schedule times as needed, then tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_comfirm_calendar.png" width="24" height="24"/> to finish creating it.

**Add a class schedule to the home screen**:

Touch and hold the **Calendar** icon on the home screen, tap **Cards**, swipe left to the **Class schedule** card, and tap **Add to home screen**.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

If any class information in a schedule you've created is incorrect, tap the class's position, then tap **Edit** to modify it.
