# Translate Typed Text with One Tap

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508111clkwd/zh-cn/image/figure/10143300_f002_QuickTranslation.png" width="560" height=""/>


Use the quick translation feature of Celia Keyboard to convert typed text directly into a foreign language, making it easier to communicate with friends from other countries.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  On the keyboard, go to <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202509181mmlk4/zh-cn/image/common/buttons/AI_keyboard.png" width="24" height="24"/> > Common features, swipe left to Quick translation, and tap to enable translation.
2.  Select the target language, tap the input box, and start typing to translate.
