# Drag into Celia to quickly create a calendar event

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/20005937_f001_AIschedule.png" width="560" height=""/>

Drag text into Celia and let Celia help you quickly create a calendar event.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Select the text that contains time information, touch and hold it until it floats, then drag it onto the navigation bar at the bottom of the screen. Once Celia opens, follow the onscreen instructions and tap Extract event.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

After the event is created, tap the event card to make further edits.
