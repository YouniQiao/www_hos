# Immersive translation for easy browsing of foreign-language content

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/10044717_f015_aitranslate.png" alt="Immersive translation" width="560" height="" />

When browsing foreign-language websites or looking up foreign-language materials, you can use Celia to translate the screen content in real time, translating as you browse for an immersive foreign-language reading experience.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1. With the current screen showing a foreign-language website or app interface, touch and hold the navigation bar at the bottom of the screen to wake Celia.
2. Tap **Continuous translation**, select the source language and target language, and the current page will be translated automatically.
3. To exit, tap the navigation bar again, then tap **End translation** in the Celia translation assistant.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

When using three-button navigation, you can wake Celia by touching and holding the power button, using voice wakeup, and other methods.
