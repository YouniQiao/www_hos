# Celia Tasks: Execute a task with one sentence

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/10104441_f004_autotasks.png" alt="Celia Tasks" width="560" height="" />

Use Celia Tasks to create a task with one sentence and run it automatically — for example, playing the news in the morning or turning on Eye Comfort mode when you open an e-book.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Take automatically running an Eye Comfort mode task as an example:

1. Touch and hold the navigation bar at the bottom of the screen to wake Celia, then say the task: "Whenever I open a reading app, turn on Eye Comfort mode."
2. Celia will create a task card. Tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_squarepencil.png" width="24" height="24"/> on the task card to view or edit the task conditions.
3. Once the conditions are met, Eye Comfort mode will turn on automatically whenever you open a reading app.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

- Before using this feature, update both your device and the Celia app to the latest version.
- On the main Celia conversation screen, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_AITouchmore.png" width="24" height="24"/> > **Celia Tasks** to view and manage the tasks you have created.
- Not all task cards support editing conditions. The actual behavior may vary.
- When using three-key navigation, you can wake Celia by touching and holding the power button, using voice wakeup, and other methods.
