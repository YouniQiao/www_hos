# Privacy Light: Timely Alerts for Sensitive Permissions

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202511061evfpV/zh-cn/image/video/20005759_f002_PermissionLight.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>


Worried that an app might be using permissions without your knowledge? Privacy Light lets you see when sensitive permissions are in use so you can take action right away.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When an app uses a sensitive permission (such as camera, microphone, or location), a Privacy Light indicator appears in the top-right corner of your phone's screen.

For example, when an app is using the microphone permission, a yellow dot appears in the top-right corner. Swipe down from the top-right edge of the screen to open the Control Panel, where you can see which app is currently using the permission at the top. Tap the notification to set the permission scope for that app.
