# File Safe, protect your private files

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202502181Uo3yy/zh-cn/image/video/10044552_f003_FileSafe.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

You can move important images, audio and video files, documents, and more into File Safe. Contents in File Safe can be accessed only after verification by password, fingerprint, or other means, and cannot be viewed in other apps.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Go to Settings > Privacy & security > File Safe, tap Enable now, and follow the onscreen instructions to complete the setup. Once set up, you can:

+   **Move files into File Safe**: Tap Move in, select the files you want to move, and tap Done.
+   **View files in File Safe**: Open File Safe and view the files after identity verification.
+   **Move files out of File Safe**: Touch and hold the file you want to move out, then select Move out.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+   Before using this feature, update your device to the latest version.
+   If your phone supports fingerprint/face recognition and you have already enrolled your fingerprint or face, your phone will prompt you to link it for access when you set up File Safe.
