# Manage app permissions to protect your privacy

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202509181mmlk4/zh-cn/image/figure/20005759_f001_PermissionManager.png" width="360" height="486"/>


Manage app permissions (such as location, camera, and microphone) as needed, and set the scope of app permission use to protect your privacy.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Go to Settings > Privacy & security, and touch Permissions to configure settings. For example, you can touch Location to set the following:

+   Turn the Access my location switch on or off. If you turn it off, location permission will be disabled for all apps.
+   Touch an app in the list to set the scope of permission access, such as Allow only while using the app.
