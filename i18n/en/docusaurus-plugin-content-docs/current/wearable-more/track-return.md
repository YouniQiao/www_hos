# Track Back

> This document applies to **WATCH 5**.

The watch can record and navigate routes. After you start a workout or reach your destination, enable Track Back to navigate back to a waypoint or your starting point.


On the watch's app list, tap **Workout** and start a single outdoor workout. During the workout, swipe up on the screen to the track screen, where you can select **Track Back** or **Straight Line Back** to return to a waypoint or your starting point.


If **Track Back** or **Straight Line Back** is not displayed, tap the screen to make it appear.


> 💡 **Tip:** The track screen is not supported for outdoor track running. Track Back can only be used during a workout. Once you end the current outdoor workout, Track Back is no longer available.
