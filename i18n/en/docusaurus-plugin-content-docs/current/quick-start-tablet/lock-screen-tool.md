# Lock screen tools for quick access to apps

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508111clkwd/zh-cn/image/figure/20005688_f001_LockScreenTool.png" width="560" height=""/>

Open frequently used apps like Flashlight and Calculator right from the lock screen — quick and convenient.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

While the screen is locked, wake the screen, then touch and hold the <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/ToolBox.png" width="24" height="24"/> icon in the lower left corner and slide to a tool icon to quickly open the corresponding app.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+   Currently, only some themes support this feature, such as **Recommended themes**, **Mood Box**, and **Weather**. You can go to Settings > Home screen & personalization > More themes to set it up.
+   If you have set face recognition to unlock the screen directly, for a better experience, go to Settings > Biometrics & password > Face recognition > Unlock screen and select Swipe to unlock.
