# Lock Screen Widgets For Instant App Launch

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/figure/20005688_f001_LockScreenTool.png" alt="" width="560" height=""/>

Open Clock, Calculator, and other favorite apps from the convenience of the lock screen.

**Try it out**

Turn on the lock screen, hold down on <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/common/buttons/ToolBox.png" width="24" height="24"/> in the lower left corner, and drap it onto an icon to open the corresponding app.

**Note**

+   This feature is only available in some themes, such as **Suggested**, **Emojis**, and **Space & Weather** themes. You can go to Settings > Home screen & style > More themes to select a theme.

+   If you have set up facial recognition to unlock the screen, for a better experience, it is recommended that you go to Settings > Biometrics & screen lock > Face recognition > Unlock device and select **Swipe to unlock**.
