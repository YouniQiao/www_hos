# Add One-Tap Screen Lock

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/10044757_f006_ScreenLock.png" width="560" height=""/>


Add the One-Tap Screen Lock app or card to the home screen to lock the screen quickly without pressing the power button.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

+   Add an app: In AppGallery, search for "One-Tap Screen Lock", tap Install, and add the One-Tap Screen Lock app to the home screen or the shortcut bar at the bottom.
+   Add a card: Pinch in with two fingers on the home screen, tap Card, select One-Tap Screen Lock, and add the One-Tap Screen Lock card to the home screen.

After adding it, tap the One-Tap Screen Lock app icon or card to lock the screen.
