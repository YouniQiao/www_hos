# Real-time task info, always at your fingertips

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/10044804_f006_LiveCapsule.png" width="560" height=""/>

Live Window keeps real-time info about your tasks always available. For example, during a call, you can use Live Window to check real-time info for other tasks such as a timer.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When a real-time task is in progress (such as a call or timer) and the app moves to the background, the Live Capsule appears in the status bar. You can:

+   View summary info about the task in the Live Capsule, such as call duration or countdown time.
+   Tap the Live Capsule to expand it into a card and view detailed info or quickly perform common actions.
+   Tap anywhere on the card other than the buttons to go straight to the corresponding app.
