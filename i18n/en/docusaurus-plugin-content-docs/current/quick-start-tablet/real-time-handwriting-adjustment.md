# Adjust Handwriting in Real Time

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/10044681_f016_Handwriting.png" alt="Adjust Handwriting in Real Time" width="560" height="" />

When you write by hand, you can change the handwriting to a font such as Regular Script or Running Script.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1. In **Notes**, open a note that is being edited and write a passage by hand.
2. Tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_lasso.png" width="24" height="24"/>, lasso the text you want to adjust, and select **Handwriting adjustment**.
3. After you select a font, the tablet automatically changes the lassoed text to that font.
