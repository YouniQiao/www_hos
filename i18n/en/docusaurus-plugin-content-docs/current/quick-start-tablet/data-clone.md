# Data clone for quick and easy phone migration


<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508111clkwd/zh-cn/image/figure/10044811_f001_phoneclone.png" width="560" height=""/>


Use Data clone to migrate contacts, photos, videos, and other data from your old tablet to your new one in one tap — quick, simple, and worry-free.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  On your new tablet, go to Settings > System > Data clone, touch This is the new device, and select the type of your old device.

2.  On your old tablet, open the cloning app, touch This is the old device, then scan the code to establish a connection.

3.  Select the data you want to migrate, then follow the onscreen instructions to complete the cloning.
