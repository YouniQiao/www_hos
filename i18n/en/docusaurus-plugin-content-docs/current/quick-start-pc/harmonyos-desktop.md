# Your New HarmonyOS Home Screen

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_desktop.png" alt="" width="720" height=""/>

The new HarmonyOS home screen comes with features like Dock, **Celia Search**, and **Control Panel**, to help you navigate with greater ease.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

+   Dock: This is located at the bottom of the home screen and provides direct access to frequently-used apps. Clicking an app icon opens or minimizes the app.

+   Celia Search:![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_celia_AI_search.png) This is located in the lower left corner of the home screen and allows you to search for files, apps, system settings, and Internet information on your computer by entering keywords (such as file name or content) in the search box.

+   Celia:![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_xiaoyi.png) This smart assistant is located in the lower right corner of the home screen, and is responsive to voice and text commands. You can initiate a chat or create a meeting event with the help of Celia.

+   Control Panel:![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_controlcenter_icon.png) This is located in the lower right corner of the home screen, gives you direct access to commonly-used features through Media Controller and shortcut switches, and allows you to click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/status/HM_public_wlan.png),![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_public_hwshare.png), or![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_controlcenter_eyemode.png) to enable or disable common features like WLAN, Huawei Share, or Eye comfort.

+   Widgets: This feature provides access to frequently-used apps via home screen Widgets, which can be previewed or opened by clicking it.

+   App shortcuts: This feature provides shortcuts to frequently-used home screen apps, which can be opened by double-clicking them.

+   Binders: This feature allows you to create Binders to store home screen content by category (home screen widgets cannot be moved to Binders), making management and searching easier.

+   Start menu:![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_public_system.png) This is located in the lower left corner of the home screen and allows you to view recent files and apps, or perform basic operations like opening settings, restarting the computer, and powering off the computer.

+   Notification Center: This is located in the date and time area (where the notification icon![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_notice_bell_filled.png) is), and allows you to view system notifications, event reminders, to-do items, and more.
