# Data Clone, Easy Data Migration

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_DataClone.png" alt="" width="720" height=""/>

**Data Clone** makes it easy to transfer data like documents, pictures, and apps from an old computer to a new one.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

The following uses data migration from a Windows computer to a HarmonyOS computer as an example.

1.  Make sure that the clone app has been installed on both the new and old computers. The Data Clone app is pre-installed on the new computer (running HarmonyOS 5). If the PC Clone app is not installed on the old computer (running Windows), download and install the latest version from the official website of Huawei PC Clone.

2.  On the new computer, click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_allapps.png) in Dock at the bottom of the home screen to access App chest. Click Data Clone and select This is the new computer. Select I've completed these steps and click Next.

3.  On the Pair & connect screen of Data Clone on the new computer, set the type of the old computer to Windows computer, and then click Continue to create a hotspot. Select the type of the old Windows computer (Huawei Windows computer or other Windows computer) based on your device model.

4.  On the old Windows computer, open PC Clone, go to **The old computer** > **NEXT** > **OK**, and search for the new computer. After the search is complete, select the name of the new computer to be connected and click NEXT. Enter the pairing code displayed on the new HarmonyOS computer and click Next. The new and old computers are now paired and connected.

5.  Select the data to be transferred on the old Windows computer (such as documents, images, and apps), click TRANSFER, and wait for the migration to complete.

6.  After the migration is complete, on the Transfer complete screen of Data Clone on the new HarmonyOS computer, you can open Files by going to **View details** > **Open file location** > **Continue** to view the migrated data.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

+   Your old Windows computer must support the wireless network adapter function (except for Broadcom and Wireless-AC 3165 network adapters).

+   The PC Clone app on the Windows computer (old computer) must be 14.0.5.900 or later. PC Clone is only supported on Windows 10 (64-bit) and Windows 11 (64-bit) computers.

+   Certain data and apps can't be migrated. Actual experience shall prevail.
