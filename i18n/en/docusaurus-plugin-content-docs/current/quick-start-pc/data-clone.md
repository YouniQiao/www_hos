# Data Clone: Migrate Your Data to a New PC

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/figure/fig_DataClone.png" width="720" height=""/>

Use Data Clone to migrate basic data (such as documents, images, and apps) from your old PC to a new one. It's quick and easy, so switching PCs is hassle-free.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Make sure the clone app is installed on both your new and old PCs. The new PC (running HarmonyOS 5) comes with Data Clone preinstalled. If PC Clone is not installed on the old PC (running Windows), go to the official HUAWEI PC Clone website to download and install the latest version of the clone app.
2.  Open the clone app on both your new and old PCs:
    +   **New PC (running HarmonyOS 5):** Tap ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_allapps.png) in the shortcut bar at the bottom of the home screen to open App Center, then tap Data Clone to open it. Follow the onscreen instructions to select the type of your old PC (a HUAWEI Windows PC or another Windows PC) and tap Continue. A hotspot will be created to connect to the old PC.
    +   **Old PC (running Windows):** Open PC Clone, follow the onscreen instructions, and tap This is the old PC > Next to confirm and connect to the new PC.
3.  On the pairing screen of the old PC, select the name of the new PC to connect to and tap Next.
4.  Follow the onscreen instructions. On the old PC, enter the pairing code displayed on the new PC and tap Next to finish pairing the two PCs.
5.  On the old PC, select the data to migrate (such as documents, images, and apps), tap Start migration, and wait for the migration to complete. Once it's done, tap Open file location > Continue to view the migrated data in File Management.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+   The Windows PC (old PC) must support a wireless network adapter (except Broadcom adapters and the Wireless-AC 3165 adapter).
+   PC Clone is supported on Windows PCs (old PCs) running Windows 10 (64-bit) or Windows 11 (64-bit) only.
+   Some data and apps cannot be migrated. The actual result prevails.
