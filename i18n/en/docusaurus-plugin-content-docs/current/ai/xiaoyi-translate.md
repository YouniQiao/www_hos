# Immersive translation for effortless browsing of foreign-language content

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202504042smqrg/zh-cn/image/figure/10044717_f015_aitranslate.png" width="360" height="486"/>

When browsing foreign-language websites or looking up foreign-language materials, you can use Celia to translate the screen content in real time, translating as you browse for an immersive foreign-language reading experience.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  With a foreign-language website or app interface on the current screen, touch and hold the navigation bar at the bottom of the screen to wake Celia.

2.  Tap Continuous translation, select the source and target languages, and the current page will be translated automatically.

3.  To exit, tap the navigation bar again, then tap End translation in Celia Translation Assistant.


<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

When using three-key navigation, you can wake Celia by touching and holding the power button, using voice wakeup, or other methods.
