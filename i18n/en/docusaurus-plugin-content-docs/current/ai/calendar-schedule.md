# Calendar class schedule: check your class schedule anytime

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508130fy4kr/zh-cn/image/video/20022701_f001_Curriculum.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

In Calendar, you can quickly create a class schedule by importing an image, and add the class schedule card to the home screen to easily manage and check your classes.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

**Create a class schedule**:

1.  Go to Calendar, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508130fy4kr/zh-cn/image/common/buttons/ic_calendar_spinner_small.png" width="24" height="24"/> > Add > Add schedule, and select Import from Gallery.
2.  Tap Start gallery import, select the class schedule image, and tap Done.
3.  Once parsing is complete, check and edit the imported result, then tap Next.
4.  Adjust the class schedule name, semester start and end dates, and class times as needed, then tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508130fy4kr/zh-cn/image/common/buttons/ic_comfirm_calendar.png" width="24" height="24"/> to finish creating it.

**Add a class schedule to the home screen**: Touch and hold the Calendar icon on the home screen, tap Cards, swipe left to the class schedule card, and tap Add to home screen.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

If any class information in a class schedule you've created is incorrect, tap the class's position, then tap Edit to make changes.
