# System Update

When a new software version is released for your HUAWEI Vision, it will prompt you to download and install the update.

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>HUAWEI Vision does not support rolling back to a previous system version, so proceed with caution.

## Manual update

Turn on your HUAWEI Vision, select **Settings** on the home screen, tap your device name, and tap **Check for updates**. HUAWEI Vision will check the system version. If a new version is detected, follow the on-screen instructions to update the system.

In **About**, tap the **Software update** card to open the software update screen and view details.

## Automatic update

Once the **Auto-update** switch is turned on, HUAWEI Vision will automatically check for new versions when it is powered on or wakes from standby. When a new version is detected, the update package will be downloaded automatically. After the download is complete, you will receive a notification, and HUAWEI Vision will install the update automatically when the screen is off or the device is powered off.

+   First power-on

    During the first power-on, on the **Enhanced services** screen of the setup wizard, select **Enable automatic system software updates** (selected by default).


+   Subsequent power-on
    +   Turn on your HUAWEI Vision, select **Settings** on the home screen, tap your device name, and tap the **Software update** card.
