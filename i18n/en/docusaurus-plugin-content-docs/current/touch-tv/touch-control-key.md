# How to Set Up the Shoulder Buttons

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>This feature is currently supported by only some games.

## **Setup Steps**

1.  After launching a game, tap the function button on the floating controller to quickly open the shoulder button configuration screen.
2.  Touch and hold the LB/RB virtual button icons on the screen, then drag them to the button areas you want to map in the game (for example, the skill button or the acceleration button).
3.  Tap the save button at the top of the screen to finish the mapping configuration.

## **Example** (QQ Speed)

1.  Tap the floating controller function button <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002483849749.png" width="24" height="24"/>.

    ![](https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002450490292.png)

2.  Open the shoulder button mapping configuration screen.

    ![](https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002450649912.png)

3.  Touch and hold the "RB" virtual button icon, then drag it onto the "Nitro Boost" button.

    ![](https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002483853909.png)

4.  Touch and hold the "LB" virtual button icon, then drag it onto the "Nitro Acceleration" button.

    ![](https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002450654442.png)

5.  Tap the "Save" button at the top of the screen to finish the mapping configuration.

    ![](https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002450814066.png)

6.  During a race, press the L/R buttons on top of the controller to trigger the acceleration effect.


    <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>In the current version, LB/RB mapping is enabled by default and cannot be hidden or turned off for now (this feature will be made available in a future system update).
