# Watching Live TV

HUAWEI Vision can be connected to a set-top box to watch TV channels.

## Connecting a Set-Top Box

If you have activated broadband and TV services with your carrier, connect the set-top box to the HDMI port on your HUAWEI Vision to watch TV channels. You can do so as follows:

1.  Insert one end of the HDMI cable into the set-top box and the other end into the HDMI port on the back of your HUAWEI Vision.

2.  Turn on the set-top box power and start the set-top box.
3.  Turn on your HUAWEI Vision, open Input Source <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002420933608.jpg" width="24" height="24"/> on the home screen, press the Menu button <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002462844213.png" width="24" height="24"/> on the remote control to display the menu, tap Switch Input Source, and select the input source corresponding to the set-top box. The input source must match the number of the HDMI port on your HUAWEI Vision to which the set-top box is connected. For example, if the set-top box is connected to HDMI1, select HDMI1 as the input source on your HUAWEI Vision.
4.  Your HUAWEI Vision will display the set-top box screen. For details about how to configure the set-top box, refer to the corresponding set-top box user guide.

    Press the Menu button <img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/zh-cn_image_0000002457716093.png" width="24" height="24"/> on the HUAWEI Vision remote control to configure more settings, such as image settings, sound mode, and HDMI format.

5.  To make it easier to watch TV channels later, go to Settings > Input Source on your HUAWEI Vision, set the default input source to the HDMI port to which the set-top box is connected, and select the option to automatically watch in full screen after power-on.
