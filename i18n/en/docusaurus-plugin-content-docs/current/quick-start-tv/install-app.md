# Install/Uninstall Apps

Learn how to install and uninstall apps on your HUAWEI Vision.

## Install Apps

1. Download and install apps from HUAWEI App Center:

1. On the HUAWEI Vision home screen, select HUAWEI App Center.
2. Enter the name of the app you want to download in the search box.
3. Select the app you want to install and tap **Install**.

2. Install apps via HUAWEI Share:

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>This feature is only supported on HUAWEI phones/tablets running HarmonyOS 5.1 or later. Only some apps can be installed this way. The actual behavior may vary.

1. On your HUAWEI phone/tablet home screen, touch and hold the app you want to share, tap **Share** in the menu that appears, and select the name of the HUAWEI Vision that will receive it.
2. On the HUAWEI Vision, tap **Accept**, then tap **Install** on the screen that appears.

## Uninstall Apps

To ensure your HUAWEI Vision works properly, some preinstalled system apps cannot be uninstalled. The actual behavior may vary.

You can uninstall apps in either of the following ways:

+   On your HUAWEI Vision, go to **Settings** > **Apps**, select the app you want to uninstall, tap **Uninstall**, and select **Uninstall** in the dialog box that appears.
+   Touch and hold the confirm button on the remote control while pointing at the icon of the app you want to uninstall. When the menu appears, release the button, tap **Uninstall**, and select **Uninstall** in the dialog box that appears.
