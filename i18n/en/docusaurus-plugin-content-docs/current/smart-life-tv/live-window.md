# Live Window

The HUAWEI Vision Live Window can display real-time information about current tasks. For example, during a MeeTime call, even if you switch to another app, you can still view the call duration, contact, and other details through the Live Window.

<img src="https://tips-p01-drcn.dbankcdn.cn/hwtips/topic/V0FM/zh-CN/images/icon-note.svg" width="24" height="24"/>Only some apps support the Live Window. The actual experience may vary.

## Live Window capsule view

When an app switches to the home screen or you switch to another app, the status bar shows a Live Window capsule that displays a summary of the current task in real time, such as the screen recording duration, call duration, or timer countdown.

When multiple tasks are in capsule view, the Live Window sorts them by a combination of task priority and creation time. Screen recording and MeeTime have the highest priority, while other tasks are sorted in reverse chronological order by creation time.

## Live Window card view

Tap the Live Window capsule in the status bar to expand it into a Live Window card, where you can view detailed information or quickly perform common actions.

Tap an empty area to collapse it back into a Live Window capsule. When the task ends, it is automatically cleared.
