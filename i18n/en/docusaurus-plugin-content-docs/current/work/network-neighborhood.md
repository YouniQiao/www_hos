# Share Files over LAN

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_FileManager_NetworkShare.png" alt="" width="720" height=""/>

Enable **Network sharing** to allow your computer to share folders with other devices on the same LAN, enabling the sharing of documents, images, and audio and video files.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

The following describes how to access a folder on the computer from another device:

1.  On your computer, click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_filemanager.png) in Dock at the bottom of the home screen to open Files.

2.  Click <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_public_more_1.png" width="24" height="24"/> > **Settings** and enable Network sharing (you may need to scroll down the page). If you are enabling this feature for the first time, follow the onscreen instructions to download and install Network sharing. After the installation is complete, click Save & close to enable network sharing.

3.  Return to the Files screen, right-click the folder you wish to share, and select **Grant access** > **Specify users** to access the sharing screen. Select the target user from the drop-down list. If you are using this feature for the first time, click Create new user, enter the username and password, and click Add.

4.  Set the access permissions (such as read) for the folder, and click Share.

5.  On other devices, you can use the IP address, username, and password of the same network to access the shared folder. For details about how to access the shared folder on a specific device, refer to the device manual or consult the device manufacturer.For example, on a Windows 11 computer, open File Explorer, enter the IP address of the host device in the address bar (for example, \\192.1.1.1), and enter the username and password to connect.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

Currently, this feature is only available on HarmonyOS PCs running HarmonyOS 6.0.0.115 or later.
