# Storage folders for flexible home screen layouts

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/figure/fig_desktop_zone.png" alt="Storage folders for flexible home screen layouts" width="720" height="540" />

Use **storage folders** to fit more content on a single home screen. You can also resize a storage folder to arrange your home screen flexibly. Click an icon in a storage folder to quickly open an app, folder, file, and more.

![Method](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/fig_method.png) Method

1. Right-click a blank area on the PC home screen and select **New > Storage folder**. Click the default name text below the storage folder to enter editing mode and change the folder name.
2. Touch and hold the icon you want to move into the storage folder, drag it to the storage folder area, and then release your finger.
3. You can also try the following operations as needed:
   - **Adjust the storage folder position:** Move the cursor to a blank area of the storage folder, touch and hold the touchpad with one finger (or press and hold the left mouse button), and move it to drag the folder to any position on the home screen (overlapping with home screen cards or other storage folders is not supported; if the folder springs back after you drag it, this is normal).
   - **Adjust the storage folder size:** Move the cursor to the edge of the storage folder. When the cursor changes to a two-way arrow (such as ![Vertical arrow](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/HM_cursor_NorthSouth.png) or ![Diagonal arrow](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/HM_cursor_NorthWest_SouthEast.png)), touch and hold the touchpad with one finger (or press and hold the left mouse button) and move it to drag the edge and resize the folder.
   - **Adjust the position of icons in a storage folder:** Move the cursor to the area of an icon in the storage folder, touch and hold the touchpad with one finger (or press and hold the left mouse button), and move it within the storage folder. Release your finger when a rectangular frame appears.
   - **Automatically sort icons in a storage folder:** Move the cursor to a blank area of the storage folder, right-click and select **Sort**, then choose the sorting rule you want, such as name, date modified, or date created.
   - **Quick access:** Double-click an icon in a storage folder to directly open an app, folder, file, and more.

![Tips](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/fig_tips.png) Tips

Home screen cards cannot be moved into storage folders. Refer to the actual situation.
