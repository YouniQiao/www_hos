# Quickly view files

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/figure/fig_FileManager_preview.png" width="720" height=""/>

Use file preview to quickly view file details without opening another app.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_filemanager.png) in the shortcut bar at the bottom of the home screen to open Files.
2.  Go to the folder containing the file, and click to select the file you want to view (such as an image or PDF document). You can also enter a keyword (such as the file name or file content) in the search box at the top to quickly find and click to select the file.
3.  Press the spacebar or right-click and select Quick view to preview its details.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

Not all file formats support file preview. The actual behavior prevails.
