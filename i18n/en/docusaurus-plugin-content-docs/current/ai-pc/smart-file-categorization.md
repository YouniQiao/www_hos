# Smart categorization: automatically group specified files

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/figure/fig_fileManager_SmartCollections.png" alt="Smart categorization" width="720" height="540" />

Use **Smart categorization** to automatically group files that share common conditions (such as file type, file name, or creation date) for quick viewing. When you add, modify, or delete files that match the conditions, the file list in **Smart categorization** updates automatically.

![Method](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/fig_method.png) Method

1. Click ![Files](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/icon/appicon_filemanager.png) in the **dock** at the bottom of the home screen to open **Files**.
2. Click **Smart categorization** in the left pane, then right-click a blank area in the right pane and select **New smart category**, or click **New > Smart categorization** in the upper-left corner.
3. On the Create smart category screen, set the category conditions:
   - Enter keywords in the upper input box as the search conditions for the category (such as file name or file content).
   - Click ![Expand](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202511200rXkw5/zh-cn/image/common/buttons/HM_public_chevron_down.png) to the right of **Category conditions** to expand it, click **Add**, and then select a search attribute from the drop-down options. If needed, click **Add** to add more conditions.
4. Once you're done, enter a **Smart category name**, and then click **Create smart category**.
