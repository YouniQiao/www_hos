# Smartly Sort Your Files

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_fileManager_SmartCollections.png" alt="" width="720" height=""/>

**Smart collections** automatically sorts files that meet the same condition, making it easy to find what you need. Whenever you add, edit, or remove files matching specific criteria, the system instantly updates its categorized list, ensuring effortless management.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  Click![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/icon/appicon_filemanager.png) in Dock at the bottom of the home screen to open Files.

2.  Click Smart collections in the left pane, and then click New smart collection in the right pane, or go to **New** > **Smart collections** in the upper left corner.

3.  On the smart collections creation screen, enter a collection name and click Add to set conditions (such as keywords, file types, and file names). You can click Add to add multiple conditions.

4.  After the settings are complete, click Create smart collection.
