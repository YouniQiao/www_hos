# Celia Search, find it in one search


<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/figure/fig_AI_search.png" width="720" height=""/>

Celia Search supports not only searching file names and file contents, but also multi-dimensional attribute combinations and complex semantic searches. Search with a single press, and results are intelligently categorized for instant viewing.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Click ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/HM_celia_AI_search.png) in the lower-left corner of the home screen, then enter a keyword in the search box (such as "seaside trip", "photos taken in Beijing", or "documents edited last week"). Search results are displayed by category. In the search results list, you can click to preview file details or open an app.
