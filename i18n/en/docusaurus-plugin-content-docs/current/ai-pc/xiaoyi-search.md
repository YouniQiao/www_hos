# Quick and Accurate Celia Search

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_AI_search.png" alt="" width="720" height=""/>

**Celia Search** helps you find exactly what you're looking for, with smartly sorted searches that sift through file names, content, and keywords.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

Click <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/HM_celia_AI_search.png" width="24" height="24"/> in the lower left corner of the desktop and enter a keyword (for example, "Seaside", "Pictures taken in Beijing", or "Documents edited last week") in the search box. The search results will display by category. Click to preview a file or open an app in the search results.
