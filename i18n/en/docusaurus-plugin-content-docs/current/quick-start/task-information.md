# Real-time task info, always at your fingertips

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202410131vcl7z/zh-cn/image/figure/10044804_f006_LiveCapsule.png" width="360" height="486"/>

Live Window keeps real-time info about your tasks always available. For example, during a call, you can use Live Window to check real-time info for other tasks such as a timer.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When there is an ongoing real-time task (such as a call or a timer), the Live Window capsule appears in the status bar once the app moves to the background. You can:

+   In the Live Window capsule, view summary info about the task, such as call duration or countdown time.
+   Tap the Live Window capsule to expand it into a card, where you can view detailed info or quickly perform common actions.
+   Tap anywhere outside the buttons on the Live Window card to go straight to the corresponding app.
