# Data Clone: Migrate Your Data to a New Phone


<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512250Xzgpn/zh-cn/image/figure/10044811_f001_phoneclone.png" width="360" height="486"/>


Use Data Clone to migrate contacts, photos, videos, and other data from your old phone to your new phone in one go — quick, easy, and worry-free.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  On your new phone, go to Settings > System > Data Clone, tap This is the new device, and select the type of your old device.

2.  On your old phone, open the cloning app, tap This is the old device, then scan the code to establish a connection.

3.  Select the data you want to migrate, and follow the onscreen instructions to complete the cloning.
