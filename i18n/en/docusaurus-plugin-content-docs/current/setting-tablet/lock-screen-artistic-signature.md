# Lock screen artistic signature: create a personalized wallpaper

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/figure/10044758_f013_Dynamic.png" alt="Lock screen artistic signature" width="560" height="" />

Use an artistic signature to blend signature text artistically with your wallpaper image. You can also use AI to create a font style you like and apply it to your signature in one tap, making your lock screen truly one of a kind.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1. Go to **Gallery**, select an image, and tap **<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_more.png" width="24" height="24"/> > Set as wallpaper**.
2. Tap the clock area and select **Artistic signature**.
3. Tap the artistic signature area to customize it:
    * Tap the text box below **Artistic signature** and enter your signature text. For best results, keep it within 6 Chinese characters.
    * Tap **<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/textformat_size_square_fill-01.png" width="24" height="24"/>** to change the font style. You can also tap **<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_ai_font_12-01.png" width="24" height="24"/>** to select an image containing text, let AI create a font from it, and apply it to your signature in one tap.
    * Tap **<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202608192tbkfh/zh-cn/image/common/buttons/ic_desktop_color-01.png" width="24" height="24"/>** to change the font color.
4. Tap **Apply > OK** to finish.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

For a better artistic signature wallpaper, choose an image with a clear subject and a clean background.
