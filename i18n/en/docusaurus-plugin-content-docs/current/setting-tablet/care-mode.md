# Care Mode: Safe and Convenient

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/20006188_f001_SeniorMode.png" width="560" height=""/>

Turn on Care Mode to quickly enlarge the screen display and simplify the home screen layout for clearer visibility. You can also set up harassment blocking and other features for safer use.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Go to Settings > Accessibility features > Care Mode and turn on the Care Mode switch.

+   Under Enlarge display, drag the slider to adjust the display size to a level that suits you.
+   Under Home screen layout, select Simple layout to make home screen icons larger and the layout simpler.
+   Under Harassment blocking, set the range of what you want to block, such as nuisance calls.
