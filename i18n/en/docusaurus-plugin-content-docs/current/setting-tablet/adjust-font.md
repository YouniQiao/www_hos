# Font and Display Size Adjustments

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/figure/10044740_f001_NewFont.png" alt="" width="560" height=""/>

Switch the font effects and display size on a whim, and with absolute ease.

**Try it out**

Go to Settings > Display & brightness > Text & display size and drag the slider at the bottom of the screen.

+   **Text size**: To adjust the font size.

+   **Text weight**: To adjust the font weight.

+   **Display size**: To adjust the relative size of different on-screen elements, such as text and images.
