# Wallpaper Settings

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/figure/fig_settings_wallpaper.png" alt="" width="720" height=""/>

Set favorite pics as the desktop and lock screen backgrounds, to see something special each time you glance at your computer.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_method.png" width="24" height="24"/> Try it out

1.  On the home screen, right-click any blank area and select Change wallpaper.

2.  Select a preset wallpaper to set it as the wallpaper. Some preset wallpapers are live wallpapers (with the![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/circle_live_wallpaper.png) icon in the lower left corner of the image). When using such wallpapers, you can enjoy the continuous dynamic effects on the lock screen, or double-click the home screen to interact with the wallpaper.

3.  You can also click Add image, select an image from Gallery or Files, and set it as the wallpaper.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202605280pkqzz/en-us/image/common/buttons/fig_tips.png" width="24" height="24"/> Note

+   Certain preset live wallpapers do not support double-click interaction on the home screen. Actual usage may vary.

+   Not all image formats are supported as wallpapers. If your desired image is not available when you add an image, the image format may not be supported.
