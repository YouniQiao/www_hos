# Share Schedules for More Efficient Collaboration


<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508180uszcw/zh-cn/image/video/20005937_f002_ShareSchedule.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

Just type a sentence to quickly create a schedule and share it with friends. One person creates it, many can view it, and any changes sync in real time.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Go to Calendar, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508180uszcw/zh-cn/image/common/buttons/ic_add_calendar.png" width="24" height="24"/> > Schedule, and enter your schedule details in the smart one-sentence schedule creation input box. The time, location, and other details are extracted automatically.
2.  Tap Add shared members, select the members you want to share with, tap Done, then tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508180uszcw/zh-cn/image/common/buttons/ic_comfirm_calendar.png" width="24" height="24"/> to start sharing the schedule.
3.  On the recipient's phone, tap the notification to open the shared schedule, then tap Accept.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

This feature requires both devices to run HarmonyOS 5 or later.
