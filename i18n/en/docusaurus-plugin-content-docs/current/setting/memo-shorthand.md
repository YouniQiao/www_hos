# Memo shorthand, quick summary and original text

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/video/20014428_f001_QuickNote.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

When browsing apps or web pages, use the shorthand feature to add links to Memo. It not only automatically generates a summary, but also lets you quickly revisit the original text with one tap, making it easy to consolidate fragmented information.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  For a better experience, sign in to your HUAWEI ID before use.
2.  Open the content you want to record, swipe down from the top right of the screen to open the Control Panel, and tap Shorthand.
3.  Tap Add link > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_choose_done.png" width="24" height="24"/> to save the original link to Memo.
4.  Go to Memo, open the corresponding memo, and tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_public_arrow_down.png" width="24" height="24"/> to view the full summary; tap the link to quickly return to the original text.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

+   HUAWEI Browser and other apps are currently supported. Summaries may not be generated for some sensitive information. The actual experience prevails.
+   When using the shorthand feature for the first time, swipe down from the top right of the screen to open the Control Panel, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_controlpanel_edit.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_quickswitch_add.png" width="24" height="24"/> to expand the shortcut switch panel, then tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_quickswitch_add1.png" width="24" height="24"/> > <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031BETA/resource/card/202504201ngpds/zh-cn/image/common/buttons/ic_choose_done.png" width="24" height="24"/> on Shorthand to add it to the Control Panel.
