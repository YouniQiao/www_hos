# Lock Screen: Make It Your Own

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/video/20005688_f002_lockScreen.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="360" height="486"> </iframe>

Pinch in with two fingers on the lock screen to change the clock style, add lock screen cards such as alarms and weather, set a lock screen signature, and quickly switch wallpapers and themes — making your lock screen both better looking and more useful.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

1.  Enter the lock screen editing screen:
    +   If you use a password or fingerprint to unlock, wake the screen, then pinch in with two fingers on the lock screen while it is still locked, and unlock to enter.
    +   If you use face recognition, it is recommended that you switch to swipe to unlock. Wake the screen, unlock with face recognition, then pinch in with two fingers to enter.
2.  Tap the clock card to adjust the lock screen clock style, font, and color. Tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/ic_lockscreen_more.png" width="24" height="24"/> to set a lock screen signature, then tap Back.
3.  On the lock screen editing screen, tap the circle below the clock card to add cards you like. Touch and hold a card, then drag it to reposition it.
4.  Once you are done, tap Apply.


<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

Currently, only some themes support this feature, such as **Recommended themes**, **Mood Box**, and **Weather**. To set them up, go to Settings > Home screen & personalization > More themes.
