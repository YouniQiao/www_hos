# Adjust the font and display size

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202512250Xzgpn/zh-cn/image/figure/10044740_f001_NewFont.png" width="360" height="486"/>


You can set different font effects and display sizes to suit your habits.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Go to Settings > Display & brightness > Font size and interface scaling, then drag the sliders at the bottom of the screen to adjust.

+   Font size: Adjust the text size.
+   Font weight: Adjust the text weight.
+   Display size scaling: Adjust the size of interface elements such as text and images.
