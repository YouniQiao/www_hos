# Back up data using external storage

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202508111clkwd/zh-cn/image/figure/10044811_f002_Backup.png" width="560" height=""/>

Use external storage (USB flash drives, portable hard drives, and the like) to easily back up important data and restore it whenever you need.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

**Back up**: Go to Settings > System > Backup & restore > External storage, tap New backup, select the data you want to back up, and tap Start backup.

**Restore**: On the phone's External storage screen, go to Backup records, select the data you want to restore, tap Start restore, enter the backup password as prompted, and then restore the data.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202508300vZjQz/zh-cn/image/common/buttons/fig_tips.png" width="24" height="24"/> Tips

The first time you back up, create a backup password as prompted. Your data will be backed up in encrypted form.
