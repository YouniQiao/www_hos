# Encrypted File Sharing

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/figure/20005748_f001_EncryptedSharing.png" alt="" width="560" height=""/>

Encrypted sharing restricts access to specific individuals, by setting permissions to ensure that only authorized people are able to open the file. You can also set the One view only permission, so that recipients can view the file only once.

**Try it out**

1.  In **Files**, **Gallery**, or **Recorder**, select one or more files to be encrypted, tap <img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202606110qRije/en/image/common/buttons/ic_gallery_share.png" width="24" height="24" alt="Share icon"/>, select **Encrypted share**, and add HUAWEI ID users who can view the files as prompted.

2.  On the **Add user** screen, you can set the validity period of the file to **No limit**, **One view only**, or **Specified duration**, and enable **Add watermark**.

    +   **No limit**: Only the authorized person can open the file, and there is no limit on the number of times the file can be opened.

    +   **One view only**: Only the authorized person can open the file for the first time. After the **File Preview** app is closed in the background, the file cannot be opened again.

    +   **Specified duration**: The authorized person can only view the file within the specified duration. If the specified duration has lapsed or the **File Preview** app is closed, the file cannot be viewed again.

3.  Tap **Go share** to generate a new encrypted file.

4.  Return to the sharing screen and select **Huawei Share** or **MeeTime** to share.

**Note**

+   Only devices running HarmonyOS 5 or later support viewing encrypted files. Encrypted files do not support screenshot and screen recording.

+   Only devices running HarmonyOS 6.0.0.328 SP52 or later support adding and viewing **Add watermark** effects and setting the file viewing duration.

+   Not all file formats support encryption. Actual experience shall prevail.
