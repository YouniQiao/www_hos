# Privacy Light: Timely Alerts for Sensitive Permissions

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B031/resource/card/202502281vpXhm/zh-cn/image/figure/20005759_f002_PermissionLight.png" width="560" height=""/>


Worried an app might be using permissions without your knowledge? Privacy Light lets you see when sensitive permissions are in use so you can take action right away.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/EMUI/C00B030/resource/card/202503041becsx/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When an app uses a sensitive permission (such as camera, microphone, or location), a Privacy Light indicator appears in the top right corner of your phone's screen.

For example, when an app is using the microphone permission, a small yellow dot appears in the top right corner. You can swipe down from the top right of the screen to open the Control Panel and check which app is currently using the permission at the top of the Control Panel. Tap the notification to set the permission scope for that app.
