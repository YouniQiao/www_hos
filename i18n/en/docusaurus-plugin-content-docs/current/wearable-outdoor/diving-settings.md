# Diving settings

> This document applies to **WATCH Ultimate ULTIMATE DESIGN**.

Before you start diving, you can adjust diving-related settings to suit your needs.

## Accessing diving settings

1. In the watch's app list, tap **Diving**.
2. Tap the **Settings** icon to open the diving settings screen.

## Settings descriptions

### Diving mode

- **Scuba diving**: For diving with an air tank.
- **Freediving**: For breath-hold diving.

### Gas mixture

- Set the oxygen concentration (21%–100%).
- Set the nitrogen concentration.
- Set the helium concentration (trimix diving).

### Safety reminders

- **Depth reminder**: Set a target depth, and the watch will vibrate when you reach it.
- **Ascent rate reminder**: The watch will issue a warning if you ascend too quickly.
- **Safety stop**: The watch will remind you to perform a safety stop after you reach the specified depth.

### Other settings

- **Underwater heart rate alert**: Set the upper and lower heart rate limits.
- **Water temperature unit**: Celsius or Fahrenheit.
- **Depth unit**: Meters or feet.

:::tip Note
Before diving, carefully check all settings to make sure the parameters match your dive plan.
:::
