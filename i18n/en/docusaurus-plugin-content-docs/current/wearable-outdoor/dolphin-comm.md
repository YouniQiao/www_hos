# Dolphin Communication

> This document applies to **WATCH ULTIMATE DESIGN**.

Press the watch's upper button, then in the app list, tap **Workout > Diving** > **Dive tools** to access the dive tools list.


## No-decompression calculation

1. Tap **No-deco calculation**, swipe up or down on the screen to select a **Gas**, and tap **Next**.
2. Swipe up or down on the screen to select the **Dive start time**, and tap **OK**. You can view the **no-decompression limit** values for different depths.
Tap **Precise query**, select a **Descent depth**, and view the **no-decompression limit** value for that depth.
