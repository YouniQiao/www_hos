# Right-click to show more menus

<iframe src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/video/vid_Touchpad_Rightclick_menu.mp4#toolbar=0" scrolling="no" border="0" frameborder="no" framespacing="0" allowfullscreen="true" width="720" height="540"> </iframe>

Use a touchpad gesture to quickly open the shortcut menu for the system or an app.

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

Take the right-click menu for a file in Files as an example:

Tap ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/icon/appicon_filemanager.png) in the dock at the bottom of the home screen to open Files, move the cursor over the icon of the file you want to work with, and then press the right side of the touchpad to bring up the shortcut menu, where you can copy, share, and more.
