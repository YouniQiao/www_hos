Shortcut keys in hotkey mode

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

In hotkey mode (when the Fn key indicator is off), use the following shortcuts to adjust screen brightness or volume.

+   **Adjust screen brightness:** Press F1 to lower the screen brightness; press F2 to increase the screen brightness.
+   **Adjust volume:** Press F5 to lower the volume; press F6 to raise the volume.
