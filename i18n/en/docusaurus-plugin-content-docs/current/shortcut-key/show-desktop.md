Shortcut key to show the desktop

<img src="https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/buttons/fig_method.png" width="24" height="24"/> Method

When you have many apps open, press the HarmonyOS key![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png) + D key combination on the keyboard to quickly minimize all open app windows and show the desktop. Press it again to restore all open app windows.
