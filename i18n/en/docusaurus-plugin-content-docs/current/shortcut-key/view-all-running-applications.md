Shortcut key to view all running apps

Press the HarmonyOS key on the keyboard ![](https://tips-p01-drcn.dbankcdn.cn/MODEL/DOC/C00B030/resource/card/202512281uswxk/zh-cn/image/common/keyboard/HM_keyboard_OH_1.png) + Tab to enter Task Center, where you can view all apps currently running on your PC and click to switch between or close them.
